# 3. Microbial isotopic source signature

A $\delta ^ { 1 3 } \mathrm { C } _ { \mathrm { { s o u r c e } } }$ database including $1 . 0 2 1 \delta ^ { 1 3 } \mathrm { C _ { M i c } }$ measurements was compiled from the literature for the following microbial source categories: wetlands, termites, ruminants, rice agriculture, and waste/landfills. The full database including measurement locations, means and uncertainties, sample sizes, metadata (e.g., season), and literature references is available in ref14. Measurement methods include flux chamber (e.g., wetlands) and downwind plumes (e.g., landfills). Each database entry describes an original set of measurements for a specific geographic area or date, or both. A $\delta ^ { 1 3 } \mathrm { C } _ { \mathrm { M i c } }$ distribution was established for each microbial source sub-category by MC simulation sampling from each $\delta ^ { 1 3 } \mathrm { C } _ { \mathrm { M i c } }$ literature entry within each sub-category (including mean and SD; see SI Figure 4).

# Ruminant $\delta ^ { l 3 } C _ { M i c }$ data and weighting based on diet

Ruminant $\delta ^ { 1 3 } \mathrm { C } _ { \mathrm { M i c } }$ measurements were distinguished by diet because $\mathrm { C H } _ { 4 }$ from a $\mathrm { C } _ { 4 }$ plant based diet is heavier than from a $\mathrm { C } _ { 3 }$ plant based diet based on our database14. It includes ruminant

$\delta ^ { 1 3 } \mathrm { C } _ { \mathrm { M i c } }$ measurements with controlled diets, and the data indicate a bimodal distribution: diets consisting of $260 \%$ $\mathrm { C } _ { 4 }$ plants yield $\delta ^ { 1 3 } \mathrm { C } _ { \mathrm { M i c } }$ of $- 5 4 . 6 \pm 3 . 1 \% o$ (1 SD) compared to a $\mathrm { C } _ { 3 }$ plant based diet $( - 6 9 . 4 \pm 3 . 1 \% o )$ . Weighting $\mathrm { C } _ { 3 }$ vs. $\mathrm { C } _ { 4 }$ based diet signatures requires global ruminant feed data including grains and grasses. Cattle contribute $96 \%$ of U.S. ruminant $\mathrm { C H } _ { 4 }$ emissions (the remainder being mainly pigs, horses, sheep, and goats)22 even though cattle represent only $57 \%$ of U.S. ruminant livestock (1980–2013 average; the global figure is $3 3 \% ^ { 5 0 }$ ). Since cattle are by far the dominant ruminant source, and because of lack of diet data for other ruminants, this model does not account for potential differences in the $\mathrm { C } _ { 3 } / \mathrm { C } _ { 4 }$ diet ratio between cattle and other ruminants.

The economically important $\mathrm { C } _ { 4 }$ grains used as cattle feed (including byproducts) include maize, sugarcane, sorghum, and millets, whereas most other grains are from $\mathrm { C } _ { 3 }$ plants. We estimated the fraction of U.S. cattle with a $\mathrm { C } _ { 4 }$ -based diet (defined as $2 6 0 \%$ $\mathrm { C } _ { 4 }$ plants, see above) as follows. The majority of U.S. cattle feed $\mathrm { C } _ { 4 }$ grains include maize $( 9 4 \% )$ and sorghum $( 4 \% ) ^ { 5 1 }$ . Based on literature52–54 and expert feedback55, our model assumes $0 \%$ $\mathrm { C } _ { 4 }$ diet (uniform distribution) in cow-calf operations, $100 \%$ in feedlots, and $0 { - } 2 5 \%$ (uniform distribution) in dairy operations (all including $\mathrm { C } _ { 4 }$ grains and silage). Weighting the $\mathrm { C } _ { 4 }$ distributions of these operations by their relative emission strength22 results in a U.S. $\mathrm { C } _ { 4 }$ emission fraction of $1 9 . 6 \pm 5 . 9 \%$ (1 SD). Extrapolating the U.S. $\mathrm { C } _ { 4 }$ emission fraction globally, where there is little available data, requires accounting for the relatively high use of $\mathrm { C } _ { 4 }$ feed grain in the U.S. During 1980–2013, the U.S. held only $7 \%$ of the global cattle population50, but it consumed $32 \%$ of global maize and sorghum feed51. We therefore used the U.S. $\mathrm { C } _ { 4 }$ emission fraction as a global upper bound. As a global lower bound, the model assumes that the $\mathrm { C } _ { 4 }$ diet fraction in the rest of the world (ROW) is zero, i.e., only a negligible fraction of ROW cattle receives $\mathrm { C } _ { 4 }$ -based plant feed. Accounting for U.S. and global cattle populations50 results in a global weighted average $\mathrm { C } _ { 4 }$ emission fraction range of $1 . 5 \mathrm { - } 1 9 . 6 \%$ (uniform). Note that we assume a $\mathrm { C } _ { 4 }$ diet fraction for grazing cattle similar to our distribution for grain-fed cattle. This assumption is consistent with global plant coverage data indicating that ${ \sim } 2 0 \%$ of both total land and cropland coverage are $\mathrm { C } _ { 4 }$ based56. Thus, unless a disproportionately large fraction of cattle grazes on land with predominantly $\mathrm { C } _ { 4 }$ based vegetation, our global weighted average $\mathrm { C } _ { 4 }$ emission fraction distribution can be used to encompass both grain and grass based diets. respective emission fraction distributions in a MC simulation yields a global weighted average ruminant $\delta ^ { 1 3 } \mathrm { C } _ { \mathrm { M i c } }$ of $- 6 6 . 8 \pm 2 . 8 \% o$ , 1 SD). # 6. Paleo $\underline { { \mathbf { C H } _ { 4 } } }$ budget and fossil $\underline { { \mathbf { C H } _ { 4 } } }$ emissions from geological seepage

Geological $\mathrm { C H } _ { 4 }$ sources refer to natural emissions of gas through the Earth’s crust in sedimentary, petroleum-prone basins (incl. gas-oil seeps, mud volcanoes, diffuse micro-seepage) and geothermal-volcanic systems12,63,64. Bottom-up estimates12,13,65 of global $\mathrm { F F _ { G e o } }$ are 45–76 Tg $\mathrm { C H _ { 4 } / y r }$ based on the acquisition of thousands of flux measurements for various seepage types in

12 countries in different petroliferous basins64; these were scaled up globally following the concepts of “point sources”, “area sources”, “activity” and “emission factors” as recommended by EMEP-EEA66. In the absence of $\mathrm { F F _ { I n d } }$ in the pre-industrial era, $\mathrm { F F _ { G e o } }$ is considered the only source with a $\delta ^ { 1 3 } \mathrm { C } _ { \mathrm { F F } }$ signature. Ice core records of $\mathrm { C H } _ { 4 }$ levels and $\delta ^ { 1 3 } \mathrm { C }$ over the past two millennia24–26,67 help constrain global $\mathrm { F F _ { G e o } }$ top-down, but this requires observations about preindustrial BB emissions, which are not available. Previous studies24,67 reversed this approach by estimating BB emissions (on average $2 0 { - } 3 0 \mathrm { T g } \mathrm { C H } _ { 4 } / \mathrm { y r }$ during AD 0–1600) based on outdated bottom-up $\mathrm { F F _ { G e o } }$ estimates. This range is lower than current day – partly satellite-based – BB estimates of $2 5 { - } 6 0 \mathrm { T g } \mathrm { C H } _ { 4 } / \mathrm { y r }$ including biofuels and wildfires11, perhaps due to a smaller human influence in the pre-industrial era. While $\mathrm { F F _ { G e o } }$ cannot be estimated without assumptions about pre-industrial BB estimates, we verified whether our global $\delta ^ { 1 3 } \mathrm { C } _ { \mathrm { s o u r c e } }$ inventory is consistent with previous $\mathrm { F F _ { G e o } }$ estimates and the above model-derived pre-industrial BB emissions. Note that we assume that the temporal average $\delta ^ { 1 3 } \mathrm { C } _ { \mathrm { F F } }$ based on NG/oil well and coal mine data is representative of $\mathrm { F F } _ { \mathrm { G e o } } \mathrm { C H } _ { 4 }$ emissions. Since there is no significant isotopic fractionation during gas migration in petroleum systems from reservoir to the surface68,69 (although molecular fractionation does occur68,69), potential differences in $\delta ^ { 1 3 } \mathrm { C } _ { \mathrm { F F } }$ between $\mathrm { C H } _ { 4 }$ emissions from $\mathrm { F F _ { I n d } }$ and $\mathrm { F F _ { G e o } }$ may only result from a potential sampling bias in our (however large) $\delta ^ { 1 3 } \mathrm { C } _ { \mathrm { F F } }$ database, i.e., reservoir depths (largely determining reservoir pressure and thus the level of thermogenic methane formation and $\delta ^ { 1 3 } \mathrm { C } _ { \mathrm { F F } } \big )$ ) of the samples vs. the seepage source. # 7. Global TM5 simulations

The broad spatial distribution of some $\mathrm { C H } _ { 4 }$ source categories is relatively well known. For example, $\sim 9 2 \%$ of $\mathrm { F F _ { \mathrm { T o t } } C H _ { 4 } }$ is emitted in the Northern Hemisphere2 with smaller values for agriculture (including livestock and rice production), waste, landfills (Ag/Waste/LF) at $8 2 \% ^ { 2 }$ and natural wetlands at $5 4 \%$ . By simulating global atmospheric $\mathrm { C H } _ { 4 }$ mole fractions using emissions maps scaled by select $\mathrm { C H } _ { 4 }$ source attribution scenarios using the global atmospheric chemistry and transport model $\mathrm { T M } 5 ^ { 2 7 }$ and comparing the resulting $\mathrm { C H } _ { 4 }$ levels across latitudes with observations20 we included a spatial constraint in our analysis in addition to the mass balance.

# Description of simulated $C H _ { 4 }$ source attribution scenarios

The simulated emission scenarios are summarized in SI Figure 14. Total $\mathrm { C H } _ { 4 }$ emissions from all sources (excluding soil sink) equal the total $\mathrm { C H } _ { 4 }$ emissions from the box model to allow direct comparison of TM5 results and the box model. The scenarios assume the mean box model $\mathrm { C H } _ { 4 }$ lifetime of 9.0 years, and the TM5 OH field was scaled (uniformly across space) such that global chemical destruction is approximately equivalent to the box model $\mathrm { C H } _ { 4 }$ lifetime. We simulated three FF scenarios that encompass approximately the $1 0 ^ { \mathrm { t h } } / 9 0 ^ { \mathrm { t h } }$ percentile range in the box model (150, 200, and $2 5 0 \mathrm { T g } \mathrm { C H } _ { 4 } / \mathrm { y r } )$ ). This range includes $\mathrm { F F _ { I n d } }$ and $\mathrm { F F _ { G e o } }$ , and measurements65 suggest that both sources are generally co-located. The same BB grid maps and absolute $\mathrm { C H } _ { 4 }$ emissions were used in each scenario. Scenarios S1, S4, S6, and S7 include $1 7 5 \mathrm { T g } \mathrm { C H } _ { 4 } / \mathrm { y r }$ natural emissions from Bergamaschi et al. $( 2 0 0 7 ) ^ { 7 2 }$ (consistent with the mean of several other top-down studies3,6,7). The simulated natural emissions also include a residual IAV component after accounting for IAV from BB and global total $\mathrm { C H } _ { 4 }$ emissions based on the assumption that anthropogenic source IAV is very small compared to natural source IAV. We attributed the remainder of the global $\mathrm { C H } _ { 4 }$ budget including its $2 5 \mathrm { T g }$ growth over time to the Ag/Waste/LF source. The box model $\mathrm { C H } _ { 4 }$ growth allocation is more complex as described above $( \sim 4 5 \mathrm { T g }$ increase from either natural or Ag/Waste/LF, and a FF decrease of ${ \sim } 2 0 \mathrm { T g }$ , all after 2004).

However, these details were disregarded for simplicity and because such small budget terms are likely to have only a minor affect on the simulated $_ { \mathrm { N - S } }$ gradient, which is the focus of the TM5 modeling. Scenarios S2, S3, S5, S8, and S9 explore the hypothesis of underestimated tropical wetland emissions by up-scaling this source between the equator and $2 5 ^ { \circ } \mathrm { S }$ by 51 or $1 0 2 \mathrm { T g }$ $\mathrm { C H _ { 4 } / y r }$ , and down-scaling the Ag/Waste/LF grid maps uniformly by 50 or $1 0 0 \mathrm { T g } \mathrm { C H } _ { 4 } / \mathrm { y r }$ . We introduced the 1 and 2 $\mathrm { T g } \mathrm { C H } _ { 4 } / \mathrm { y r }$ differences between up-scaling natural emissions and downscaling Ag/Waste/LF emissions to partly account for the larger OH sink in the tropics and rapid vertical distribution of emissions relative to mid-latitudes (see description below).

Global total $C H _ { 4 }$ level differences between observations and simulations (model artifact)

The simulated and observed annual mean, globally averaged $\mathrm { C H } _ { 4 }$ levels for all years are shown in SI Figure 15 (panels d, e). The simulated $\mathrm { C H } _ { 4 }$ of all scenarios generally follows the observed trend as expected because simulated annual total $\mathrm { C H } _ { 4 }$ emissions were scaled according to observed global means using the box-model (SI section 1). Note that scenario-dependent amounts of $\mathrm { C H } _ { 4 }$ (spatially varying emissions among scenarios) are consumed in the 3D model

because (i) the OH sink is larger in the tropics than in lower latitudes (more water vapor, higher temperatures, and more solar radiation), and (ii) emissions are distributed through a deeper atmospheric column. However, the empirical tuning of the total OH sink in TM5 was applied only once for all scenarios. In contrast, the box-model considers a global average $\mathrm { C H } _ { 4 }$ sink. Thus, some simulation–observation mismatches are expected because relatively high tropical emissions in some scenarios, e.g. S3 vs. S1, lead to greater total $\mathrm { C H } _ { 4 }$ destruction, thus lower global average $\mathrm { C H } _ { 4 }$ levels. The particular simulation–observation mismatches in SI Figure 15 (panels d, e) are explained as follows. (i) The constant simulated emissions during 1980-1983 (for model initialization; SI Figure 14) are likely too high in absence of observations, which results in overestimated $\mathrm { C H } _ { 4 }$ levels. (ii) This surplus $\mathrm { C H } _ { 4 }$ decreases over time as “true” emissions increase to the simulated values, and the surplus has decayed by the early-1990s (approximately one $\mathrm { C H } _ { 4 }$ lifetime after 1983). (iii) Simulations and observations are roughly in balance starting in 1994 for scenarios without added tropical emissions (S1/4/6/7). (iv) In 2000/2001 and 2004/2005 total global emissions drop by ${ \sim } 2 0 \mathrm { T g / y r }$ , but scenarios S2/3/5/8/9 include a fixed shift of emissions (50 or $1 0 0 \mathrm { T g / y r }$ ) from Northern mid-latitudes to the tropics (where $\mathrm { C H } _ { 4 }$ destruction is greater). This increases global total $\mathrm { C H } _ { 4 }$ destruction relative to S1/4/6/7 and observations, which leads to lower global $\mathrm { C H } _ { 4 }$ levels relative to S1/4/6/7 and observations until the pre-2001 simulations–observations difference is achieved again. Note, however, that while this model artifact influences simulated global average $\mathrm { C H } _ { 4 }$ levels, it has little bearing on the simulated N–S gradients given the relatively fast inter-hemispheric atmospheric mixing of ${ \sim } 1$ year.
