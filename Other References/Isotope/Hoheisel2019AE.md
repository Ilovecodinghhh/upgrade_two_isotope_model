Abstract. The carbon isotopic signature $( \delta ^ { 1 3 } \mathrm { C H } _ { 4 } )$ of several methane sources in Germany (around Heidelberg and in North Rhine-Westphalia) were characterised. Mobile measurements of the plume of $\mathrm { C H } _ { 4 }$ sources are carried out using an analyser based on cavity ring-down spectroscopy (CRDS). To achieve precise results a CRDS analyser, which measures methane $\mathrm { ( C H _ { 4 } ) }$ , carbon dioxide $\left( \mathbf { C O } _ { 2 } \right)$ and their $^ { 1 3 } \mathrm { C } .$ -to- $^ { 1 2 } \mathrm { C }$ ratios, was characterised especially with regard to cross sensitivities of composition differences of the gas matrix in air samples or calibration tanks. The two most important gases which affect $\delta ^ { 1 3 } \mathrm { C H } _ { 4 }$ are water vapour $\left( \mathrm { H } _ { 2 } \mathrm { O } \right)$ and ethane $\mathrm { ( C _ { 2 } H _ { 6 } ) }$ . To avoid the cross sensitivity with $_ { \mathrm { H } _ { 2 } \mathrm { O } }$ the air is dried with a Nafion dryer during mobile measurements. ${ \mathrm { C } } _ { 2 } { \mathrm { H } } _ { 6 }$ is typically abundant in natural gases and thus in methane plumes or samples originating from natural gas. A ${ \mathrm { C } } _ { 2 } { \mathrm { H } } _ { 6 }$ correction and calibration are essential to obtain accurate $\delta ^ { 1 3 } \mathrm { C H } _ { 4 }$ results, which can deviate by up to $3 \text{‰}$ depending on whether a ${ \mathrm { C } } _ { 2 } { \mathrm { H } } _ { 6 }$ correction is applied.

The isotopic signature is determined with the Miller–Tans approach and the York fitting method. During 21 field campaigns the mean $\delta ^ { 1 3 } \mathrm { C H } _ { 4 }$ signatures of three dairy farms $( - 6 3 . 9 \pm 0 . 9 \% o )$ , a biogas plant $( - 6 2 . 4 \pm 1 . 2 \% o )$ , a landfill $( - 5 8 . 7 \pm 3 . 3 \% o )$ , a wastewater treatment plant $( - 5 2 . 5 \pm$ $1 . 4 \text{‰}$ , an active deep coal mine $( - 5 6 . 0 \pm 2 . 3 \% o )$ and two natural gas storage and gas compressor stations $( - 4 6 . 1 \pm$ $0 . 8 \text{‰}$ ) were recorded.

In addition, between December 2016 and November 2018 gas samples from the Heidelberg natural gas distribution network were measured with a mean $\delta ^ { 1 3 } \mathrm { C H } _ { 4 }$ value of $- 4 3 . 3 \pm$ $0 . 8 \text{‰}$ . Contrary to previous measurements between 1991 and 1996 by Levin et al. (1999), no strong seasonal cycle is shown.

# 1 Introduction

Methane $\mathrm { ( C H _ { 4 } ) }$ ) is the second most important anthropogenic greenhouse gas. The atmospheric growth rate of $\mathrm { C H } _ { 4 }$ has changed significantly during the last decades, stabilising at zero growth from 1999 to 2006 before beginning to increase again after 2007 (Dlugokencky et al., 2009). Several studies have focused on the recent $\mathrm { C H } _ { 4 }$ growth caused by changes in sources and sinks (Rigby et al., 2017; Turner et al., 2017).

Recent studies by Schaefer et al. (2016), Rice et al. (2016) and Nisbet et al. (2016) have shown how the $\delta ^ { 1 3 } \mathrm { C H } _ { 4 }$ measurements can help to understand the changes in global $\mathrm { C H } _ { 4 }$ increase rates and to assign the related source types. The stable carbon isotope ratio ${ \big ( } ^ { 1 3 } \mathbf { C } / ^ { 1 2 } \mathbf { C } { \big ) }$ of $\mathrm { C H } _ { 4 }$ sources varies due to the initial source material and the fractionation during production and release to the atmosphere. The source categories can be classified as pyrogenic (e.g. biomass burning), biogenic (e.g. wetlands and livestock) or thermogenic (e.g. a subcategory of fossil fuel extraction), which show different but also overlapping isotope ratio ranges. Various studies have shown that the assignment of isotopic signatures from different $\mathrm { C H } _ { 4 }$ sources remains uncertain due to large temporal variabilities and also regional specificities (e.g. Sherwood et al., 2017). This missing knowledge may result in large uncertainties when the $\mathrm { C H } _ { 4 }$ budget is determined on global or regional scales using isotope-based estimates. In addition to global studies, the use of $\bar { \delta } ^ { 1 3 } \mathrm { C H } _ { 4 }$ was already successfully applied by Levin et al. (1999) in Heidelberg or Lowry et al. (2001) in London. The study by Levin et al. (1999) showed the $\mathrm { C H } _ { 4 }$ emission reduction in the catchment area of Heidelberg, which was accompanied by a significant change in the $\delta ^ { 1 3 } \mathrm { C H } _ { 4 }$ source mixture from $- 4 7 . 4 \text{‰}$ in 1992 to $- 5 2 . 9 \text{‰}$ in 1995/1996. Both were explained by decreasing contributions from fossil sources, mainly coal mining.

In order to apply $\delta ^ { 1 3 } \mathrm { C H } _ { 4 }$ in regional models, a better knowledge of the regional source signature of each $\mathrm { C H } _ { 4 }$ source type is needed, taking into account the temporal variations in these sources. For instance, due to its origin the source signature of natural gas in Germany varies between $- 5 5 \%$ and $- 3 0 \%$ for Russia or the North Sea respectively (Levin et al., 1999). In addition to seasonal variations, changes in landfill managements like gas collector systems and the implementation of biogas plants at many farms need to be taken into account for a new study of the global and regional source signature of $\mathrm { C H } _ { 4 }$ .

Traditionally, the isotopic ratio of $\mathrm { C H } _ { 4 }$ has been measured with isotope ratio mass spectrometry (IRMS) coupled with gas chromatography (GC) (Fisher et al., 2006) and this technique is still the most precise, as shown by Röckmann et al. (2016) by a comparison of dual isotope mass spectrometry, quantum cascade laser absorption spectroscopy (QCLAS), and cavity ring-down spectroscopy (CRDS). Instrumental development in measurement technique now allows isotope analysis of $\delta ^ { 1 3 } \mathrm { C H } _ { 4 }$ by a CRDS analyser and even its use on a mobile platform (Rella et al., 2015; Lopez et al., 2017). This is a further improvement to the study of Zazzeri et al. (2015), which involved collecting air samples in bags and analysing them later in the laboratory by IRMS. The studies of Rella et al. (2015) and Assan et al. (2017) demonstrated the importance of a careful determination of cross sensitivities and a good calibration strategy for precise isotope measurements with a CRDS analyser.

In this paper, a strategy to monitor and determine the isotopic carbon source signature of major $\mathrm { C H } _ { 4 }$ sources in Germany using mobile measurements is presented. One major aspect is a careful characterisation of the CRDS analyser to take into account the cross sensitivity between $\delta ^ { 1 3 } \mathrm { C } \dot { \mathrm { H } } _ { 4 }$ and other components like water vapour and ethane $\mathrm { ( C _ { 2 } H _ { 6 } ) }$ and to improve the use of a storage tube, for later reanalysis, described by Rella et al. (2015). During 21 mobile measurement days, emission plumes from a biogas plant, three dairy farms, a landfill, a wastewater treatment plant, two natural gas facilities and a bituminous deep coal mine were measured with our set-up.

# 2 Methods

# 2.1 Experimental set-up

The core component of our experimental set-up is the commercially available cavity ring-down spectrometer G2201-i (Picarro, Inc., Santa Clara, CA), which routinely measures the mole fraction of $^ { 1 2 } { \bf C } { \bf O } _ { 2 }$ , $^ { 1 3 } { \bf C } { \bf O } _ { 2 }$ , $^ { 1 2 } \mathrm { C H } _ { 4 }$ , $^ { 1 3 } \mathrm { C } \dot { \mathrm { H } _ { 4 } }$ and $_ { \mathrm { H } _ { 2 } \mathrm { O } }$ in an air sample. In addition to the raw spectroscopic measurements, the analyser automatically calculates and outputs the carbon isotopic ratios $\delta ^ { 1 3 } \mathrm { C H } _ { 4 }$ and $\delta ^ { 1 3 } \mathrm { C O } _ { 2 }$ . Furthermore, the mole fraction of ${ \mathrm { C } } _ { 2 } { \mathrm { H } } _ { 6 }$ is measured as an additional feature, which had to be investigated and calibrated for our analyser. All measurements with the CRDS analyser were done in the combined $\mathrm { C O } _ { 2 } / \mathrm { C H } _ { 4 }$ mode to measure $\mathrm { C H } _ { 4 }$ and $\mathrm { C O } _ { 2 }$ in parallel. In addition, the High Precision (HP) mode for $\mathrm { C H } _ { 4 }$ is chosen to provide the most precise $\mathrm { C H } _ { 4 }$ and $\delta ^ { 1 3 } \mathrm { C H } _ { 4 }$ measurements for $\mathrm { C H } _ { 4 }$ mole fractions up to $1 2 \mathrm { p p m }$ . A more detailed description of this type of CRDS analyser can be found in Rella et al. (2015). Two different set-ups are used in this study: a laboratory set-up for sample bag analysis and test series and a mobile configuration in a vehicle.

# 2.1.1 Laboratory set-up

In the laboratory in Heidelberg the analyser continuously measures ambient air alternating with regular calibration gas and quality control gas injections (Dinger, 2014). In addition, diluted samples from different $\mathrm { C H } _ { 4 }$ sources and gas cylinders can be measured and calibrated. The mobile measurements are also calibrated using the immediate calibration runs in the laboratory before and after a mobile campaign.

The schematic of the laboratory set-up is shown in Fig. 1a. A 16-port rotary valve (model: EMT2CSD16UWE, Valco Vici, Switzerland) can be switched automatically by the analyser to change between different measurements. Ambient air is measured at port 1. Ports 3, 7 and 15 are reserved for calibration and quality control measurements. Sample bags are measured on ports 11 or 13. The gas flow to the analyser is typically 25 to $3 5 \mathrm { m L } \mathrm { m i n } ^ { - 1 }$ for calibration gas, target gas and sample bag measurements. For some applications like ambient air measurements, the flow is higher with values of around $8 0 \mathrm { m L } \mathrm { m i n } ^ { - 1 }$ to resolve shorter temporal variabilities. The flow is measured by an electronic flowmeter (model: 5067-0223, Agilent Technologies, Inc., Santa Clara, CA) before entering the analyser.

Gas samples taken directly from different installations (e.g. natural gas pipelines, biogas plants, gas collecting systems of landfills and wastewater treatment plants) need to be diluted before the measurement with the CRDS analyser because such samples usually consist of between $50 \%$ and $90 \%$ $\mathrm { C H } _ { 4 }$ . Therefore, approximately $4 0 { \mu \mathrm { L } }$ of the sample was injected into a $^ { 3 \mathrm { L } }$ bag (Tedlar® with polypropylene valve with septum, Restek GmbH, Bad Homburg, Germany) filled with synthetic air $( 2 0 . 5 \pm 0 . 5 \%$ ${ \bf O } _ { 2 }$ in ${ \Nu } _ { 2 }$ ) to dilute the $\mathrm { C H } _ { 4 }$ mole fraction to approximately $1 0 \mathrm { p p m }$ in the new sample bag. Due to cross sensitivity with water vapour, these gas samples were dried using a cooling trap below a mole fraction of $0 . 0 0 1 5 \%$ water vapour prior to analysis. Each diluted sample was measured for $1 5 \mathrm { { m i n } }$ . However, only the last $1 0 \mathrm { { m i n } }$ were used to take into account 5 min stabilisation time.

# 2.1.2 Mobile measurement set-up

For mobile measurements the CRDS analyser is installed inside a vehicle and measures air while driving. The system consists of the CRDS analyser, a Nafion dryer and a storage tube, the so-called AirCore (Karion et al., 2010), which enables us to remeasure the stored air from the last $2 \mathrm { m i n }$ of continuous measurement (Fig. 1b). The AirCore was built after Rella et al. (2015) using a $2 5 \mathrm { m }$ Decabon tubing with an inner diameter of $9 . 5 \mathrm { m m }$ and a volume of $1 . 7 7 \mathrm { L }$ (Yeman, 2015). The set-up of the Nafion dryer is similar to the one built by Welp et al. (2013) using a Perma Pure MD-070-96- S Nafion dryer and a vacuum pump. The CRDS device and the vacuum pumps are powered by a portable power source (260 Ah deep-cycle battery, Winnerbatterien Germany) and a $1 0 0 0 \mathrm { W }$ inverter (e-ast HighPowerSinus HPLS 1000-12) which offers $2 3 0 \mathrm { V }$ output), which allows for over $1 2 \mathrm { h }$ of measurement time.

The ambient air enters the air intake line $2 0 \mathrm { c m }$ above the vehicle roof. It can follow two different paths to the analyser depending on the valve positions. In the “monitoring mode”, indicated by blue arrows in Fig. 1b, the ambient air enters the CRDS analyser after the air is dried with the Nafion dryer to a mole fraction of less than $0 . 1 \%$ water vapour. Simultaneously, a second split-off flow leads the ambient air through the AirCore. Due to the length of the intake line, the volume of the cavity and a flow rate of $1 6 0 \mathrm { m L } \mathrm { m i n } ^ { - 1 }$ the time lag between air sampling at inlet and measurement in the cavity of the CRDS analyser is 20 to $2 5 \mathrm { s }$ .

The vehicle usually passes an emission plume of a $\mathrm { C H } _ { 4 }$ source within 40 s and the analyser records approximately 10 data points per $\mathrm { C H } _ { 4 }$ peak. To achieve higher time resolution and accuracy for $\delta ^ { 1 3 } \mathrm { C H } _ { 4 }$ analysis, it is possible to remeasure $\mathrm { C H } _ { 4 }$ peaks by analysing the air stored in the AirCore with the “replay mode” by switching the valves manually. This enables us to remeasure the stored air that contains the sampled $\mathrm { C H } _ { 4 }$ peak. The average analysis time is then $4 . 5 \mathrm { { m i n } }$ corresponding to approximately 70 data points, and thus the measurement in replay mode has a higher time resolution than the one in monitoring mode.

In Fig. 2a and b a typical mobile measurement of a plume from a biogas plant close to Heidelberg (Germany) is shown for $\mathrm { C H } _ { 4 }$ mole fractions and $\delta ^ { 1 3 } \mathrm { C H } _ { 4 }$ values. The vertical black line indicates the switching from monitoring mode to replay mode. The small dots represent the reported data in monitoring (blue) and replay (black) mode, logged approximately every $3 . 7 \mathrm { s }$ , while the red lines show the 15 s averages in replay mode. For comparison the peak measured in monitoring mode (blue dots/line in a and b) is stretched by a factor of 12.5 in the $x$ direction (blue line c and d) so that the peak measured with the AirCore and the stretched one measured without it have the same width. The peak measured in replay mode precisely corresponds to the stretched one measured in monitoring mode because both peaks reproduce the same emission plume. This differs from the AirCore measurements performed by Lopez et al. (2017), which show higher $\mathrm { C H } _ { 4 }$ mole fractions in replay than in monitoring mode.

During the mobile measurements the vehicle position was recorded by a GPS mouse (Navilock 602u) with an accuracy of $2 \mathrm { m }$ CEP (circullar error probable). A weather station (Vantage $\mathrm { P r o } 2 ^ { \mathrm { T M } }$ , Davis Instruments) was set up near the measurement site to record the wind speed and direction, the temperature, and the incident solar radiation.

# 2.2 Characterisation of the CRDS analyser G2201-i

# 2.2.1 Correcting the measured $\delta ^ { 1 3 } \mathrm { C H } _ { 4 }$ values

With regard to the publications of Rella et al. (2015) and Assan et al. (2017), our main focus during the instrumental characterisation was on $\delta ^ { 1 3 } \mathrm { C H } _ { 4 }$ . The cross sensitivities of $_ { \mathrm { H } _ { 2 } \mathrm { O } }$ , $\mathrm { C H } _ { 4 }$ , $\mathrm { C O } _ { 2 }$ and ${ \mathrm { C } } _ { 2 } { \mathrm { H } } _ { 6 }$ mole fractions to $\delta ^ { 1 3 } \mathrm { C H } _ { 4 }$ were investigated to determine correction factors. The correction factors subsequently applied in this study are summarised in Table 1. The correction scheme is sketched in Fig. 3 and described in more detail in Hoheisel (2017). The $_ { \mathrm { H } _ { 2 } \mathrm { O } }$ interference on $\delta ^ { 1 3 } \mathrm { C H } _ { 4 }$ was tested by carrying out several humidity tests (Fig. S1 in the Supplement). For this purpose, two dry compressed air gases with gas mixtures of $2 . 3 \mathrm { p p m }$ and $1 0 . 1 \mathrm { p p m } \mathrm { C H } _ { 4 }$ were humidified by flushing them through a reversed glass condensation trap kept at room temperature and filled with one droplet of deionised water. Due to evaporation of the water droplet, the humidity of the gas passing the condensation trap changed with time between $1 . 5 \%$ and $0 \%$ water vapour. Rella et al. (2015) recommended a reduction in the humidity below a mole fraction of $0 . 1 \%$ water vapour for accurate $\delta ^ { 1 3 } \mathrm { C H } _ { 4 }$ results. Our tests confirm this recommendation for humidity levels below $0 . 1 5 \%$ but observed a significant cross sensitivity of $0 . 5 4 { \pm } 0 . 2 9 ( \mathcal { H } _ { o o } \delta ^ { 1 3 } \mathbf { C H } _ { 4 } ) ( \mathcal { H } _ { } \mathbf { H } _ { 2 } \mathbf { O } ) ^ { - 1 }$ for humidity levels above $0 . 1 5 \%$ . To reduce possible uncertainties due to humidity correction, the air was dried with a Nafion dryer below a mole fraction of $0 . 1 \%$ water vapour during mobile measurement. However, the Nafion drying unit was not installed until September 2016, so the measurements before this date were corrected.

Additionally, the cross sensitivities of $\mathrm { C H } _ { 4 }$ and $\mathrm { C O } _ { 2 }$ on $\delta ^ { 1 3 } \mathrm { C H } _ { 4 }$ were tested (Figs. S2 and S3). Two dilution tests were carried out, generating different gas mixtures. Previous studies from Rella et al. (2015) and Assan et al. (2017) have reported higher $\delta ^ { 1 3 } \mathrm { C H } _ { 4 }$ results when the gas sample contains ${ \mathrm { C } } _ { 2 } { \mathrm { H } } _ { 6 }$ . As typical natural gases in the pipeline network in Germany contain between $1 . 4 \mathrm { M o l } \%$ and $7 M o l \%$ of ${ \mathrm { C } } _ { 2 } { \mathrm { H } } _ { 6 }$ (Nitschke-Kowsky et al., 2012), the ${ \mathrm { C } } _ { 2 } { \mathrm { H } } _ { 6 }$ interference is especially important when analysing $\mathrm { C H } _ { 4 }$ emissions from natural gas facilities or the isotopic composition of natural gas. The ${ \mathrm { C } } _ { 2 } { \mathrm { H } } _ { 6 }$ interference on $\delta ^ { 1 3 } \mathrm { C H } _ { 4 }$ measurements was carefully tested with our analyser by carrying out three dilution tests, to determine a correction (Fig. S4). $\delta ^ { 1 3 } \mathrm { C H } _ { 4 }$ increases linearly with an increasing ${ \mathrm { C } } _ { 2 } { \mathrm { H } } _ { 6 }$ -to- $\mathrm { . C H _ { 4 } }$ ratio. The slope of the regression line and thus the correction factor was found to be $4 0 . 8 7 \pm 0 . 4 9 \% o$ $\mathrm { ( p p m C H } _ { 4 } ,$ ) $\mathrm { ( p p m C _ { 2 } H _ { 6 } ) ^ { - 1 } }$ . A correction is necessary because for typical ${ \mathrm { C } } _ { 2 } { \mathrm { H } } _ { 6 }$ -to- $\mathrm { C H } _ { 4 }$ ratios between 0.027 and 0.073 measured for our natural gas samples, $\delta ^ { 1 3 } \mathrm { C H } _ { 4 }$ shows a bias between $1 \text{‰}$ and $3 \text{‰}$ to more enriched values. We must also keep in mind that similar shifts in $\delta ^ { 1 3 } \mathrm { C H } _ { 4 }$ to less enriched values can occur when using a calibration cylinder which contains ${ \mathrm { C } } _ { 2 } { \mathrm { H } } _ { 6 }$ .

# 2.2.3 Calibration to international scales

All calibration gases used in this study are compressed air filled in aluminium cylinders. The $\mathrm { C H } _ { 4 }$ and $\mathrm { C O } _ { 2 }$ mole fractions were calibrated against the WMO scale (Dlugokencky et al., 2005) using a GC system (Levin et al., 1999). To determine the $\delta ^ { 1 3 } \mathrm { C H } _ { 4 }$ values, flasks filled from our calibration gases were analysed at Max Planck Institute (MPI) for Biogeochemistry in Jena $\delta ^ { 1 3 } \mathrm { C H } _ { 4 }$ : $\pm 0 . 0 5 \text{‰}$ ). These analyses connect our Heidelberg measurements to the VPDB (Vienna Pee Dee Belemnite) isotope scale (Sperlich et al., 2016). ${ \mathrm { C } } _ { 2 } { \mathrm { H } } _ { 6 }$ is not yet calibrated to an international scale. One calibration cylinder filled by Deuste-Steininger (Mühlhausen, Germany) with $4 . 9 8 \mathrm { p p m } \mathrm { C } _ { 2 } \mathrm { H } _ { 6 }$ is certified by this company with an uncertainty of $\pm 2 \%$ .

All data measured with the CRDS analyser in the laboratory or during mobile campaigns were corrected using the factors from Table 1 and following Fig. 3 prior to the onepoint calibration calculation.

The gas cylinder used for calibration was chosen according to the experiment to ensure a similar composition and similar mole fractions for sample and standard. For ambient air measurements in the laboratory and for mobile measurements a gas cylinder filled with compressed air is used to calibrate the data. For diluted gas samples from $\mathrm { C H } _ { 4 }$ sources a gas cylinder with atmospheric mole fractions spiked with natural gas to $1 0 \mathrm { p p m } \mathrm { C H } _ { 4 }$ is used. The calibration gas is measured before and after every experiment/field campaign in the laboratory or in the vehicle. Tests at the beginning of this study showed that measurements of the calibration gas inside the vehicle do not increase the precision and are therefore not necessary for mobile measurements of less than $1 0 \mathrm { h }$ . To take into account possible drifts during the measurement, we determined the time function of the standard $( \delta ^ { 1 3 } \mathrm { C H } _ { 4 _ { \mathrm { S t a n d a r d } } } )$ , used in the one-point calibration, for each measuring point with a linear interpolation between the two calibration measurements.

# 2.2.4 Instrument performance and uncertainties

The repeatability of the analyser as a function of the $\mathrm { C H } _ { 4 }$ mole fraction was determined by the measurement of three different gas cylinders for $1 2 0 \mathrm { m i n }$ each. The Allan variance (Werle et al., 1993) was calculated with the raw data for averaging times of up to $1 5 \mathrm { { m i n } }$ (Fig. 4). The Allan standard deviation $\sigma$ (the square root of the Allan variance $\sigma ^ { 2 }$ ) for the raw (3.7 s) $\mathrm { C H } _ { 4 }$ data is between 0.34 and $2 . 6 9 \mathrm { p p b }$ for gases with a $\mathrm { C H } _ { 4 }$ mole fraction of 1900 to $1 0 0 0 0 \mathrm { p p b }$ . For the corresponding $\delta ^ { 1 3 } \mathrm { C H } _ { 4 }$ data, an improvement of the Allan standard deviation with a higher $\mathrm { C H } _ { 4 }$ mole fraction from $3 . 7 6 \text{‰}$ to $0 . 7 7 \text{‰}$ can be seen. The Allan standard deviation of ${ \mathrm { C } } _ { 2 } { \mathrm { H } } _ { 6 }$ is approximately $0 . 0 9 \mathrm { p p m }$ for gases with ${ \mathrm { C } } _ { 2 } { \mathrm { H } } _ { 6 }$ mole fractions up to $5 \mathrm { p p m }$ .

During mobile measurements especially, $\mathrm { C H } _ { 4 }$ and $\delta ^ { 1 3 } \mathrm { C H } _ { 4 }$ show rapid changes when driving through the emission plume of a $\mathrm { C H } _ { 4 }$ source and thus do not allow us to average the data over long time periods. However, for sample measurements in the laboratory (e.g. natural gas samples) longer averaging times of up to 10 or $1 5 \mathrm { { m i n } }$ significantly decrease the Allan standard deviation (see Fig. 4). For a $1 0 \mathrm { { m i n } }$ averaging period, the Allan standard deviation of $1 9 0 0 \mathrm { p p b }$ or $1 0 0 0 0 \mathrm { p p b C H } _ { 4 }$ decreases to values of 0.09 and $0 . 4 7 \mathrm { p p b }$ and for $\delta ^ { 1 3 } \mathrm { { C H } _ { 4 } }$ to values of $0 . 4 0 \text{‰}$ and $0 . 0 6 \text{‰}$ . The Allan standard deviation of ${ \mathrm { C } } _ { 2 } { \mathrm { H } } _ { 6 }$ decreases to $0 . 0 0 6 \mathrm { p p m }$ . Due to the correction and calibration of $\delta ^ { 1 3 } \mathrm { C H } _ { 4 }$ , there is a relative increase in the uncertainty in $\delta ^ { 1 3 } \mathrm { C H } _ { 4 }$ of approximately 3 to $12 \%$ for $_ { \mathrm { H } _ { 2 } \mathrm { O } }$ mole fractions below $1 . 3 \%$ and atmospheric $\mathrm { C H } _ { 4 }$ mole fractions.

# 2.3.1 Gas samples from natural gas distribution network

Between December 2016 and November 2018, gas samples from the Heidelberg natural gas distribution network were collected two to three times a month from the glass blowing workshop at the university campus in $1 \mathrm { L }$ sample bags (Tedlar® with polypropylene valve with septum, Restek GmbH, Bad Homburg, Germany).

# 2.3.2 Determination of $\delta ^ { 1 3 } \mathrm { C H } _ { 4 }$ source signatures from mobile plume measurements

For mobile measurements the CRDS analyser is installed inside a vehicle and measurements are carried out as described in Sect. 2.1.2. The $\delta ^ { 1 3 } \mathrm { C H } _ { 4 }$ signature of the $\mathrm { C H } _ { 4 }$ sources were determined by the Miller–Tans approach (Miller and Tans, 2003) using the non-averaged data measured in replay mode with the AirCore. To fit a linear regression line to the data, the York fit (York et al., 2004) was used as recommended also by Wehr and Saleska (2017). York’s solution is the general least-squares estimation solution, providing the best possible, unbiased estimates of the true intercept and slope in all cases where the points are independent and the errors are normally distributed (Wehr and Saleska, 2017). Because the York fit allows errors in $x$ and $y$ , it also accounts for the finding that the analyser can measure $\delta ^ { 1 3 } \mathrm { C H } _ { 4 }$ more accurately at higher $\mathrm { C H } _ { 4 }$ mole fractions. The errors for $\mathrm { C H } _ { 4 }$ and $\delta ^ { 1 3 } \mathrm { { C H } _ { 4 } }$ for different mole fractions were determined with the Allan standard deviation.

For accurate results the following criteria are used to select 79 AirCore measurements out of 135. Only $\delta ^ { 1 3 } \mathrm { C H } _ { 4 }$ signatures with fit uncertainties lower than $5 \text{‰}$ are used. The number of data points and especially the peak height above background mole fraction control the uncertainty in the determined isotopic signature when applying a Miller–Tans plot; therefore, only plume measurements with peak heights above background mole fraction higher than $0 . 4 5 \mathrm { p p m }$ and more than 25 data points fulfil this criterion. Furthermore, in some cases the reported ${ \mathrm { C } } _ { 2 } { \mathrm { H } } _ { 6 }$ mole fraction jumps while driving although there cannot be a change in the ${ \mathrm { C } } _ { 2 } { \mathrm { H } } _ { 6 }$ mole fraction of the ambient air. These jumps in ${ \mathrm { C } } _ { 2 } { \mathrm { H } } _ { 6 }$ also results in $\delta ^ { 1 3 } \mathrm { C H } _ { 4 }$ jumps. Therefore, all AirCore measurements with a sudden change in ${ \mathrm { C } } _ { 2 } { \mathrm { H } } _ { 6 }$ larger than $1 \mathrm { p p m }$ were neglected. With these criteria the isotopic signature of a $\mathrm { C H } _ { 4 }$ source determined from one AirCore plume measurement has an average fit uncertainty of $1 . 8 \pm 1 . 3 \% o$ .

# 2.3.3 Comparison of different methods to determine $\delta ^ { 1 3 } \mathrm { C } \mathbf { \bar { H } } _ { 4 }$ source signatures

In order to define the optimal method for the determination of the source signature, the 135 AirCore measurements as well as simulated data were used. In the following the differences in the $\delta ^ { 1 3 } \mathrm { C H } _ { 4 }$ source signature when using the Keeling method or the Miller–Tans approach (Keeling, 1958; Miller and Tans, 2003) will be discussed and the York fit will be compared to the ordinary least squares (OLS) fit (here the $\mathrm { l m } ( )$ fit function from R is used).

Similarly to the method described by Wehr and Saleska (2017) for $\mathrm { C O } _ { 2 }$ and $\delta ^ { 1 3 } \mathrm { C O } _ { 2 }$ , we create several typical emission plume crossings. We generated synthetic $\mathrm { C H } _ { 4 }$ peaks using a background mole fraction of $1 . 9 5 \mathrm { p p m C H } _ { 4 }$ and a Gaussian curve with 10–280 equidistant data points every $3 . 7 \mathrm { s }$ and an enhancement of $1 0 0 { - } 1 0 0 0 0 \mathrm { p p b }$ . The corresponding $\delta ^ { 1 3 } \mathrm { C H } _ { 4 }$ values were calculated with $\mathrm { C H } _ { 4 }$ source signatures between $- 3 5 \text{‰}$ and $- 6 5 \text{‰}$ and a background of $- 4 8 \text{‰}$ . To reproduce the statistical uncertainties of a real measurement, we add a normally distributed scattering around zero to the synthetic $\mathrm { C H } _ { 4 }$ mole fractions and the corresponding isotope ratios. The standard deviation of the normally distributed scattering depends on the $\mathrm { C H } _ { 4 }$ mole fractions and was chosen as the Allan standard deviation measured for raw data of the analyser. However, when simulating possible improved analysers, we reduced the scattering by a factor 2 to 10. Such sets of data were generated 5000 times for each condition. To study the influence of the averaging time, we calculate mean data sets with varying averaging periods (up to $1 \mathrm { m i n }$ ). For each data set the $\delta ^ { 1 3 } \mathrm { C H } _ { 4 }$ source signature was calculated with the Miller–Tans and the Keeling method using the York or the OLS fit.

For the York fit the $\delta ^ { 1 3 } \mathrm { C H } _ { 4 }$ source signature determined using the Miller–Tans approach is identical within the relevant order of magnitude to the one calculated using the Keeling method. This can be shown for the AirCore measurements and is confirmed by our simulations. Figure 2 shows an example of the Keeling plot (panel c) and the Miller–Tans plot (panel d) used to calculate the isotopic signature of the corresponding $\mathrm { C H } _ { 4 }$ source.

The $\delta ^ { 1 3 } \mathrm { C H } _ { 4 }$ signature calculated with the simple OLS fit from the AirCore measurements differ between $- 2 \text{‰}$ and $2 \text{‰}$ depending on the method which is used (Miller–Tans or Keeling method). This finding is in agreement with the simulated results.

Comparing the isotopic source signatures of $\mathrm { C H } _ { 4 }$ from the AirCore measurements resulting from York and the OLS fit in approximately $90 \%$ of the measurements the result of the York fit lies in between the results from the OLS with the Miller–Tans and the Keeling method. This agrees well with our simulated results, where the value of the $\bar { \delta } ^ { 1 3 } \mathrm { C H } _ { 4 }$ signature determined with the York fit for peak enhancements between 0.1 and 3 ppm lies between the values calculated for the OLS fit with the Miller–Tans and Keeling method in more than $9 8 . 5 \%$ of the results.

The average values for the 5000 determined isotopic signatures for the York and the OLS (Keeling and Miller–Tans) fit in this study are nearly the same $( < 0 . 0 5 \text{‰}$ for $\mathrm { C H } _ { 4 }$ peaks higher than $0 . 2 \mathrm { p p m }$ ) and have in all three cases significantly larger differences to the true value $( < 0 . 2 \text{‰}$ for $\mathrm { C H } _ { 4 }$ peaks higher than $0 . 2 \mathrm { p p m }$ and $< 0 . 1 \text{‰}$ for $\mathrm { C H } _ { 4 }$ ranges higher than $0 . 6 \mathrm { p p m } )$ than between each other. However, the 5000 individual simulated values for the $\delta ^ { 1 3 } \mathrm { C H } _ { 4 }$ signatures for one condition vary widely around the average and the true value.

Due to the comparisons described above, the York fit and the Miller–Tans approach were chosen to determine the $\delta ^ { 1 3 } \mathrm { C H } _ { 4 }$ source signature in our study. A further characterisation of this method showed that the uncertainty in a single source signature determination depends mainly on three criteria: the $\mathrm { C H } _ { 4 }$ range, the number of data points used for the fit and the precision of the analyser.

The first large limitation for a precise determination of the isotopic source signature is the $\mathrm { C H } _ { 4 }$ mole fraction of the plume above background. The higher the $\mathrm { C H } _ { 4 }$ peak the more accurately the $\delta ^ { 1 3 } \mathrm { C H } _ { 4 }$ signature can be determined. Especially for small $\mathrm { C H } _ { 4 }$ sources, it is important to drive as close as possible to the source to increase the peak height. In Fig. 5 the fit error of the isotopic signature of every AirCore measurement (black dots) is given as a function of $\mathrm { C H } _ { 4 }$ peak height above background. For $\mathrm { C H } _ { 4 }$ enhancements lower than $1 \mathrm { p p m }$ , the uncertainty increases strongly to values higher than $20 \text{‰}$ . The coloured lines show the standard deviation of the 5000 synthetic data with different numbers of data points used for the Miller–Tans approach. The synthetic data agree well with the measured values which were calculated from 25 to 280 data points.

The second parameter which influences the accuracy of the determined $\delta ^ { 1 \bar { 3 } } \mathrm { C H } _ { 4 }$ signature is the number of data points. During measurements, significantly different isotopic signatures were determined using the monitoring (approximately 10 data points) or replay mode with the AirCore (on average approximately 70 data points) (see Fig. 2). The synthetic data confirm that with an increasing number of data points, the uncertainty in the $\delta ^ { 1 3 } \mathrm { C H } _ { 4 }$ signature improves (Fig. 5). The precision can be more than doubled by increasing the number of points from 10 to 70 and more than quadrupled by an increase from 10 to 280. In monitoring mode the number of data points per peak is constrained by the small width of the plume and the driving speed. Therefore, it is important to remeasure the plume using the AirCore to increase the number of data points and thus the precision of the determined $\delta ^ { 1 3 } \mathrm { C H } _ { 4 }$ signature.

The third limitation of the accuracy of the determined source signature is the measurement precision of the instrument for raw (3.7 s) data, especially for $\delta ^ { 1 3 } \mathrm { C H } _ { 4 }$ . The measuring intervals of the plume are short, and thus the $\mathrm { C H } _ { 4 }$ mole fraction and isotopic composition change rapidly, making it impossible to increase the precision through averaging over time periods longer than $1 \mathrm { { m i n } }$ . The value as well as the uncertainty in the isotopic signatures determined from the original and the $1 5 \mathrm { s }$ averaged data from AirCore measurements do not show significant differences using the Keeling or the Miller–Tans approach for the real measurements (see Fig. 2). Moreover, additional tests with synthetic data show that averaging over 7 to $6 0 s$ improves the precision of the measurement but not the source signature determination due to a smaller number of data points. Therefore, the raw non-averaged data from the analyser measured in replay mode were used instead of the averaged ones. The Allan standard variance without averaging for $\delta ^ { 1 3 } \mathrm { C H } _ { 4 }$ is up to $3 . 7 6 \text{‰}$ $( 1 . 9 \mathrm { p p m } \mathrm { C H } _ { 4 } )$ ).

# 3.1 $\delta ^ { 1 3 } \mathrm { C H } _ { 4 }$ from Heidelberg gas distribution network

Between 1991 and 1996 $\delta ^ { 1 3 } \mathrm { C H } _ { 4 }$ measurements of natural gas from the distribution network in Heidelberg were carried out by Glatzel-Mattheier (1997). The measured $\delta ^ { 1 3 } \mathrm { C H } _ { 4 }$ values underlay a strong seasonal variation with $- 3 0 \text{‰}$ i n winter and up to $- 5 0 \text{‰}$ in summer. The annual average was $- 4 0 . 3 \pm 3 . 0 \% o$ (Glatzel-Mattheier, 1997; Levin et al., 1999). The seasonal cycle in the isotopic composition of natural gas in the 1990s was explained by seasonal changes in gas imports, with a larger contribution from Russian gas in summer months and mainly from northern Germany and Scandinavia during winter because the isotopic signature of natural gas differs depending on its formation process and therefore its origin. Natural gas from Siberia has an isotopic signature between $- 4 8 \text{‰}$ and $- 5 4 \text{‰}$ (Cramer et al., 1998) and is thus less enriched than North Sea gas with $\delta ^ { 1 3 } \mathrm { C H } _ { 4 }$ signatures of approximately $- 3 4 \pm 3 \text{‰}$ (Lowry et al., 2001). In the late 1990s the percentage of natural gas from import and domestic production in Germany (BAFA, 2017) varied with the seasons. While in summer 1998 and 1999, approximately $44 \%$ of the natural gas imports in Germany originated from Russia, in winter it was only $25 \%$ to $30 \%$ .

# 3.2 $\mathbf { C _ { 2 } H _ { 6 } }$ -to- $\mathbf { C H _ { 4 } }$ ratio of direct samples and mobile measurements

The ${ \mathrm { C } } _ { 2 } { \mathrm { H } } _ { 6 }$ -to- $\mathrm { C H } _ { 4 }$ ratio of gas samples from the natural gas distribution network in Heidelberg varies between 0.027 and 0.072 with lower ratios in winter $( 0 . 0 4 \pm 0 . 0 1 ) $ and higher ones in summer $( 0 . 0 6 \pm 0 . 0 1 ) $ . This finding can indicate that the percentage of Russian gas is higher in winter than in summer taking into account that Nitschke-Kowsky et al. (2012) reported the ${ \mathrm { C } } _ { 2 } { \mathrm { H } } _ { 6 }$ -to- $\mathrm { C H } _ { 4 }$ ratio for Russian natural gas to be 0.014, while for North Sea gas it is 0.078. Also the isotopic signatures of our natural gas samples support this trend with slightly more depleted values in winter than in summer.

Gas emitted by other $\mathrm { C H } _ { 4 }$ sources like landfills, biogas plants and wastewater treatment plants do not contain ${ \mathrm { C } } _ { 2 } { \mathrm { H } } _ { 6 }$ . The ${ \mathrm { C } } _ { 2 } { \mathrm { H } } _ { 6 }$ -to- $\mathrm { C H } _ { 4 }$ ratio of the gas samples taken directly at the gas collecting systems of these sources is zero within the errors and can be clearly separated from the natural gas samples (see Fig. 7).

The separation due to the ${ \mathrm { C } } _ { 2 } { \mathrm { H } } _ { 6 }$ -to- $\mathrm { C H } _ { 4 }$ ratio works well with direct gas samples but unfortunately not for mobile Air-Core measurements yet. In contrast to the direct sample measurement, in mobile AirCore measurements $\mathrm { C H } _ { 4 }$ and ${ \mathrm { C } } _ { 2 } { \mathrm { H } } _ { 6 }$ emitted by the source are diluted in the background. To determine the ratio, a linear fit of the measured ${ \mathrm { C } } _ { 2 } { \mathrm { H } } _ { 6 }$ mole fraction to the measured $\mathrm { C H } _ { 4 }$ mole fraction is used. However, due to the high uncertainty in the ${ \mathrm { C } } _ { 2 } { \mathrm { H } } _ { 6 }$ measurement without averaging, as is possible for the direct sample measurement, in combination with the very small or non-existent changes in ${ \mathrm { C } } _ { 2 } { \mathrm { H } } _ { 6 }$ , the fit does not provide reasonable data.

# 3.3 $\delta ^ { 1 3 } \mathrm { C H } _ { 4 }$ source signatures from mobile measurements

The $\delta ^ { 1 3 } \mathrm { C H } _ { 4 }$ signature for different $\mathrm { C H } _ { 4 }$ sources (see Fig. 8) are determined from 135 plumes measured over 21 days while using the AirCore. For the evaluation, only 79 Air-Core measurements with peak heights of more than $0 . 4 5 \mathrm { p p m }$ above background and more than 25 data points were selected (see Sect. 2.3.2). During each measurement day, one to five AirCore measurements were carried out at selected $\mathrm { C H } _ { 4 }$ sources, and the determined isotopic source signatures were averaged to daily means. For each source the daily mean values calculated for each visit were averaged (see Fig. 9 and Tables 2 and S1 in the Supplement).

In the following the determined isotopic signatures of $\mathrm { C H } _ { 4 }$ sources will be discussed for every measuring site and be compared with values from other studies and $\delta ^ { \bar { 1 } 3 } \mathrm { C H } _ { 4 }$ signatures measured from gas samples taken at selected measuring sites.

# 3.3.1 Biogas plant

In biogas plants, microbial organisms produce $\mathrm { C H } _ { 4 }$ under anaerobic conditions. The isotopic signature of $\mathrm { C H } _ { 4 }$ in biogas can vary widely due to the substrate, the microbial producers of $\mathrm { C H } _ { 4 }$ and kinetic values like temperature and frequency of feeding (Polag et al., 2015; personal communication Daniela Polag, 2017).

The biogas plant Pfistererhof in Heidelberg has two fermenter tanks. One is fed with a substrate mainly consisting of maize silage and the other predominantly of food waste. Gas samples from both fermenter tanks were taken and measured. The $\delta ^ { 1 3 } \mathrm { C H } _ { 4 }$ signature of the produced biogas was $- 6 1 . 5 \pm 0 . 1 \%$ for the maize-silage tank and $- 6 4 . 1 \pm 0 . 3 \% o$ for the food-waste tank. Therefore, the isotopic source signature determined from the measurement of the $\mathrm { C H } _ { 4 }$ plume is expected to lie between the above-mentioned values because $\mathrm { C H } _ { 4 }$ from both fermenter tanks is mixed downwind of the biogas plant.

Over 10 days, mobile measurements were carried out downwind of the biogas plant between August and December 2016 and in February and March 2017. The maximum $\mathrm { C H } _ { 4 }$ mole fractions of the measured plumes varied between 2.5 and $1 7 \mathrm { p p m }$ . Often multiple peaks were measured while driving through the plume, caused by several sources on the biogas plant. The isotopic signatures of $\mathrm { C H } _ { 4 }$ emitted by the biogas plant were determined from 17 measured plumes. The values varied between $- 5 9 . 0 \text{‰}$ and $- 6 4 . 2 \text{‰}$ with one exception of $- 6 7 . 4 \text{‰}$ , and the average $\delta ^ { 1 3 } \mathrm { C H } _ { 4 }$ was $- 6 2 . 4 \pm 1 . 2 \% o$ . The determined isotopic signatures agree well with the isotopic signatures of the direct samples.

# 3.3.2 Dairy farms

The $\delta ^ { 1 3 } \mathrm { C H } _ { 4 }$ source signature emitted at three dairy farms (in Ladenburg, Weinheim and Kleve) were characterised. The dairy farm in Weinheim holds 320 to 340 dairy cows and the one in Ladenburg holds 80 dairy cows. Haus Riswick in Kleve is an education and research centre of the Agricultural Chamber of North-Rhine Westphalia with 230 dairy cows in conventional livestock farming, 45 dairy cows in organic livestock farming, and more than 200 sheep and calves each. Feeding experiments and emission measurements were carried out (Schiefler, 2013; Schmithausen et al., 2016) in the largest dairy cowshed in Kleve (conventional dairy cowshed).

All three dairy farms have an associated biogas plant. This is not representative of Germany because most dairy farms do not have such a facility. In 2013 there were 285 000 agricultural holdings in Germany, $4 5 . 8 \%$ of them were cattle farms including dairy cow farms. But only $2 . 2 \%$ (6300) of all agricultural holdings had a biogas plant, and thus much less than $5 \%$ of all cattle farms (including dairy cow farms) can have a biogas plant (Agrarstrukturerhebung, 2013).

Levin et al. (1993) showed that the isotopic signature of $\mathrm { C H } _ { 4 }$ produced by cows strongly depends on the diet. Cows with a $100 \%$ C3 $( - 6 5 . 1 \pm 1 . 7 \% o )$ diet emit less enriched $\mathrm { C H } _ { 4 }$ than cows with a $60 \%$ to $80 \%$ C4 diet $( - 5 5 . 6 \pm 1 . 4 \% o )$ . In addition, $\mathrm { C H } _ { 4 }$ emitted by liquid manure has a more depleted isotope ratio of $- 7 3 . 9 \pm 0 . 7 \% o$ .

These AirCore measurements were taken when driving directly across the farm. Therefore, the maximum $\mathrm { C H } _ { 4 }$ mole fractions measured were relatively high with 8.3 to $8 . 9 \mathrm { p p m }$ . The $\delta ^ { 1 3 } \mathrm { C H } _ { 4 }$ signatures varied between $- 6 2 . 6 \text{‰}$ and $- 6 6 . 0 \text{‰}$ with an average of $- 6 4 . 9 \pm 1 . 6 \% o$ . For the 10 other AirCore measurements, $\mathrm { C H } _ { 4 }$ emitted from the cowshed and the biogas plant cannot be separated. The resulting mean isotopic signature is $- 5 4 . 0 \pm 8 . 0 \% o$ spanning a range between $- 4 3 . 1 \text{‰}$ and $- 6 2 . 6 \text{‰}$ . The plumes measured downwind of the dairy farm had $\mathrm { C H } _ { 4 }$ mole fractions between 2.6 and $9 \mathrm { p p m }$ with an average of $4 . 3 \mathrm { p p m }$ .

Next to the dairy farm in Ladenburg, the plumes measured over 6 days between October 2016 and February 2017 most of the time had very small maximum $\mathrm { C H } _ { 4 }$ mole fractions of 2.1 to $2 . 8 \mathrm { p p m }$ (on average $2 . 4 \mathrm { p p m }$ ). As expected, due to fewer animals, the plumes were smaller than the ones measured near the dairy farm in Weinheim although the measurements were carried out closer to the source. Only on 1 day in November 2016 was a $\mathrm { C H } _ { 4 }$ mole fraction of up to $8 \mathrm { p p m }$ measured in the plume. The $\delta ^ { 1 3 } \mathrm { C H } _ { 4 }$ signatures determined from three AirCore measurements taken when driving on the road next to the farm have values of around $- 4 4 . 4 \pm 0 . 8 \% o$ . For these measurements it was not possible to separate between $\mathrm { C H } _ { 4 }$ emitted by the cows and by the biogas plant. To determine the isotopic signature of $\mathrm { C H } _ { 4 }$ from the dairy cows and the cowshed alone, three AirCore measurements of the plume directly on the farm next to the cowshed were taken in October 2016, which had mole fractions up to 4.1 to $7 . 3 \mathrm { p p m }$ . The determined $\delta ^ { 1 3 } \mathrm { C H } _ { 4 }$ source signatures varied between $- 6 1 . 6 \text{‰}$ and $- 6 4 . 0 \text{‰}$ with an average of $- 6 3 . 2 \pm 1 . 4 \% o$ .

In Weinheim as well as in Ladenburg, the $\delta ^ { 1 3 } \mathrm { C H } _ { 4 }$ signature of the whole farm (cowshed and biogas plant) is less depleted than the isotopic signature of the cowshed alone. Further experiments are needed to determine the isotopic signature of the biogas plants on dairy farms and the influence on the plume of the farm in total.

On 24 March 2017, five AirCore plume measurements were taken on the dairy farm in Kleve with maximum $\mathrm { C H } _ { 4 }$ mole fractions between 4.7 and $1 3 . 6 \mathrm { p p m }$ . The weather conditions made it possible to exclude an influence from the biogas plant. Two measurements were taken directly next to both the large cowshed with dairy cows of conventional farming and next to the organic cowsheds. For conventional livestock the determined $\delta ^ { 1 3 } \mathrm { C H } _ { 4 }$ signature is $- 6 4 . 3 \pm 1 . 5 \% o$ and for organic livestock $- 6 4 . 4 \pm 0 . 9 \% o$ . The fifth AirCore measurement was done on the downwind side of the farm $( - 6 1 . 7 \pm 1 . 7 \% o )$ .

The average $\delta ^ { 1 3 } \mathrm { C H } _ { 4 }$ signatures of all three dairy farms match each other and the isotopic signature expected from the results from Levin et al. (1993). It is important to note that the measured $\mathrm { C H } _ { 4 }$ from the plume of cowsheds is a mixture of $\mathrm { C H } _ { 4 }$ emitted by cows and manure.

# 3.3.3 Landfill

In addition to the source material and fractionation during the production the isotopic signature of gas emitted by landfills depends also on fractionation processes in the upper soil layers of the landfill. Due to the presence of oxygen in the upper soil layers, aerobic bacteria oxidise parts of $\mathrm { C H } _ { 4 }$ which diffuses through the soil cover and shift the isotopic composition to more depleted values. Bergamaschi et al. (1998) measured these different isotopic signatures. They determined $\delta ^ { 1 3 } \mathrm { C H } _ { 4 }$ signatures of different sample types from four German and Dutch landfills. For direct gas samples from the gas collecting system, they measured an isotopic signature of $- 5 9 . 0 \pm 2 . 2 \% o$ . Emission samples taken with static chambers at covered areas of the landfill showed, however, more enriched isotopic signatures of $- 4 5 . 9 \pm 8 . 0 \% o .$ . Upwind– downwind measurements of $\mathrm { C H } _ { 4 }$ around the landfill lead to an isotopic signature of $- 5 5 . 4 \pm 1 . 4 \% o$ .

In this study, the isotopic signature of $\mathrm { C H } _ { 4 }$ emitted from a landfill with a disposal area of approximately $1 . 4 5 \mathrm { k m } ^ { 2 }$ which is located near Sinsheim, south-east of Heidelberg, was characterised. From 1978 to 1998 biodegradable domestic waste was deposited there. A degassing system collects the produced biogas, which is used to generate electricity (AVR, 2016). The landfill is covered in large parts by a final surface sealing, and during the measuring period construction work was underway to cover further parts.

Over 10 days from July to November 2016 and in March and July 2017, 26 plume measurements were performed. During this period the $\mathrm { C H } _ { 4 }$ plume was measured twice on the landfill, and the other times, it was measured while driving on a public road next to it. The measured $\mathrm { C H } _ { 4 }$ mole fractions of the plumes downwind of the landfill were relatively small with 2.1 to $2 . 7 \mathrm { p p m }$ . Therefore, the $\delta ^ { 1 3 } \mathrm { C H } _ { 4 }$ signature cannot be determined to a high accuracy. From 18 measured plumes only four can be used to determine the isotopic source signature precisely. The resulting values vary between $- 5 4 . 2 \text{‰}$ and $- 6 2 . 2 \text{‰}$ . No seasonal variations were observed. The average is $- 5 8 . 7 \pm 3 . 3 \% o$ . This result is comparable to the upwind–downwind measurements of $\mathrm { C H } _ { 4 }$ by Bergamaschi et al. (1998) and to the study of Zazzeri et al. (2015) in the

UK with values between $- 5 5 . 2 \pm 0 . 6 \% o$ and $- 6 0 . 2 \pm 1 . 4 \% o$ with an average of $- 5 8 . 0 \pm 3 . 0 ( 2 \mathrm { S D } ) \%$ .

In July 2016 the $\mathrm { C H } _ { 4 }$ mole fraction was measured directly on the landfill. With values of up to $6 { \mathrm { p p m } }$ , the maximum measured mole fraction was higher than the ones measured downwind of the landfill. The average $\delta ^ { 1 3 } \mathrm { C H } _ { 4 }$ signature is $- 6 6 . 5 \pm 2 . 5 \% o$ $- 6 4 . 0$ to $- 6 9 . 3 \text{‰}$ ). Nearly 1 year later, measurements were carried out on the landfill again. With $- 5 9 . 5 \pm 0 . 5 \% o$ $- 5 9 . 9 \text{‰}$ and $- 5 9 . 1 \text{‰}$ , the average $\delta ^ { 1 3 } \mathrm { C H } _ { 4 }$ signature from two AirCore measurements is much more enriched and in good agreement with the measurements next to the landfill. The maximum $\mathrm { C H } _ { 4 }$ mole fractions of the plumes, with values between 2.6 and $7 . 2 \mathrm { p p m }$ , were again higher than the measurements downwind of the landfill.

Direct gas samples from the gas collecting system taken on the same day in July 2017 have an average isotopic signature of $\mathrm { C H } _ { 4 }$ of $- 5 9 . 5 \pm 0 . 1 \%$ . This value matches the isotope ratio of $- 5 9 . 0 \pm 2 . 2 \% o$ reported by Bergamaschi et al. (1998) for direct samples from the gas collecting system. Like Bergamaschi et al. (1998) the isotopic signature of $\mathrm { C H } _ { 4 }$ in the gas collecting system is less enriched than the isotope ratio measured in the plume next to the landfill. The isotopic signature of $\mathrm { C H } _ { 4 }$ determined from the plume on the landfill in July 2017 is the same as for the direct gas sample. The large $\mathrm { C H } _ { 4 }$ peaks measured on the landfill seem to originate from the gas collecting system.

As previously mentioned, less enriched $\delta ^ { 1 3 } \mathrm { C H } _ { 4 }$ signatures of $- 6 6 \text{‰}$ were determined from measurements carried out on the landfill in July 2016. Bergamaschi et al. (1998) measured such depleted $\delta ^ { 1 3 } \mathrm { C H } _ { 4 }$ signatures of approximately $- 6 9 \text{‰}$ , too, once for a gas sample from the gas collecting system and in one depth profile measurement. Our measurement may have been influenced by construction work which was underway on the landfill during the whole measurement period.

# 3.3.4 Wastewater treatment plant

Every year approximately 23 million $\mathrm { m } ^ { 3 }$ of wastewater is cleaned in the wastewater treatment plant (WWTP) in Heidelberg. During our field campaigns mobile measurements were carried out next to the southern part. There, the sludge treatment inside the digestion towers takes place in three septic tanks with a volume of $2 5 0 0 \mathrm { m } ^ { 3 }$ each, under anaerobic mesophilic conditions, which means without oxygen at $3 7 ^ { \circ } \mathrm { C }$ . The produced sewage gas consists predominantly of $\mathrm { C H } _ { 4 }$ and is collected to be utilised in a block heating station (Abwasserzweckverband Heidelberg, 2017).

In February 2017 two gas samples of the collected gas were taken from the WWTP and were analysed in the laboratory. The average $\delta ^ { 1 3 } \mathrm { C H } _ { 4 }$ signature of the gas produced in the WWTP is $- 5 1 . 3 \pm 0 . 2 \% o$ . In total, 13 plume measurements next to the WWTP were taken over 5 days in October 2016 to February 2017. The maximum $\mathrm { C H } _ { 4 }$ mole fractions of the plumes varied between 2.4 and $8 . 5 \mathrm { p p m }$ . The isotopic signature for the seven plume measurements used are within the range of $- 4 9 . 4 \text{‰}$ to $- 5 6 . 3 \text{‰}$ with an average of $- 5 2 . 5 \pm 1 . 4 \% o$ . This agrees well with the results of Zazzeri (2016), who reported isotopic signatures of $\mathrm { C H } _ { 4 }$ between $- 4 8 . 1 \text{‰}$ to $- 5 9 . 2 \text{‰}$ for wastewater treatment emissions.

# 3.3.5 Natural gas facilities

Besides the direct sampling of natural gas in Heidelberg (see Sect. 3.1) the plumes at two natural gas facilities were measured to determine the isotopic signature of $\mathrm { C H } _ { 4 }$ from natural gas in the region of Heidelberg. Between July 2016 and March 2017, the $\mathrm { C H } _ { 4 }$ mole fraction around the natural gas storage site in Sandhausen was measured over 10 days. Except for 2 days, the $\mathrm { C H } _ { 4 }$ mole fraction of the plumes was lower than $2 . 1 5 \mathrm { p p m }$ , and four times no significant changes in $\mathrm { C H } _ { 4 }$ could be measured at all. On these 2 days the maximum $\mathrm { C H } _ { 4 }$ mole fraction of the plume was higher with values between 2.3 and $1 0 \mathrm { p p m }$ , so that the isotopic source signature could be determined with the Miller–Tans approach. The resulting $\delta ^ { 1 3 } \mathrm { C H } _ { 4 }$ signature was on average $- 4 5 . 5 \pm 5 . 2 \% o$ and $- 4 1 . 8 \pm 0 . 4 \% o$ (two AirCores) on one day and $- 4 9 . 2 \pm$ $4 . 6 \text{‰}$ (one AirCore) on the other day. The natural gas storage in Sandhausen probably only emitted small amounts of $\mathrm { C H } _ { 4 }$ except during some events, making it difficult to sample.

Between Hähnlein and Gernsheim, a natural gas storage, compressor stations and other natural gas facilities were placed together on one site. Over 5 days between September 2016 and February 2017, mobile measurements were carried out next to this site and showed that natural gas escaped at different locations. Contrary to the natural gas storage in Sandhausen, the measured $\mathrm { C H } _ { 4 }$ plumes had maximum $\mathrm { C H } _ { 4 }$ mole fractions between $2 . 2 \mathrm { p p m }$ and $6 { \mathrm { p p m } }$ , but some plumes even reached 6 to $2 5 \mathrm { p p m }$ . The emissions from these natural gas facilities are not negligible and seem to be highly heterogeneous. The determined $\delta ^ { 1 3 } \mathrm { C H } _ { 4 }$ signature of the $\mathrm { C H } _ { 4 }$ plumes was between $- 4 1 . 1 \text{‰}$ and $- 5 7 . 4 \text{‰}$ . The average was $- 4 6 . 6 \pm 6 . 8 \%$ and thus a little bit less enriched than the isotopic signatures of $\mathrm { C H } _ { 4 }$ measured in Sandhausen and than the natural gas samples taken in Heidelberg $( - 4 3 . 3 \pm 0 . 8 \% o )$ . The location of this natural gas facility may be the explanation for more depleted values because the gas pipeline ME-GAL directly passes this site and has a compressor station there. MEGAL runs from the border of the Czech Republic to France and mainly transports Russian natural gas, which has a more depleted isotopic signature.

# 3.3.6 Coal mines

On 25 March 2017 the emitted $\mathrm { C H } _ { 4 }$ mole fractions from bituminous deep coal mines in Bottrop were measured. In particular, the plume of one closed mine shaft and two that are still in service was measured. In the plume of the closed mine shaft the maximum $\mathrm { C H } _ { 4 }$ mole fraction measured was between 2.2 and $2 . 6 \mathrm { p p m }$ , while for the mine shafts in service mole fractions between 3 and $7 . 5 \mathrm { p p m }$ were detected, although the mobile measurements were carried out much closer to the closed mine shaft. It seems that the $\mathrm { C H } _ { 4 }$ emissions from mine shafts in service are larger than from closed ones. The $\delta ^ { 1 3 } \mathrm { C H } _ { 4 }$ signature of the closed mine shaft is $- 5 0 . 0 \pm 6 . 3 \% o$ while for the active mine shafts the average $\delta ^ { 1 3 } \mathrm { C H } _ { 4 }$ signature is $- 5 6 . 0 \pm 2 . 3 \% o$ $- 5 4 . 7$ to $- 5 9 . 5 \text{‰}$ . However, only one AirCore was measured for the closed mine shaft and the error of the isotopic source signature is larger than our criterion of $5 \text{‰}$ . The determined isotope ratios of $\mathrm { C H } _ { 4 }$ in Bottrop are less depleted than the values of the coal bed gas samples from Bottrop $( - 4 7 . 1 \text{‰}$ to $- 5 2 . 4 \text{‰}$ measured by Thielemann et al. (2004). However, the values are similar to the average isotope ratio of $\mathrm { C H } _ { 4 }$ of $- 5 5 \text{‰}$ measured for $\mathrm { C H } _ { 4 }$ from bituminous coal in deep mines by Zazzeri et al. (2016).

On 23 March 2017 mobile measurements of $\mathrm { C H } _ { 4 }$ were carried out in the area around the lignite opencast mines Hambach and Garzweiler. However, no $\mathrm { C H } _ { 4 }$ emitted directly by the opencast mines could be detected. Around the opencast mine Hambach, the $\mathrm { C H } _ { 4 }$ mole fraction varied only slightly between 1.94 and $1 . 9 8 \mathrm { p p m }$ when we measured upwind as well as downwind of the pit. Therefore, it was not possible to identify an emission peak. High $\mathrm { C H } _ { 4 }$ mole fractions were only measured at two locations next to the opencast pit. However, the two detected $\mathrm { C H } _ { 4 }$ plumes were measured upwind of the opencast mine and thus did not originate from the pit itself, but from the drainage system. The maximum $\mathrm { C H } _ { 4 }$ mole fractions measured were between 3 and $7 . 5 \mathrm { p p m }$ . The $\delta ^ { 1 3 } \mathrm { C H } _ { 4 }$ signature of the measured $\mathrm { C H } _ { 4 }$ is between $- 7 9 . 7 \text{‰}$ and $- 8 4 . 8 \text{‰}$ with an average of $- 8 2 . 0 \pm 2 . 6 \% o$ . These extremely depleted values indicate that the measured $\mathrm { C H } _ { 4 }$ is of microbial origin and thus is probably produced by $\mathrm { C O } _ { 2 }$ reduction similarly to one gas sample measured by Thielemann et al. (2004) with values of $- 8 5 . 1 \text{‰}$ to $- 8 5 . 9 \text{‰}$ .

# 4 Conclusions

We have developed and tested a mobile instrument set-up to determine the $\delta ^ { \bar { 1 } 3 } \mathrm { C H } _ { 4 }$ signature by measuring the plume of different $\mathrm { C H } _ { 4 }$ sources. The advantage of such a mobile application is that measurements can be performed downwind of the emission source and therefore outside of any industrial installation such as a gas compressor station or landfill without the consent of the owners. For accurate results, a carefully characterisation of each individual analyser, especially the cross sensitivities of ${ \mathrm { C } } _ { 2 } { \mathrm { H } } _ { 6 }$ , and the drying of air prior to the measurement is required. To reduce the $_ { \mathrm { H } _ { 2 } \mathrm { O } }$ mole fraction below $0 . 1 \%$ , a Nafion dryer was installed in the mobile set-up and the cross sensitivity between ${ \mathrm { C } } _ { 2 } { \mathrm { H } } _ { 6 }$ and the measurement of $\delta ^ { 1 3 } \mathrm { C H } _ { 4 }$ was corrected as shown in Fig. 3. Especially for natural gas samples, the precise determination and correction of ${ \mathrm { C } } _ { 2 } { \mathrm { H } } _ { 6 }$ is important as in our study ${ \mathrm { C } } _ { 2 } { \mathrm { H } } _ { 6 }$ can bias $\delta ^ { 1 3 } \mathrm { C H } _ { 4 }$ by up to $3 \text{‰}$ depending on the $\mathrm { C H } _ { 4 }$ -to- ${ \mathrm { C } } _ { 2 } { \mathrm { H } } _ { 6 }$ ratio of the sample and the calibration cylinder.

For the precise determination of the isotopic signature of different $\mathrm { C H } _ { 4 }$ sources, we use the Miller–Tans approach together with a York fit for most accurate results. There are three major limitations to the precise determination of the $\delta ^ { 1 3 } \mathrm { C H } _ { 4 }$ source signature: the number of data points during plume crossing, the measured mole fraction enhancement and the precision of the analyser for isotope analysis. The number of data points limits the accuracy as the uncertainty decreases with an increasing number of data points. To enlarge the amount of points, the measurement should be carried out while driving as slowly as possible through the plume and then the plume should be remeasured using the AirCore. It is important to use the AirCore because it is a simple option to reduce the uncertainty by more than half. The most important limitation of the $\delta ^ { 1 3 } \mathrm { C H } _ { 4 }$ source signature is the plume mole fraction above background. Measured plumes with a peak height above background smaller than $0 . 4 5 \mathrm { p p m }$ have uncertainties larger than $5 \text{‰}$ and thus are not used in this study. Driving as close as possible to the source increases the $\mathrm { C H } _ { 4 }$ mole fraction. However, where it is not possible, or the increase is not enough, the isotopic signature of the source cannot be determined with sufficient precision with this method. To get better results even for smaller enhancements, more precise instruments are required in the future.

In this study, the $\delta ^ { 1 3 } \mathrm { C H } _ { 4 }$ signature of $\mathrm { C H } _ { 4 }$ emitted from a biogas plant, a landfill, dairy farms, a wastewater treatment plant, natural gas storage and compressor stations, and bituminous deep mines were determined. The $\delta ^ { 1 3 } \mathrm { C H } _ { 4 }$ signatures measured during mobile campaigns are in good agreement with the measured isotope ratios from direct samples taken at some of the $\mathrm { C H } _ { 4 }$ sources and with values from other studies. Thus, this method provides an opportunity to characterise the $\mathrm { C H } _ { 4 }$ emissions from a source where it is not possible or it is difficult to take direct samples, for example, from an industrial site without the authorisation of the operating company or from a large area where $\mathrm { C H } _ { 4 }$ emits heterogeneously at multiple unknown positions. Gas samples from Heidelberg city gas supply from December 2016 to November 2018 confirm a change in the natural gas mixture, especially of Russian and North Sea gas. In previous years (1991 to 1996) strong seasonal variations in $\delta ^ { 1 3 } \mathrm { C H } _ { 4 }$ were measured, whereas recently the isotopic signature is nearly constant throughout the year. In addition, the average is approximately $3 \text{‰}$ more depleted than in the 1990s.
