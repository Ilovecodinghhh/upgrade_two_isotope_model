Abstract. Radiocarbon ${ } ^ { ( ^ { 1 4 } \mathrm { C ) } }$ is an optimal tracer of methane emissions, as $^ { 1 4 } \mathrm { C }$ measurements enable distinguishing between fossil methane and biogenic methane $\mathrm { ( C H _ { 4 } ) }$ . However, $^ { 1 4 } \mathrm { C }$ measurements in atmospheric methane are still rare, mainly because of the technical challenge of collecting enough carbon for $^ { 1 4 } \mathrm { C }$ analysis from ambient air samples. In this study, we address this challenge by advancing the system in Zazzeri et al. (2021) into a much more compact and portable sampler and by coupling the sampler with the MICADAS (MIni CArbon DAting System) accelerator mass spectrometry (AMS) system at ETH Zurich, using a gas interface.

Here, we present the new sampler setup, the assessment of the system contamination and a first inter-laboratory comparison with LARA (Laboratory for the Analysis of Radiocarbon with AMS) at the University of Bern.

With our sampling line, we achieved a very low blank, $0 . 7 \mu \mathrm { g C }$ compared to $5 . 5 \mu \mathrm { g C }$ in Zazzeri et al. (2021), and a sample precision of $0 . 9 \%$ , comparable with other measurement techniques for $^ { 1 4 } \mathrm { C H } _ { 4 }$ , while reducing the sample size to $6 0 \mathrm { L }$ of air. We show that this technique, with further improvements, will enable routine $^ { 1 4 } \mathrm { C H } _ { 4 }$ measurements in the field for an improved understanding of $\mathrm { C H } _ { 4 }$ sources.

# 1 Introduction

Understanding the methane $\mathrm { ( C H _ { 4 } ) }$ ) budget and identifying methane sources have become a priority to tackle global warming, as methane is the second-most-important anthropogenic greenhouse gas after carbon dioxide $( \mathrm { C O } _ { 2 } )$ and because the dynamics that led to the $\mathrm { C H } _ { 4 }$ increase in the last decade have not been fully unravelled. Tracing $\mathrm { C H } _ { 4 }$ sources and monitoring mitigation strategies are urgently needed.

$^ { 1 4 } \mathrm { C }$ measurements of atmospheric methane can advance our knowledge of methane production processes by differentiating fossil vs. biogenic sources. This is because fossil $\mathrm { C H } _ { 4 }$ is depleted in $^ { 1 4 } \mathrm { C }$ and, when emitted into the atmosphere, exerts a dilution effect on the $^ { 1 4 } \mathrm { C }$ in the atmosphere that can be quantified. However, this research field is still underexplored, as $^ { 1 4 } \mathrm { C }$ measurements of atmospheric methane are challenging.

One of the main challenges is sampling enough air for $^ { 1 4 } \mathrm { C }$ analysis via accelerator mass spectrometry (AMS), as the atmospheric methane concentration is low $( \sim 2 \mathrm { p p m } )$ . Here, we build on recent advances that have been made in the analysis of $^ { 1 4 } \mathrm { C }$ in atmospheric methane. Traditionally, air was collected in pressurized cylinders using high-pressure pumps, followed by an extraction procedure in the laboratory (Eisma et al., 1995; Townsend-Small et al., 2012). Zazzeri et al. (2021) developed a new technique that separates methane carbon from ambient air while sampling, simplifying the transportation of collected samples in a small trap and minimizing the laboratory processing needed. The $F ^ { \bar { 1 4 } } \mathrm C$ measurement precision achieved is between $0 . 5 \%$ and $1 . 2 \%$ , comparable to the best precisions of alternative but more lab-intensive techniques. The laboratory-based system developed by Zazzeri et al. (2021) was applied in the quantification of fossil and biogenic proportions of $\mathrm { C H } _ { 4 }$ in London (Zazzeri et al., 2023). A portable system using a similar technique was demonstrated by Palonen et al. (2017), but in that study they only used samples with enriched methane concentrations of $> 1 0 0 \mathrm { p p m }$ , e.g. for $\mathrm { C H } _ { 4 }$ emissions from wetlands. Another promising recently developed technique applies chromatographic separation of $\mathrm { C H } _ { 4 }$ from air as it requires only $6 0 \mathrm { L }$ of atmospheric air to be sampled in a bag (Espic et al., 2019), still achieving precisions of $1 . 2 \%$ .

In this study, we advance the sensitive though simple methane sampling system in Zazzeri et al. (2021) with the portability of the system by Palonen et al. (2017), requiring as little air as demonstrated by Espic et al. (2019). The result is a compact and portable system that can be deployed in field campaigns. We present the technology advancement and the assessment of the system efficiency by quantifying the amount of extraneous carbon introduced during sample preparation and ultimately the measurement precision to be achieved. We demonstrate the method by comparing $^ { 1 4 } \mathrm { C }$ measurements made by the new portable system at the Laboratory of Ion beam Physics (LIP) at ETH Zurich and by the system using bag sampling and chromatographic separation at the Laboratory for the Analysis of Radiocarbon with AMS (LARA) at the University of Bern.

# 2 Method

# 2.1 The sampling setup

The sampling system is based on four main steps as in Zazzeri et al. (2021): (1) $_ { \mathrm { H } _ { 2 } \mathrm { O } }$ removal with a Nafion dryer, (2) CO and $\mathrm { C O } _ { 2 }$ removal, (3) combustion of $\mathrm { C H } _ { 4 }$ to $\mathrm { C O } _ { 2 }$ and (4) adsorption of the combustion-derived $\mathrm { C O } _ { 2 }$ onto a molecular sieve sample trap. Figure 1 shows the system schematic. Ambient air is sampled through a Nafion dryer (Perma Pure gas dryer, PD-50-24) at up to $5 0 0 \mathrm { c m } ^ { 3 } \operatorname* { m i n } ^ { - 1 }$ with a KNF membrane pump (“Pump $2 ^ { \circ }$ in Fig. 1), controlled by a mass flow controller. The Nafion filter enables reduction of the water content to levels of $0 . 0 1 \%$ (Zazzeri et al., 2021). Downstream of the pump, CO is oxidized to $\mathrm { C O } _ { 2 }$ using the Sofnocat® catalyst before all $\mathrm { C O } _ { 2 }$ (from ambient air and from oxidation of CO) is removed by a trap containing $1 4 \mathrm { g }$ of 13X molecular sieve in $1 \mathrm { m m }$ pellets. This amount of molecular sieve has been found to be sufficient to trap atmospheric $\mathrm { C O } _ { 2 }$ in $\sim 3 0 0 \mathrm { L }$ of air (see Fig. A1). After collection of the three samples, this trap is disconnected from the system via two Swagelok ball valves and then removed and regenerated by heating at $5 0 0 ^ { \circ } \mathrm { C }$ with a high-purity nitrogen back-flush step for at least $^ { 3 \mathrm { h } }$ , in a similar manner as in Zazzeri et al. (2021).

After the sample air passes through the $\mathrm { C O } _ { 2 }$ trap, $\mathrm { C H } _ { 4 }$ is combusted at $8 0 0 ^ { \circ } \mathrm { C }$ in a small furnace comprising a $2 2 \mathrm { c m }$ long quartz tube with $_ { 1 \mathrm { ~ g ~ } }$ of platinized quartz wool (Sigma-Aldrich) acting as catalyst (Petrenko et al., 2008). The $_ { \mathrm { H } _ { 2 } \mathrm { O } }$ derived from the $\mathrm { C H } _ { 4 }$ oxidation is trapped onto a magnesium perchlorate trap ( $\mathrm { ^ { 6 6 } H } _ { 2 } \mathrm { O }$ trap” in Fig. 1), while the $\mathrm { C O } _ { 2 }$ derived from combustion of $\mathrm { C H } _ { 4 }$ is collected on the sample trap (13X, 45–60 mesh) for subsequent $^ { 1 4 } \mathrm { C }$ measurement. A non-dispersive infrared $\mathrm { C O } _ { 2 }$ sensor (NDIR $\mathrm { F L O W } ^ { \mathrm { E V O } }$ from SmartGas) monitors both the completeness of $\mathrm { C O } _ { 2 }$ removal from air prior to methane combustion and the completeness of $\mathrm { C O } _ { 2 }$ collection on the sample trap. If regularly calibrated and run at constant temperature and pressure, the sensor can measure $\mathrm { C O } _ { 2 }$ concentrations in a range of 0 to $1 0 0 \mathrm { p p m }$ with a precision of $\pm 1 \mathrm { p p m }$ . The sample trap, minimized in size for low cross contamination, can be cooled with Peltier coolers to maximize trapping efficiency and avoid sample loss.

The whole system runs either on 115/230 V AC or $4 8 \mathrm { V }$ DC provided by a battery pack. Two 72 V 30 Ah (2160 Wh) lithium batteries are sufficient to run the sampling system for $1 0 \mathrm { h }$ .

# 2.2 Sample trap and cooling system

The sample trap consists of $0 . 2 5 0 \mathrm { g }$ of 13X 45–60 mesh molecular sieve packed in a $4 \mathrm { c m }$ long 1/4 in. o.d. stainlesssteel tube. The trap tube is welded to stainless-steel capillary tubing and attached to a VICI 4-port valve which can be disconnected from the sampling system (Fig. 1b) in order to release the sample for $^ { 1 4 } \mathrm { C }$ analysis in the AMS. Before its first use, the sample trap is heated gradually to $6 5 0 ^ { \circ } \mathrm { C }$ in a customized oven while flushing with high-purity nitrogen. The NDIR FLOWEVO $\mathrm { C O } _ { 2 }$ sensor is used to check when the trap is not releasing $\mathrm { C O } _ { 2 }$ anymore and does not contain any residual carbon, typically after $^ { 1 \mathrm { h } }$ . During sampling, the sample trap is cooled down to $- 1 0 ^ { \circ } \mathrm { C }$ using two Peltier elements (part (6) in Fig. 2). This maximizes the trapping efficiency such that $0 . 2 5 0 \mathrm { g }$ of 13X can adsorb $\sim 6 0 \mu \mathrm { g C }$ (methane carbon from $\sim 6 0 \mathrm { L }$ of ambient air at $2 { \mathrm { p p m } }$ ), before the $\mathrm { C O } _ { 2 }$ breakthrough happens. The adsorption capacity can be enhanced by lowering the temperature even further.

After sampling, the sample trap is disconnected from the system and heated at $4 5 0 ^ { \circ } \mathrm { C }$ for $1 0 \mathrm { { m i n } }$ for sample desorption using the TSE (Tube Sealing Equipment) system (https: //www.ionplus.ch/tse, last access: 8 January 2025), which enables us to measure the pressure of the desorbed gases and to quantify the amount of the $\mathrm { C O } _ { 2 }$ released. The desorbed $\mathrm { C O } _ { 2 }$ is cryogenically sealed into a glass ampule to be used in the gas interface system of the MIni CArbon DAting System (MICADAS) (Wacker et al., 2013).

Before the next sample is collected, the sample trap is cleaned of remaining $\mathrm { C O } _ { 2 }$ by flushing with high-purity nitrogen while heating at $5 5 0 ^ { \circ } \mathrm { C }$ for $3 0 \mathrm { { m i n } }$ . Such a long procedure compared to other cleaning processes for other applications is only precautionary; a shorter procedure might be sufficient to remove any residual carbon from previous sampling.

# 2.3 AMS analysis

The sample is measured with the MICADAS accelerator mass spectrometry facilities for radiocarbon measurements in the Laboratory of Ion Beam Physics, ETH (Wacker et al., 2010). The $\mathrm { ^ { 1 4 } C }$ analysis using the gas interface of the MICADAS takes about $2 0 \mathrm { { m i n } }$ and achieves a measurement precision of less than $1 \%$ for modern samples (Wacker et al., 2013) for a sample containing $2 0 \mu \ g$ of carbon. Precisions down to $0 . 5 \%$ can be achieved when measurements are repeated on $1 \geq 5 0 \mu \mathrm { g }$ of carbon (Fahrni et al., 2013).

The combusted NOX standard (SRM-4990C, Mann, 1983; Wacker et al., 2019) and the $^ { 1 4 } \mathrm { C }$ -free $\mathrm { C O } _ { 2 }$ premixed with helium in gas bottles were measured for standard normalization or blank correction. Measured data (Zazzeri, 2025) were evaluated with the BATS computer program, where the samples were fractionation-corrected, blank-subtracted and normalized with the NOX standard (Wacker et al., 2010) to obtain $F ^ { 1 4 } \mathrm { C }$ values (Reimer et al., 2004).

# 2.4 Characterization of the extraneous contaminant carbon within the sampler

Extraneous contaminant carbon in the sample trap after a sample collection might derive from intrusion of lab air into the system, from incomplete removal of atmospheric $\mathrm { C O } _ { 2 }$ , from residual carbon on the sample trap prior to sampling or from impurities within the combustion column.

To check for and quantify the contaminant carbon, we collected $\mathrm { C H } _ { 4 }$ samples of different sizes, and we followed the relationship between the measured fraction modern $( F ^ { 1 4 } \mathrm { C } )$ vs. the sample masses given by the mass balance in Eq. (1):

$$
\begin{array} { r l } & { F ^ { 1 4 } \mathrm { C } _ { \mathrm { m e a s . } } = F ^ { 1 4 } \mathrm { C } _ { \mathrm { t r u e } } } \\ & { ~ + \frac { 1 } { \mu \mathrm { C } _ { \mathrm { m e a s . } } } \left[ \mu \mathrm { C } _ { \mathrm { a d d } } \times \left( F ^ { 1 4 } \mathrm { C } _ { \mathrm { a d d } } - F ^ { 1 4 } \mathrm { C } _ { \mathrm { t r u e } } \right) \right] , } \end{array}
$$

where “meas.” indicates the measured value, $F ^ { 1 4 } \mathrm { C } _ { \mathrm { t r u e } }$ indicates the $F ^ { 1 4 } \mathrm { C }$ value of the sampled air, $\mu \mathrm { C _ { a d d } }$ indicates the carbon added into the system and $F ^ { 1 4 } C _ { \mathrm { a d d } }$ indicates its $F ^ { 1 4 } \mathrm { C }$ value. If assuming a constant contamination, the contaminant carbon added to the system is given by the $\mu \mathrm { C _ { a d d } }$ value that produces the best fitting curve through the $F ^ { 1 4 } C _ { \mathrm { m e a s } }$ . values plotted against the measured sample masses $\mathrm { ( \mu C _ { \mathrm { { m e a s . } } } ) }$ . We assess the goodness of fit using reduced chi-squared statistics (i.e. “curve_fit” function from the “scipi.optimize” Python package).

# 2.5 Comparison with chromatographic extraction procedure

Three samples transferred in sampling bags from the cylinder of pressurized ambient air Ref 1 were extracted at LARA, University of Bern, using $6 0 \mathrm { L }$ of air and following the chromatographic extraction procedure in Espic et al. (2019). $\mathrm { C O } _ { 2 }$ derived from the sample extraction in Bern was measured using the gas interface system of the MICADAS AMS system at ETH, in the same manner as the samples collected with our portable sampler.

# 3 Results

Table 1 shows the $F ^ { 1 4 } \mathrm { C }$ values and masses of the samples collected.

Assuming a $F ^ { 1 4 } C _ { \mathrm { t r u e } }$ value for Fossil Ref of 0.01 and a $F ^ { 1 4 } \mathrm { C }$ value of the modern contaminant $( F ^ { \mathrm { 1 4 } } \mathrm { C _ { a d d } ) }$ of 1, the best fitting curve through the Fossil Ref samples indicates a constant level of modern contamination $( \mu \mathrm { g C _ { a d d } } )$ of $0 . 5 \pm 0 . 1 \mu \mathrm { g C } .$ Larger samples $\mathrm { ( > 5 0 \mu g C ) }$ show an offset that can be explained with a size-dependent contamination, an additional $0 . 1 \mu \mathrm { g C }$ every $1 0 \mu \mathrm { g C }$ collected, which we can correct for (Fig. 3).

# 4 Discussion

In order to make the sampler portable, we have reduced the size of the sampler components compared to the system in Zazzeri et al. (2021). The main changes include the following:

– a smaller $\mathrm { C O } _ { 2 }$ trap placed before the combustion furnace, with $1 4 \mathrm { g }$ against $6 0 \mathrm { g }$ of molecular sieve; its adsorption capacity is demonstrated by the very low modern blank, which indicates that all the ambient $\mathrm { C O } _ { 2 }$ is captured while sampling;

– a new design of the sample trap, with $0 . 2 5 0 \mathrm { g }$ of molecular sieve against $1 \mathrm { g }$ , accommodated in a $4 \mathrm { c m }$ long tube and connected to a single 4-port VICI valve; collection of $6 0 \mu \mathrm { g C }$ (2 or3 h of sampling at $5 0 0 \mathrm { s c c m } )$ ) has been achieved by cooling down the sample trap using two Peltier elements;

![](images/38574324829ad08ddf0cedfbd9b636826baf2ba82e1e93f95bc947ad3ce34043.jpg)  
Figure 4. Measured $F ^ { 1 4 } \mathrm { C }$ values against the measured mass of the samples collected from Ref 1. Symbols in blue are the Ref 1 samples extracted in Bern and are not included for the curve fitting. The grey bands represent the $1 \sigma$ uncertainty bar on the curve fit.

– a smaller combustion furnace built at the Laboratory of Ion Beam Physics;

– connections and tubing of 1/8 in. size instead of 1/4 in.

All these modifications led to an important reduction in the level of constant modern contamination, from $5 . 5 \pm 1 . 1 \mu \mathrm { g C }$ in Zazzeri et al. (2021) down to $0 . 5 { \pm } 0 . 1 \mu \mathrm { g C }$ . According to the $F ^ { 1 4 } \mathrm { C }$ measurements of our modern reference cylinder (Ref 1), we have an extra $0 . 2 \pm 0 . 1 \mu \mathrm { g C }$ of fossil contamination, leading to $0 . 7 0 \pm 0 . 1 4 \mu \mathrm { g C }$ total amount of contaminant carbon with an averaged $F ^ { 1 4 } \mathrm { C }$ value of 0.71. We also found a size-dependent contamination of $1 \%$ , which can be explained either with a tiny leak within the sampler or with some outgassing.

To further test the system contamination and demonstrate full separation of $\mathrm { C H } _ { 4 }$ and $\mathrm { C O } _ { 2 }$ , more gas mixtures could be used for $F ^ { 1 4 } \mathrm { C }$ measurements. For example, the system could be run using a mixture made of $2 \mathrm { p p m }$ of fossil $\mathrm { C H } _ { 4 }$ and $4 0 0 \mathrm { p p m }$ of $\mathrm { C O } _ { 2 }$ from combustion of OXII (oxalic acid II), diluted in $\Nu _ { 2 }$ or He.

The overall uncertainty for individual samples of $6 0 \mu \mathrm { g C }$ , calculated by propagating the error from counting statistics and background uncertainty, is $0 . 9 \%$ , comparable with other measurement techniques for $^ { 1 4 } \mathrm { C H } _ { 4 }$ , demonstrating that a larger sample, and therefore a longer sampling time, is not needed.

The main benefit of a portable system that needs only $6 0 \mathrm { L }$ of air for one sample is the important time saving both in the field and in the laboratory. The sample processing time in the laboratory has been reduced significantly, and so has the likelihood of contamination or mistakes by the operator.

The system, given its small size, could be placed in a vehicle, enabling sampling in a source area (such as a landfill site or an urban environment) or performing a mapping of isotopic signatures in a region.

# 5 Conclusions

We have advanced the $\mathrm { C H } _ { 4 }$ sampling system from Zazzeri et al. (2021) to a portable system that can be used in field campaigns while also reducing the contamination in the system. Further improvements could be made to automate the system so that the valve and pump switching and the flow rate are computer-controlled, making the whole sampling procedure more consistent. More samples could be collected in parallel and at the same time. In addition, the $\mathrm { C O } _ { 2 }$ desorbed from the sample trap is presently cryogenically trapped in glass ampules sealed for offline $^ { 1 4 } \mathrm { C }$ measurements, but a direct coupling of the zeolite trap to the gas interface (Wacker et al., 2013) connected to the MICADAS AMS system could be implemented, avoiding the additional step of using glass ampules.

Full assessment of the fossil carbon contamination in $^ { 1 4 } \mathrm { C H } _ { 4 }$ measurements is still challenging, because there is no modern reference material available for $\mathrm { C H } _ { 4 }$ . The production of a modern $\mathrm { C H } _ { 4 }$ standard for $^ { 1 4 } \mathrm { C }$ analysis, followed by an inter-laboratory comparison, should be pursued.

Overall, the combination of a selective and field deployable $\mathrm { C H } _ { 4 }$ sampler and sensitive AMS analysis provides a unique technology that can expand the use of $^ { 1 4 } \mathrm { C H } _ { 4 }$ measurements.
