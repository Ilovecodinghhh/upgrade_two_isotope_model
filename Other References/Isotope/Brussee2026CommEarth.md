# Triple-isotopic analyses pinpoint microbial methane release from subsea permafrost in the inner Laptev Sea

Marenka Brussee $\oplus 1 , 2 \boxtimes ,$ , Henry Holmstrand1,2, Birgit Wild 1,2, Denis Kosmach3,5, Denis Chernykh 3 , Natalia Shakhova3,4, Arkadiy Kurilenko3 , Igor Semiletov $\oplus 3 \&$ Örjan Gustafsson 1,2

Elevated methane concentrations are observed in the shallow water column above subsea permafrost on the East Siberian Arctic Shelf, including the inner Laptev Sea. The subsea source of this methane is poorly understood, yet crucial for predicting future methane emissions. Here, we combine analyses of dissolved methane concentrations, triple-isotopic fingerprinting, and Bayesian Markov Chain Monte Carlo statistics to constrain the source of high-concentration methane sampled during four expeditions, 2016-2020. In contrast to earlier findings of predominantly thermogenic methane release in the outer Laptev Sea, our results for the major methane release region of the inner Laptev Sea suggest that old microbial methane (radiocarbon age $> 4 8 0 0 0$ y BP) is being released from preformed methane pools stored within the subsea permafrost system. This observation reveals that several sources contribute to the elevated methane on the shelf and thus the necessity to consider a diversity of sources when estimating future methane release trajectories.

Highly elevated levels of methane $\mathrm { ( C H _ { 4 } ) }$ have been detected across extensive scales of the East Siberian Arctic Shelf (ESAS) over the past two decades1–3 . Next to enriched $\mathrm { C H } _ { 4 }$ concentrations in both seawater and the atmospheric boundary layer, strong ebullition was observed at several seep sites across the $\mathrm { E S A S } ^ { 3 - 5 }$ . The ESAS ( $< 2 0 0 \mathrm { m }$ depth) is the world’s largest shelf sea $( \sim 1 . 7 \times 1 0 ^ { 6 } \mathrm { k m } ^ { 2 } )$ , yet it is very shallow with an average depth of only ${ \sim } 4 5 \mathrm { m } ^ { 6 }$ . It started forming ${ \sim } 1 5$ ky before present (BP) as the sea level rose, inundating Pleistocene-age terrestrial permafrost7–10. The resulting subsea permafrost below the ESAS is estimated to stretch over $\sim 1 . 5 \times 1 0 ^ { 6 } \mathrm { k m } ^ { 2 }$ at an average thickness of ${ \sim } 3 3 0 \mathrm { m } ^ { 1 1 , 1 2 }$ . Based on subsea drill coring through the upper horizon of the subsea permafrost, repeated 21–22 years apart, it was shown that subsea permafrost is now thawing ${ \sim } 3 5 $ times faster than nearby terrestrial permafrost10,13. The thawing subsea permafrost contains preformed $\mathrm { C H } _ { 4 }$ and organic matter (OM) that could contribute to the observed intense $\mathrm { C H } _ { 4 }$ emissions. However, the $\mathrm { C H } _ { 4 }$ sources releasing $\mathrm { C H } _ { 4 }$ to the ESAS seawater are poorly constrained. Constraining the relative importance of the different $\mathrm { C H } _ { 4 }$ sources is a prerequisite for predicting to what extent the observed $\mathrm { C H } _ { 4 }$ emissions in the ESAS will intensify in the future.

Several old subsea pools could contribute to the elevated $\mathrm { C H } _ { 4 }$ levels on the ESAS. The deepest subsea $\mathrm { C H _ { 4 } }$ sources are fossil natural gas reservoirs of either microbial or thermogenic origin, formed below the permafrost layer14,15. The amount of $\mathrm { C H } _ { 4 }$ stored in such reservoirs is uncertain but may be $\mathord { \sim } 1 \mathord { - } 5 \mathrm { G t C }$ for the $\mathrm { E S A S ^ { 1 6 - 1 8 } }$ , i.e., respectively ${ \sim } 3 { - } 2 1 \%$ and ${ \sim } 1 { - } 7 \%$ of Russia’s natural gas reserves and resources19. The overlying subsea permafrost also holds substantial amounts of carbon in the form of both preformed $\mathrm { C H } _ { 4 }$ and as OM that can be microbially degraded to $\mathrm { C H } _ { 4 }$ upon thaw13,20. The preformed $\mathrm { C H } _ { 4 }$ within the subsea permafrost layer could originate from past in situ methanogenesis21,22. Furthermore, upward-moving gases from sub-permafrost fossil gas reservoirs could get trapped within23 or below14 the subsea permafrost layer.

The amounts of both OM and $\mathrm { C H _ { 4 } }$ in subsea permafrost reservoirs are highly uncertain. Estimates of the amount of OM in subsea permafrost are ${ \sim } 2 8 0 0 \mathrm { G t C }$ for the circum-Arctic24 and ${ \sim } 5 0 0 \mathrm { G t C }$ for the ${ \mathrm { E S A S } } ^ { 2 }$ . The $\mathrm { C H } _ { 4 }$ trapped by subsea permafrost may be present as free gas but also as gas hydrate, a solid where water $\left( \mathrm { H } _ { 2 } \mathrm { O } \right)$ and $\mathrm { C H _ { 4 } }$ molecules combine to a crystalline structure25. A gas hydrate is stable within specific pressuretemperature boundaries, where higher pressures and lower temperatures favor the hydrate phase26. An overview of estimated amounts of preformed $\mathrm { C H } _ { 4 }$ stored in oceanic and (subsea) permafrost hydrates, as free gas/hydrate within subsea permafrost, and in gas reserves/resources is provided in Supplementary Table 1, along with a description of how they were estimated, as far as that is retrievable. The highly varying estimates of the carbon mass of preformed $\mathrm { C H _ { 4 } }$ stored within the ESAS subsea permafrost domain range in published studies from $1 ^ { 2 7 }$ to $9 0 0 \mathrm { G r } \mathrm { C } ^ { 2 }$ . Taken together, there are very large uncertainties in the size of $\mathrm { C H } _ { 4 }$ -relevant compartments in the Arctic sedimentary drape.

There are multiple mechanisms that can release $\mathrm { C H _ { 4 } }$ from the old subsea $\mathrm { C H _ { 4 } }$ and OM reservoirs. First, the combination of geothermal heat, warm overlying Holocene seawater, and human-induced additional climate warming results in subsea permafrost thawing1,4,10. Such warming may induce microbial degradation of OM and concomitant $\mathrm { C H } _ { 4 }$ production in the thawed subsea permafrost, but also results in the direct release of subsea permafrost-trapped $\mathrm { C H } _ { 4 }$ by the destabilization of the subsea permafrost itself 2,28–30. Existing and developing taliks, i.e., unfrozen layers/bodies in permafrost31, can act as migration pathways for the release of subsea permafrost-trapped CH4 to the water column2,10,29,32,33. Furthermore, increasing subsea temperatures could destabilize $\mathrm { C H } _ { 4 }$ hydrates26, releasing $\mathrm { C H _ { 4 } }$ while facilitating the upward transport of formerly trapped preformed $\mathrm { C H _ { 4 } }$ from greater depths. Finally, the ESAS is tectonically active34–37, and $\mathrm { C H _ { 4 } }$ originating from fossil gas reservoirs could seep along faults formed by tectonic activity2,28,38,39.

In addition to these old subsea $\mathrm { C H _ { 4 } }$ sources, several younger and/or laterally transported sources can potentially also contribute $\mathrm { C H } _ { 4 }$ to the water column. Holocene shelf sediments contain both laterally transported OM (from coastal erosion or river discharge) and marine OM, which can be microbially degraded to $\mathrm { C H } _ { 4 }$ under anoxic conditions. Rivers32,40 and potentially submarine groundwater discharge41 can transport dissolved $\mathrm { C H } _ { 4 }$ to the ESAS, although dissolved $\mathrm { C H } _ { 4 }$ is largely reduced in concentration during freshwater transport to the sea42.

The heterogeneity of the subsea geology and permafrost in the ESAS precludes generalizing $\mathrm { C H } _ { 4 }$ emissions to the water column and the atmosphere based on the currently available data. While the origin of high $\mathrm { C H } _ { 4 }$ concentrations at outer Laptev Sea hotspot locations was identified as predominantly stemming from fossil thermogenic $\mathbf { g } \mathbf { a } \mathbf { s } ^ { 3 }$ , the origin of $\mathrm { C H } _ { 4 }$ released in other regions of the ESAS remains largely unknown. Specifically, the inner Laptev Sea has been found to hold extensive seeps4,10 and highly elevated $\mathrm { C H _ { 4 } }$ concentrations1,2,4 , yet $\mathrm { C H _ { 4 } }$ sources are poorly constrained. Given its shallow depth $( < 2 5 \mathrm { m } )$ , there is a short conduit to the atmosphere for any sediment-escaping $\mathrm { C H _ { 4 } }$ .

Several traits make permafrost underneath the inner Laptev Sea susceptible to destabilization. The region has been inundated comparatively recently (starting ${ \sim } 1 0 \mathrm { k y \ B P ^ { 7 , 8 } } ,$ ) and is suggested to have relicts of its terrestrial past in the form of taliks from paleo-rivers and thermokarst processes10,11,29,43–45. This coastal sea also has more pronounced lateral inputs than deeper offshore regions, including heat from the Lena River plume32. Moreover, the few existing core-based measurements of shallow coastal subsea permafrost indicate a thaw rate ${ \sim } 3 5 $ times greater than that of its terrestrial counterpart10,13 and, in the upper $5 7 \mathrm { m } ,$ a temperature $8 { - } 1 1 ^ { \circ } \mathrm { C }$ higher4 . This suggests that the shallow subsea permafrost is much more vulnerable than nearby terrestrial permafrost, likely because of the longterm heating from overlying seawater29,46. The geological setting, highly elevated $\mathrm { C H } _ { 4 }$ levels, and vulnerability of the inner Laptev Sea subsea permafrost make this a key subregion to disentangle what sources are dominating the $\mathrm { C H } _ { 4 }$ releases in the ESAS.

The rapid and amplified warming of the Arctic additionally motivates the study of sources and release mechanisms of $\mathrm { C H } _ { 4 }$ in the inner Laptev Sea. The Arctic is warming three to four times faster than the global average47,48, and a warmer climate would likely accelerate $\mathrm { C H _ { 4 } }$ release in the ESAS region. Benthic seawater temperatures in the shallow ESAS $( < 2 5 \mathrm { m } )$ have increased substantially compared to those in the deeper parts of the shelf 29. The observational record shows that mean summer bottom-water temperatures increased by ${ \sim } 1 ^ { \circ } \mathrm { C }$ for the 1999–2009 decade compared to the 100-year mean4,29, a process which may have accelerated over the past decade concomitant with wider Arctic warming trends. Potential effects of rising temperatures are increased $\mathrm { C H } _ { 4 }$ hydrate destabilization, increased subsea permafrost destabilization, releasing subsea permafrost-trapped $\mathrm { C H } _ { 4 } ,$ increased OM degradation in thawing subsea permafrost, and increased lateral inputs of OM and $\mathrm { C H } _ { 4 }$ . Some of these positive feedback mechanisms to climate change may evolve gradually, while others may be more abrupt. Future $\mathrm { C H _ { 4 } }$ emissions from thawing (subsea) permafrost and destabilizing $\mathrm { C H } _ { 4 }$ hydrates are two of the large uncertainties in the changing $\mathrm { C H } _ { 4 }$ budget and are considered potential biogeochemical tipping points for climate change49,50. In addition, the estimated size of the subsea OM and $\mathrm { C H } _ { 4 }$ deposits in the ESAS is $\sim 1 { - } 4 \times 1 0 ^ { 2 }$ times larger than the total amount of $\mathrm { C H } _ { 4 }$ in the atmosphere $( 3 . 8 \mathrm { G t C } ) ^ { 2 , 2 7 , 5 0 }$ . However, the current atmospheric monitoring networks cannot detect a sudden multiple-year-long $\mathrm { C H } _ { 4 }$ release event in the ESAS of the size of a $1 0 0 \%$ increased oceanic flux51. Improved constraints on the type and evolution of $\mathrm { C H } _ { 4 }$ emissions in the ESAS are necessary for reliable projections of this region’s current and future, potentially intensifying $\mathrm { C H } _ { 4 }$ emissions.

The main objective of this study is to quantify the relative contribution of different sources to the observed elevated dissolved $\mathrm { C H } _ { 4 }$ in the seawater of the inner Laptev Sea. To that end, we measured the concentration and tripleisotopic $( \Delta ^ { 1 4 } \mathrm { C } , \delta ^ { 1 3 } \mathrm { C } , \delta ^ { 2 } \mathrm { H } )$ composition of seawater $\mathrm { C H _ { 4 } }$ collected in regions at and near the inner Laptev Sea $\mathrm { C H } _ { 4 }$ hotspots over multiple years. The concentration of $\mathrm { C H _ { 4 } }$ and its stable isotopic composition were measured in samples from four ship expeditions between 2016 and 2020 (121 samples for $\delta ^ { 1 3 } \mathrm { C } _ { \mathrm { C H 4 } } , 7 6$ for $\delta ^ { 2 } \mathrm { H } _ { \mathrm { C H } 4 } ,$ ), and the natural abundance radiocarbon content in samples from 2019 $( n = 7 )$ and 2020 ${ \mathrm { ( } } n = 1 6 { \mathrm { ) } }$ . The $\delta ^ { 1 3 } \mathrm { C } _ { \mathrm { C H 4 } }$ and $\delta ^ { 2 } \mathrm { H } _ { \mathrm { C H 4 } }$ data were evaluated to characterize the formation process of $\mathrm { C H } _ { 4 }$ and distinguish between primary microbial and thermogenic $\mathrm { C H } _ { 4 } ^ { 5 2 - 5 4 }$ . Radiocarbon measurements were used to determine the age of the $\mathrm { C H } _ { 4 }$ precursor3,55. These observations were interpreted within a comprehensive literature review to constrain the isotopic composition of possible $\mathrm { C H _ { 4 } }$ sources (Fig. 1). These constrained endmembers and the measured $\mathrm { C H _ { 4 } }$ isotope data were combined in a Bayesian Markov Chain Monte Carlo (MCMC) statistical framework56,57 to quantify the dominant sources of dissolved $\mathrm { C H _ { 4 } }$ in the inner Laptev Sea.

# Results and discussion Elevated methane concentrations and ubiquitous bubble plumes in the inner Laptev Sea

High $\mathrm { C H } _ { 4 }$ concentrations and many bubble plumes were observed in the inner Laptev Sea during the four expeditions. A major hotspot region with strongly elevated $\mathrm { C H } _ { 4 }$ concentrations (up to $2 7 , 0 0 0 \mathrm { n M }$ ; Supplementary Data 2–5) was repeatedly observed along with dense ebullition patterns (Fig. 2; Supplementary Note 3 and Supplementary Data 6). North and south of this major methane hotspot (MMH), $\mathrm { C H } _ { 4 }$ concentrations were still up to $1 5 0 \mathrm { n M }$ for samples retrieved during 2016–2020; all of these are substantially elevated compared to ${ \sim } 4 \mathrm { n M }$ that would result if there were no local source and just equilibration with atmospheric $\mathrm { C H _ { 4 } }$ .

There is some variation between years in spatial concentration gradients and in the locations of observed $\mathrm { C H _ { 4 } }$ hotspots. The MMH observed in 2016–2020 was slightly northward compared to $\mathrm { C H _ { 4 } }$ hotspots identified earlier. In 2005, bottom water samples showed a distinct $\mathrm { C H } _ { 4 }$ hotspot $1 0 1 \mathrm { k m }$ away from the recent MMH $( \operatorname { F i g } . 2 ) ^ { 2 }$ . In 2007, $\mathrm { C H } _ { 4 }$ hotspots beneath sea ice were observed $7 9 - 5 7 \mathrm { k m }$ away from this $\mathbf { M M H } ^ { \mathrm { 1 } }$ . In 2009 and 2010, water column data showed a major $\mathrm { C H } _ { 4 }$ hotspot about $6 8 \mathrm { k m }$ from the $\mathrm { M M H ^ { 4 } }$ . Varying locations of the most apparent $\mathrm { C H } _ { 4 }$ hotspots over 15 years indicate that multiple $\mathrm { C H } _ { 4 }$ hotspots are present in the inner Laptev Sea and possibly have a changing activity level over short time scales (years to decades). The central impression is that there is a continuous ubiquity of intensive $\mathrm { C H } _ { 4 }$ hotspots in this inner Laptev Sea region.

At the MMH, dissolved $\mathrm { C H _ { 4 } }$ concentrations were up to 6000 times higher than expected from equilibrium with the atmosphere. The highest $\mathrm { C H } _ { 4 }$ concentrations were observed below the pycnocline $( \sim 1 0 - 1 5 \mathrm { m }$ deep) in the bottom water layer (Fig. 2 and Supplementary Note 2). The geographical alignment of the highest $\mathrm { C H } _ { 4 }$ concentrations with the intensity of the ebullition pattern at the MMH suggests partial dissolution from rising bubbles as a key cause of the elevated seawater $\mathrm { C H } _ { 4 }$ concentrations. These combined findings point to one or several continuous seabed sources of $\mathrm { C H } _ { 4 }$ causing the perennial and strongly elevated $\mathrm { C H } _ { 4 }$ concentrations in the shallow water column of the inner Laptev Sea.

# Radiocarbon signatures of dissolved methane

Radiocarbon dating of dissolved $\mathrm { C H _ { 4 } }$ in the inner Laptev Sea points toward the release of old (>48 ky BP) $\mathrm { C H } _ { 4 }$ into the overlying seawater, and mixing of this primary source with a background of younger $\mathrm { C H } _ { 4 }$ . Keeling plots were used to identify the isotopic signature of the primary $\mathrm { C H } _ { 4 }$ source, i.e., the y-intercept of the Keeling plot (“Methods”). The Keeling plot for the combined 2019 and 2020 measurements of $\Delta ^ { 1 4 } \mathrm { C } _ { \mathrm { C H 4 } }$ yielded a source signature of $- 1 0 5 8 \pm 6 6 \%$ $9 5 \%$ confidence interval), with a closely corresponding signature for 2020 data at the MMH of $- 1 0 0 7 \pm 8 \%$ (Fig. 3). Therefore, only compartments with such ancient radiocarbon signatures need to be considered as endmembers to apportion the dominant $\mathrm { C H } _ { 4 }$ sources in the inner Laptev Sea.

This old $\mathrm { C H } _ { 4 }$ could originate from a preformed $\mathrm { C H } _ { 4 }$ pool below or within the subsea permafrost or represent recently produced $\mathrm { C H } _ { 4 }$ from deep-situated thawing permafrost having radiocarbon-depleted OM. Three old source endmembers were consistent with this picture (Fig. 1 and “Methods”, Supplementary Methods 1.2). The first endmember was subsea permafrost-associated methane (SPAM), representing microbial $\mathrm { C H } _ { 4 }$ formed from OM in the upper subsea permafrost region before/during freezing and/or formed upon subsea permafrost thawing. The endmember SPAM thus represents $\mathrm { C H } _ { 4 }$ that is freshly formed near the subsea permafrost thaw front, as well as $\mathrm { C H } _ { 4 }$ formed in the past and retained in the current upper subsea permafrost layer (Fig. 1). The second endmember was fossil primary microbial (FOPRIM) gas, being primary microbial gas formed in the past by OM degradation using older OM than SPAM at higher formation temperatures. The third endmember was fossil thermogenic and secondary microbial (FOTSEM) gas, representing $\mathrm { C H } _ { 4 }$ formed by catagenesis in even deeper sedimentary basins at even higher temperatures and secondary microbial gas formed by the biodegradation of thermogenic petroleum. The FOPRIM and FOTSEM gases represent preformed $\mathrm { C H } _ { 4 }$ pools that may be located at multiple locations: in gas reservoirs beneath the subsea permafrost, or trapped below/within the permafrost as either free gas or $\mathrm { C H } _ { 4 }$ hydrate (indicated by the yellow and red areas in Fig. 1). Details regarding these endmembers are in Supplementary Methods 1.2.

The release of $\mathrm { C H _ { 4 } }$ from ancient seabed sources to the bottom seawater has been proposed for two other Arctic shelf sea regions; however, in both cases, the generated isotopic data were limited and based on single expeditions. The reports for the Beaufort Sea did not feature hydrogen isotope data and did not utilize the generated stable carbon isotope data for more detailed source apportionment55. The identified ancient $\mathrm { C H } _ { 4 }$ was suggested to originate from $\mathrm { C H _ { 4 } }$ hydrates, permafrost, and/or geologic sources55. For the outer Laptev Sea, very few $\Delta ^ { 1 4 } \mathrm { C _ { C H 4 } }$ data were generated3 . These were combined with single-year dual-stable isotope data, and the release of thermogenic $\mathrm { C H } _ { 4 }$ was suggested3 .

In addition to constraining the old characteristics of the strong $\mathrm { C H } _ { 4 }$ emission source, the $\Delta ^ { 1 4 } \mathrm { C _ { C H 4 } }$ data in the Keeling plots also yield information on the character/source of the $\mathrm { C H } _ { 4 }$ pool of lower concentration that it is mixing into. The consistently higher $\Delta ^ { 1 4 } C _ { \mathrm { C H 4 } }$ values associated with lower $\mathrm { C H } _ { 4 }$ concentrations observed here indicate a background of less-aged $\mathrm { C H } _ { 4 } ,$ which appears to be relatively constant over 2019–2020, considering the good fit in the Keeling plot for the years combined (Fig. 3B, $R ^ { 2 } = 0 . 7 5$ ). The relatively younger background pool mixing with large amounts of old $\mathrm { C H } _ { 4 }$ at the MMH could originate from $\mathrm { C H } _ { 4 }$ production in the upper reaches of thawed subsea permafrost and/or in sediment layers accumulated during the Holocene, or preformed $\mathrm { C H } _ { 4 }$ transported by rivers. Any of these younger $\mathrm { C H } _ { 4 }$ sources deliver microbially produced $\mathrm { C H } _ { 4 }$ .

The lowest concentration samples analyzed for radiocarbon content were $9 0 { - } 9 5 \mathrm { n M }$ and had an average $\Delta ^ { 1 4 } \mathrm { C } _ { \mathrm { C H 4 } } \left( \pm 1 \sigma \right)$ value of $- 5 5 5 \pm 4 5 \%$ ${ \it n } = 4$ , Supplementary Data 5); these samples are expected to have the highest relative contribution of background $\mathrm { C H } _ { 4 }$ among the sample set. River input is, in principle, a potentially contributing source of $\mathrm { C H } _ { 4 }$ . However, the dissolved $\mathrm { C H } _ { 4 }$ concentrations in the Lena Delta channels exporting $\mathrm { C H } _ { 4 }$ to the sea are only $\mathsf { 5 } { - } 2 0 \mathrm { n M } ^ { 4 2 }$ , so river input seems unlikely to be the primary cause of the observed elevated $\mathrm { C H } _ { 4 }$ concentrations of $9 0 { - } 9 5 \mathrm { n M }$ . The younger $\mathrm { C H _ { 4 } }$ in the lower-concentration range of the Keeling mixing curves may stem from OM degradation in the upper range of thawed subsea permafrost and/or Holocene-accumulated sediments. The $\mathrm { C H } _ { 4 }$ concentration resulting from early diagenesis in the upper sediments was estimated by using a three-source mixing model (including $\mathrm { C H _ { 4 } }$ from atmospheric equilibrium, $\mathrm { C H } _ { 4 }$ produced by early diagenesis in surface sediments, and radiocarbon-free $\mathrm { C H } _ { 4 }$ from greater depths; see equations in Supplementary Note 5). In these computations, we used the $\Delta ^ { 1 4 } C$ value of upper sediment bulk organic carbon (OC) sampled in the region $1 3 0 { - } 1 3 1 ^ { \circ } \mathrm { E } ,$ , $7 1 - 7 4 ^ { 0 } \mathrm { N } ^ { 5 8 , 5 9 }$ to estimate the $\Delta ^ { 1 4 } \mathrm { C }$ value of $\mathrm { C H } _ { 4 }$ produced by early diagenesis from shallow-sedimentary OM. If deeper and older sediments/thawed subsea permafrost, having lower $\Delta ^ { 1 4 } \mathrm { C }$ values, would be degraded, a larger contribution from early diagenesis would be inferred. Furthermore, the reactivity of OM is compound-specific 60, and the sedimentary OM consists of a mixture of compounds from different origins and ages61. Therefore, bulk OC $\Delta ^ { 1 4 } \mathrm { C }$ values are not directly equal to the $\Delta ^ { 1 4 } \mathrm { C }$ of the organic compounds that are predominantly degraded to $\mathrm { C H } _ { 4 }$ . Consequently, the calculated $\mathrm { C H } _ { 4 }$ concentrations resulting from early diagenesis $( 6 8 \pm 9 \mathrm { n M } )$ should be considered a rough estimate. Taken together, the lower concentration background $\mathrm { C H } _ { 4 }$ may stem primarily from early diagenesis in Holocene sediments and/or the upper thawed subsea permafrost layer, contributing $\mathrm { C H } _ { 4 }$ to the seawater over some areas in the inner Laptev Sea, yet it represents a minor part of the highly elevated $\mathrm { C H } _ { 4 }$ observed at the MMH.

As $\Delta ^ { 1 4 } \mathrm { C }$ measurements are, by definition, corrected for isotopic fractionation62 and thereby unaffected by microbial oxidation, the strong $\Delta ^ { 1 4 } \mathrm { C _ { C H 4 } }$ Keeling regressions (Fig. 3) inform about the source signature. The good fits of the regression lines, combined with slopes being evidently larger than zero, support a scenario where a primary source mixes with a background of much lower $\mathrm { C H } _ { 4 }$ concentration. Microbial degradation of $\mathrm { C H } _ { 4 }$ in the sediment or water column would result in a regression slope close to zero. Hence, there is an overwhelmingly old source causing the highly elevated $\mathrm { C H } _ { 4 }$ concentrations, which is mixing with a background pool of younger $\mathrm { C H } _ { 4 }$ . This supports the use of Keeling plots to interpret the stable isotope data in a mixing scenario, as discussed next.

# Dual-stable isotope signatures of dissolved methane

Multi-year dual-stable isotope results of dissolved $\mathrm { C H } _ { 4 }$ in the inner Laptev Sea indicate that microbially-produced $\mathrm { C H _ { 4 } }$ is the primary source, and that the source signature is very similar for all four studied years. The Keeling plot-derived multi-year average source signatures $( \pm 1 \sigma )$ for the below pycnocline samples were $- 7 2 \pm 2 \text{‰}$ for $\delta ^ { 1 3 } \mathrm { C } _ { \mathrm { C H 4 } }$ and $- 3 1 3 \pm 1 9 \%$ for $\delta ^ { 2 } \mathrm { H } _ { \mathrm { C H } 4 }$ (Fig. 4 and Supplementary Table 2). The multi-year average source signature $( \pm 1 \sigma )$ using the above pycnocline samples was very similar at $- 7 3 \pm 3 \text{‰}$ for $\delta ^ { 1 3 } \mathrm { C } _ { \mathrm { C H 4 } } ,$ and $- 3 1 4 \text{‰}$ for $\delta ^ { 2 } \mathrm { H } _ { \mathrm { C H } 4 }$ in 2020 (Fig. 4 and Supplementary Table 2). These low stable carbon and hydrogen isotope values point to primary microbially formed $\mathrm { C H } _ { 4 } ^ { 5 3 , 5 4 }$ . Depending on the pathway by which $\mathrm { C H } _ { 4 }$ is released to the water column (bubble dissolution versus diffusion from the sediment), $\mathrm { C H _ { 4 } }$ may be susceptible to anaerobic $\mathrm { C H } _ { 4 }$ oxidation during its sedimentary transit, altering its stable isotope composition54. The observed dual-stable isotope source signature is, however, very constant between years (Fig. 4 and Supplementary Table 2) and ebullition is ubiquitously observed (Fig. 2). Therefore, bubble dissolution likely represents the dominant pathway for $\mathrm { C H } _ { 4 }$ addition to the water column. Hence, anaerobic oxidation of $\mathrm { C H } _ { 4 }$ in the sediments would, if present, only marginally affect the observed dual-stable isotope source signatures.

The observed source signature for the inner Laptev Sea is in substantial contrast to observations for the outer Laptev Sea, where source signatures of $- 4 3 \text{‰}$ to $- 5 5 \text{‰}$ for $\delta ^ { 1 3 } \mathrm { C } _ { \mathrm { C H 4 } }$ and $- 1 3 7 \text{‰}$ to $- 1 5 8 \text{‰}$ for $\delta ^ { 2 } \mathrm { H } _ { \mathrm { C H } 4 }$ were identified, and consequently a thermogenic origin of $\mathrm { C H } _ { 4 }$ was suggested for that region ${ \sim } 3 5 0 \mathrm { k m }$ offshore3 . Combining the stable isotope and $\Delta ^ { 1 4 } \mathrm { C } _ { \mathrm { C H 4 } }$ data from the inner Laptev Sea indicates a predominantly old microbial source, in our source compartment terms SPAM and/or FOPRIM, being released into the inner Laptev Sea seawater at the MMH, which contrasts with the thermogenic FOTSEM seeps in the outer Laptev Sea.

# Isotopic source apportionment of methane released in the inner Laptev Sea

The Keeling plot-extrapolated isotopic source signatures of all four years of data fall within the endmember region of SPAM (Fig. 5). This suggests that $\mathrm { C H } _ { 4 }$ produced microbially from old subsea permafrost OM is the primary source of the intensive seabed escape of $\mathrm { C H } _ { 4 }$ in the inner Laptev Sea. The SPAM category includes both freshly produced $\mathrm { C H } _ { 4 }$ from thawed old OM $( > 4 8 \mathrm { k y B P } )$ and $\mathrm { C H } _ { 4 }$ formed in the past from OM that is now within subsea permafrost, held since formation as free gas or $\mathrm { C H } _ { 4 }$ hydrate. The tripleisotopic composition of $\mathrm { C H _ { 4 } }$ cannot be used to differentiate between recently and formerly formed $\mathrm { C H _ { 4 } }$ when both are formed by the same process from the same OM.

Most of the uncertainty in the determined fractional source contributions (Fig. 6) are due to the large variety in the isotopic values found for each endmember category and the inherent large standard deviations on the isotopic values of these endmembers (Supplementary Methods 1.2 and Supplementary Data 1). Small fractions of FOTSEM and FOPRIM gas (medians: $7 - 1 6 \%$ and $1 2 - 2 4 \%$ ) may be released simultaneously with SPAM (Fig. 6). These different types of gases may have mixed while being collectively trapped by the subsea permafrost before their combined release.

# Putative release pathways

We deduce that the released SPAM originates predominantly from a preformed pool instead of being freshly produced in thawing subsea permafrost. This is supported by the ubiquity of gas bubble fields in the hotspot regions (Fig. 2). Recent modeling studies are inconclusive regarding the contribution of OM degradation in thawing subsea permafrost to the observed $\mathrm { C H _ { 4 } }$ emissions in the ESAS. One modeling study of subsea permafrost OC stocks proposes low microbial decomposition rates of OM in thawing subsea permafrost $( { \sim } 0 . 1 3 \mathrm { m m o l } \mathrm { C m } ^ { - 2 } \mathrm { d } ^ { - \bar { 1 } } ) ^ { 2 4 }$ . In contrast, another model suggests substantial $\mathrm { C H _ { 4 } }$ production rates from OM degradation in thawed subsea permafrost $( \sim 1 1$ mmol $\mathrm { C H } _ { 4 } \ \mathrm { m } ^ { - 2 } \mathrm { d } ^ { - 1 } ) ^ { 6 3 }$ . Extrapolations of incubation experiments using subsea permafrost from the inner Laptev Sea show a minor in situ microbial $\mathrm { C H } _ { 4 }$ production rate of only 0.133 ${ \bf \sigma } ^ { \prime } \sigma = 0 . 1 6 7 { \bf \sigma } ,$ ) mmol $\mathrm { C H } _ { 4 } \mathrm { m } ^ { - 2 } \mathrm { d } ^ { - 1 1 3 }$ . This was the rate estimated for a thawed layer of $1 4 \pm 7 \mathrm { m }$ thickness, i.e., the average thaw depth in 2012–2014 of eight subsea permafrost cores from the inner Laptev $\mathsf { S e a } ^ { 1 3 }$ . Such a limited gas release rate cannot explain the large bubble fluxes observed with the echosounder at the MMH (Fig. 2; Supplementary Note 3 and Supplementary Data 6) nor the observation-based $\mathrm { C H } _ { 4 }$ ebullition fluxes estimated for this region of 18 (6.2–39) mmol $\mathrm { C H } _ { 4 } \mathrm { m } ^ { - 2 } \mathrm { d } ^ { - 1 4 }$ . We conclude that the released SPAM is dominantly not recently produced but more likely released from a preformed pool of free gas or destabilizing $\mathrm { C H } _ { 4 }$ hydrate within subsea permafrost. An implication is that the observed $\mathrm { C H _ { 4 } }$ releases might not necessarily develop gradually but may be more abrupt in nature.

Estimates of $\mathrm { C H } _ { 4 }$ hydrate abundance on the ESAS vary widely (Supplementary Table 1). Gas hydrates form under specific conditions when $\mathrm { C H } _ { 4 }$ and $_ \mathrm { H _ { 2 } O }$ are situated together at a specific ratio, pressure, and temperature25. The pressure and temperature conditions needed to form a $\mathrm { C H } _ { 4 }$ hydrate restrict $\mathrm { C H } _ { 4 }$ hydrate formation to the polar regions and deeper $( > \sim 3 0 0 \mathrm { m } )$ oceans26,64. Shallow $\mathrm { C H } _ { 4 }$ hydrates can be formed at ${ \sim } 2 0 0 \mathrm { m }$ depth in permafrost $( \sim 1 7 0 - 2 2 0 \mathrm { m }$ at ${ \sim } - 1 5$ to $- 5 ^ { \circ } \mathrm { C } ) ^ { 2 6 }$ , and hydrates have been identified in Arctic permafrost65–67. Yet, the gas hydrate stability region may shift upwards/downwards in the presence of other gases, such as carbon dioxide or longer hydrocarbons, and ionic compounds like $\mathrm { N a C l } ^ { 2 6 }$ . Furthermore, relict $\mathrm { C H } _ { 4 }$ hydrates formed by ice sheet-induced pressures during glaciations and subsequently retained outside the hydrate stability zone by self-preservation66,68 could be present even shallower in permafrost69,70. However, the lack of ice sheets in the inner Laptev Sea region during the Last Glacial Maximum71–73 likely prohibits the growth of hydrates formed due to glacier-exerted pressure. Some modeling studies estimate an upper border of the gas hydrate stability zone in the ESAS at $\mathord { \sim } 1 3 0 ^ { 4 5 }$ and ${ \sim } 7 5$ $\mathrm { m } ^ { 4 6 }$ during the Pleistocene, while currently at ${ \sim } 2 0 0 \mathrm { m } ^ { 4 5 , 4 6 }$ . Reported subsea permafrost drill cores from the ESAS extend to $\mathrm { \sim } 5 0 \mathrm { m } \mathrm { d e p t h } ^ { 4 , 1 0 }$ , i.e., not deep enough to verify the presence of hydrates in the ESAS region. All in all, the abundance of $\mathrm { C H _ { 4 } }$ hydrates on the ESAS and their associated depths is uncertain.

We assess the possibility of gradual thawing and deepening of the subsea permafrost table as a direct cause for the release of preformed SPAM from the thaw front. Preformed SPAM could be present as free gas or as $\mathrm { C H } _ { 4 }$ hydrate in permafrost, where $\mathrm { C H _ { 4 } }$ hydrate contains much more $\mathrm { C H } _ { 4 }$ per unit volume $\mathrm { ^ { \prime } 1 6 0 { - } 1 8 0 \ t i m e s ^ { 7 4 , 7 5 } } ,$ than free gas. Therefore, we consider destabilizing $\mathrm { C H _ { 4 } }$ hydrates as the maximum amount of preformed $\mathrm { C H _ { 4 } }$ that can be released by the gradual deepening of the permafrost table. The deepening of the subsea permafrost table in the coastal inner Laptev Sea was observed to be ${ \sim } 1 4 \ c m \ y ^ { - 1 1 0 }$ . To constrain an upper limit for $\mathrm { C H } _ { 4 }$ release from dissociating $\mathrm { C H } _ { 4 }$ hydrates, pure $\mathrm { C H } _ { 4 }$ hydrates were considered. If pure $\mathrm { C H } _ { 4 }$ hydrates gradually dissociate at ${ \sim } 1 4 \ c m \ y ^ { - 1 1 0 }$ , $2 7 0 0 { - } 3 0 0 0 \mathrm { m m o l }$ $\mathrm { C H } _ { 4 }$ $\mathbf { m } ^ { - 2 } \mathbf { d } ^ { - 1 }$ is released74,75. This suggests that $\mathrm { C H } _ { 4 }$ hydrate dissociation at the thaw front could result in detectable bubble plumes. However, given the depth of the permafrost table at $8 { - } 2 4 \mathrm { m }$ in the shallow coastal inner Laptev $\mathrm { S e a } ^ { 1 0 , 1 3 }$ , it is unlikely that the thaw front and associated salt intrusion76 have yet reached the gas hydrate stability zone45,46. Nevertheless, our study area was inundated earlier than the locations with permafrost table data7,8,10,13. Due to longer exposure to heat and salinity from overlying seawater, our study area may therefore exhibit a slightly deeper permafrost table and thaw front. Furthermore, the combination of geothermal heat and warming induced by the overlying seawater decreases the gas hydrate stability zone below the permafrost table45,46, possibly resulting in hydrate destabilization below the thaw front77. However, when considering permafrost as an impermeable layer for gas flow, the migration of $\mathrm { C H } _ { 4 }$ released from such destabilizing $\mathrm { C H } _ { 4 }$ hydrates below the thaw front would require thawedthrough zones that extend much deeper than the current thaw front, such as taliks, as discussed next.

Taliks of different origin may act as conduits for upward-moving $\mathrm { C H } _ { 4 }$ . The inner Laptev Sea is tectonically active, and the study area is located in the Ust’-Lensky rift basin, which contains many faults29,34,35,78. Such faults and the associated taliks from penetrating geothermal heat46,79 are a potential pathway for the release of SPAM. Other types of taliks, from paleo-river channels or submerged thaw lakes, have also been reported to be present in the inner Laptev Sea and could also act as vertical conduits for the release of preformed $\mathrm { C H } _ { 4 } ^ { 1 0 , 2 9 , 3 2 , 8 0 }$ . Taliks formed by paleo-river channels have been modeled as being able to explain gas venting from dissociating hydrate deposits33. Warming from both the top and the bottom after submergence was modeled to increase talik width, resulting in gas hydrate dissociation near the talik edges, driving gas transport to the water column33. Similarly, open taliks, acting as gas migration pathways for preformed subseapermafrost trapped $\mathrm { C H } _ { 4 } ,$ have been modeled to be present over large areas in the inner Laptev $\mathrm { S e a ^ { 4 } }$ . Furthermore, sub-bottom profile images for the coastal Laptev Sea showed blanked areas interpreted as propagating gas plumes co-located with a submerged lake basin10. The overlying bubble plumes in the water column pointed to gas propagation through a submerged thaw lake talik, and it was hypothesized that such submerged thaw lake taliks develop further downwards after inundatio n10,29,81. Further mechanisms for talik formation have also been observed. On the Beaufort Sea shelf, gas flares were observed to be associated with pingo-like features82. These were interpreted as being formed by upward sediment extrusion due to sub-permafrost gas pressure build-up from gas hydrate decomposition82, an example of gas release and talik formation driven by geothermal heat from below. In summary, existing and developing taliks of different origins could explain the observed release of SPAM in the inner Laptev Sea.

At the major $\mathrm { C H } _ { 4 }$ hotspot in our study area, we have identified SPAM as the primary source, while fractions of FOPRIM and FOTSEM gases are also suggested (Fig. 6 and Supplementary Note 8). The release of $\mathrm { C H _ { 4 } }$ along taliks from subsea permafrost-trapped gas, potentially from dissociating $\mathrm { C H } _ { 4 }$ hydrates, aligns with these observations as SPAM could have mixed with FOPRIM and FOTSEM gases while being trapped. Furthermore, the demonstrated presence of taliks in the inner Laptev Sea and the propagation of gas plumes through the seabed2,10,83 make $\mathrm { C H } _ { 4 }$ release along these features plausible. Moreover, local ebullition hotspots at many locations in the inner Laptev Sea align with developing taliks releasing preformed $\mathrm { C H } _ { 4 }$ . Therefore, we believe that the leakage of subsea permafrost-associated $\mathrm { C H } _ { 4 }$ along existing and/or developing taliks is the most likely explanation for the observed intensive $\mathrm { C H _ { 4 } }$ release at the major $\mathrm { C H } _ { 4 }$ hotspot in the inner Laptev Sea. Taken all together, the observed $\mathrm { C H } _ { 4 }$ is released from a preformed $\mathrm { C H } _ { 4 }$ pool associated with degrading subsea permafrost.

# The fate of methane after release from the seabed

The old microbial subsea permafrost-associated $\mathrm { C H } _ { 4 } ,$ released at the major $\mathrm { C H } _ { 4 }$ hotspot in the inner Laptev Sea, is observed to mix with a younger microbial, likely partly oxidized, $\mathrm { C H } _ { 4 }$ background in the water column. All samples below the pycnocline with dual-stable isotope data lie within stable isotope regimes of $\mathrm { C H } _ { 4 }$ formed by primary microbial pathways53,54 (Fig. 5). This aligns with the proposed scenario in which $\mathrm { C H } _ { 4 }$ is predominantly released from an old microbial $\mathrm { C H _ { 4 } }$ source, mixing into a younger (Fig. 3) yet microbial $\mathrm { C H } _ { 4 }$ background. The observed trend of enrichment in the stable isotopes with decreasing concentration is consistent with a partly oxidized $\mathrm { C H } _ { 4 }$ background pool, considering the enriched stable isotopic composition of the background material53,54 (Fig. 4). The different slopes of the Keeling plots to either the north $( 7 4 ^ { \circ } \mathrm { N } )$ or south $( 7 2 ^ { \circ } \mathrm { N } )$ of the MMH (Fig. 4) could point to mixing with background material having different concentrations and/or more/less isotopically enriched $\mathrm { C H } _ { 4 }$ . The isotopic enrichment could also partly originate from aerobic oxidation of the $\mathrm { C H } _ { 4 }$ released at the MMH. However, the stable isotope Keeling plots show strong linear relationships, and the $\delta ^ { 2 } \mathrm { H } _ { \mathrm { C H 4 } }$ data manifest as a cloud around $- 3 0 0 \text{‰}$ across a range of $\mathrm { C H } _ { 4 }$ concentrations at the MMH in 2020 (Fig. 4). This suggests that $\mathrm { C H } _ { 4 }$ oxidation is not an important cause of the varying $\mathrm { C H } _ { 4 }$ concentrations. Instead, $\mathrm { C H _ { 4 } }$ from the same source appears to be released/mixed into the water column to different extents, possibly through bubble dissolution, resulting in the observed variation in $\mathrm { C H } _ { 4 }$ concentration.

Additional lines of evidence support that there is little microbial $\mathrm { C H _ { 4 } }$ oxidation of the primary source in the water column. The dualstable isotope plot (Fig. 5) shows a range of literature-based dual-stable isotope fractionation lines derived from microbial incubation experiments (Supplementary Table 3). These lines were derived by computing the shift in $\delta ^ { 1 3 } \mathrm { C } _ { \mathrm { C H 4 } }$ for the $\mathrm { C H _ { 4 } }$ fraction remaining corresponding to a $\delta ^ { 2 } \mathrm { H } _ { \mathrm { C H } 4 }$ shift from $- 3 0 0 \text{‰}$ to $- 1 5 0 \text{‰}$ of the source material. The resulting theoretical range of the dual-stable isotope fractionation lines for microbial aerobic oxidation in the water column, i.e., a $\Delta \delta ^ { 1 3 } \mathrm { C } { : } \Delta \delta ^ { 2 } \mathrm { H }$ ratio of $7 . 5 \pm 2 . 2$ $( \pm 1 \sigma )$ , does not align with the fitted $\Delta \delta ^ { 1 3 } \mathrm { C } { : } \Delta \delta ^ { 2 } \mathrm { H }$ lines through the measured dual-stable isotope data, as these were much larger, ranging from 13 to 24 (Fig. 5). This indicates that the change in stable isotope composition in our seawater samples does not reflect $\mathrm { C H _ { 4 } }$ oxidation in the water column, but is more likely caused by mixing with a background pool. Importantly, any dilution of the primary source material and additional source addition, for example, by bubble dissolution, would keep the observed stable isotope data along the mixing line. Finally, the bottom, mid-column, and surface waters at the MMH show $\mathrm { C H _ { 4 } }$ of similar stable isotopic composition (Fig. 7), which again aligns with minor $\mathrm { C H } _ { 4 }$ oxidation in the water column in this region.

Based on the above, it is likely that a predominant fraction of the subsea permafrost-associated $\mathrm { C H _ { 4 } }$ released at the major $\mathrm { C H _ { 4 } }$ hotspot reaches the surface water and atmosphere in this shallow ocean region. Similar source signatures were identified with Keeling plots below and above the pycnocline (Fig. 4 and Supplementary Table 2), identifying the same primary $\mathrm { C H } _ { 4 }$ source in both surface and bottom waters. Moreover, south of the hotspot, more negative $\delta ^ { 2 } \mathrm { H } _ { \mathrm { C H } 4 }$ values were found in the surface waters compared to the bottom waters (Fig. 7). This could point to $\mathrm { C H } _ { 4 }$ being spread along the surface away from the MMH, leading to a somewhat lower $\delta ^ { 2 } \mathrm { H } _ { \mathrm { C H 4 } }$ value in the surface water south of the MMH. Furthermore, the rising bubbles likely transport $\mathrm { C H } _ { 4 }$ directly to the atmosphere, considering the shallow water column84. Even if $\mathrm { C H } _ { 4 }$ dissolves partly from rising bubbles through the shallow water column at the MMH, resulting in similar $\mathrm { C H } _ { 4 }$ stable isotope signals along the water column up to the surface water (Fig. 7), the remaining $\mathrm { C H } _ { 4 }$ in such bubbles reaching the surface water will be directly emitted to the atmosphere.

Lower $\mathrm { C H } _ { 4 }$ concentrations but similar stable isotope composition in the surface water compared to sub-pycnocline water at the MMH could point to several processes. At the MMH, $\mathrm { C H } _ { 4 }$ concentrations were smaller in the surface water than in the bottom water (Fig. 2; Supplementary Note 2 and Supplementary Data 2–5). The dissolved $\mathrm { C H } _ { 4 }$ in the surface water was likely diluted through water mixing, reducing its observed concentration. Furthermore, $\mathrm { C H } _ { 4 }$ can diffuse from the water column into the atmosphere, reducing its concentration. An effective way to rapidly reduce $\mathrm { C H } _ { 4 }$ concentrations in surface waters is by intensive $\mathrm { C H } _ { 4 }$ release (ventilation) due to storm events, which has been observationally demonstrated for this region4 . Both slow diffusion and rapid $\mathrm { C H } _ { 4 }$ venting result in the release of SPAM from the surface water into the atmosphere. The relatively invariant dual-stable isotope composition along the water column at the MMH (Fig. 7) and deduced $\mathrm { C H _ { 4 } }$ release to the atmosphere contrast with findings for the Beaufort Shelf, where it was suggested that $\mathrm { C H _ { 4 } }$ oxidation and dispersion strongly limit the emission of ancient $\mathrm { C H } _ { 4 }$ into the atmosphere55. All in all, this study suggests the release of old microbial preformed $\mathrm { C H _ { 4 } }$ from deep seabed sources in degrading permafrost that reaches the surface water and atmosphere in the inner Laptev Sea region.

# Implications

Multi-year triple-isotopic analysis of seawater $\mathrm { C H _ { 4 } }$ from the inner Laptev Sea region with intensive sedimentary $\mathrm { C H } _ { 4 }$ emissions indicates the release of predominantly old, microbial $\mathrm { C H } _ { 4 }$ formerly trapped in subsea permafrost. Based on the ebullitive character and the geological setting, it is hypothesized that (developing) taliks facilitate the seepage of this preformed $\mathrm { C H } _ { 4 } ,$ possibly from destabilizing $\mathrm { C H } _ { 4 }$ hydrates. Importantly, our results point towards the release of preformed $\mathrm { C H } _ { 4 }$ from degrading subsea permafrost, hereby providing insights on a vulnerable $\mathrm { C H } _ { 4 }$ compartment in the context of climate warming.

The major finding of old, microbial, and subsea permafrost-associated $\mathrm { C H } _ { 4 }$ as the primary source in the inner Laptev Sea contrasts with thermogenic $\mathrm { C H } _ { 4 }$ released in the outer Laptev Sea. This indicates that multiple $\mathrm { C H } _ { 4 }$ pools contribute to the observations of elevated $\mathrm { C H } _ { 4 }$ concentrations on the extensive ESAS, the largest shelf region of the world. This implies that multiple sources and release pathways must be considered in estimates of current and future $\mathrm { C H } _ { 4 }$ releases from the ESAS system. Furthermore, considering the size of the subsea permafrost-associated $\mathrm { C H } _ { 4 }$ pool and its vulnerability, this may be an intensifying natural $\mathrm { C H } _ { 4 }$ release process that may be one part of the poorly understood current increase in global atmospheric $\mathrm { C H } _ { 4 } ,$ where enhanced natural releases of biogenic $\mathrm { C H } _ { 4 }$ are suggested85,86. The identified $\mathrm { C H } _ { 4 }$ release from subsea permafrost, a littlestudied yet major earth system compartment, is exacerbated by the inefficient removal through microbial oxidation in the water column, likely yielding the majority of the $\mathrm { C H } _ { 4 }$ being also released into the atmosphere. The observed release of formerly subsea-permafrost-trapped $\mathrm { C H } _ { 4 }$ in the inner Laptev Sea is coupled to subsea permafrost destabilization, a process that is expected to continue with global warming and needs further consideration.

# Methods Expeditions and sampling stations

This study is based on four extensive expeditions to the distant ESAS. In 2016, the R/V Akademik M.A. Lavrentyev traversed the inner Laptev Sea at the end of September while in October 2018, 2019, and 2020, the R/V Akademik Mstislav Keldysh (AMK) crossed the inner Laptev Sea (Fig. 2). Sampling was focused on regions where high $\mathrm { C H } _ { 4 }$ concentrations had been previously observed in order to address the source(s) of these massive sedimentary releases. Within these regions, geophysical soundings were used to detect gas seeps that could indicate strong $\mathrm { C H } _ { 4 }$ release by ebullition. Most sampling took place close to seep sites, while some samples were retrieved at background locations with lower $\mathrm { C H } _ { 4 }$ concentrations for comparison (sample details in Supplementary Data 2–5).

# Seep detection

The seeps were detected with a scientific $2 0 0 \mathrm { k H z }$ single-beam echosounder, Simrad EK15. The beam swath was $2 6 ^ { \circ }$ , resulting in a swath diameter of ${ \sim } 2 0 \mathrm { m }$ and a sounding area of $\sim 3 0 0 \mathrm { m } ^ { 2 }$ at ${ \sim } 2 0 \mathrm { m }$ water depth. The acoustic survey was conducted at ${ \sim } 1 1 \mathrm { k m h ^ { - 1 } }$ . The presence of rising bubbles was identified by observing an increased acoustic signal intensity in the water column (Supplementary Note 3). This type of echosounder data was generated for the expeditions in 2018, 2019, and 2020. This seep detection technique has been described elsewhere4,5,87.

# Procedures for sampling seawater methane for concentration and isotopic analyses

Seawater samples for $\mathrm { C H } _ { 4 }$ concentration and isotope analyses were retrieved with a Niskin Rosette, deployed from the research vessel (procedures in Supplementary Methods 1.1.1). The samples for $\mathrm { C H _ { 4 } }$ concentration and stable isotope analysis were taken at several water depths. In 2020, additional samples for stable isotope analysis were collected at the three main $\mathrm { C H } _ { 4 }$ hotspot locations in the form of a set of horizontally spaced near-bottom water samples. Samples for radiocarbon content were collected from bottom water at locations where high $\mathrm { C H } _ { 4 }$ concentrations were found.

# Methane concentration, stable isotope, and radiocarbon analysis

Methane concentrations were measured onboard after headspace equilibration using gas chromatography flame-ionization detection (GC-FID, Supplementary Methods 1.1.2). Gas samples, retrieved by headspace equilibration onshore, were analyzed for $\mathrm { C H _ { 4 } }$ stable isotope composition using gas chromatography continuous-flow isotope-ratio mass spectrometry (GC-CF-IRMS) and two standards with different isotopic composition (Supplementary Methods 1.1.3). Upon entering the GC-CF-IRMS, $\mathrm { C H } _ { 4 }$ in the gas samples was concentrated in a preconcentration device resembling a former setup88 but with some modifications (Supplementary Methods 1.1.3). Samples for radiocarbon analysis were sampled and prepared for analysis by accelerator mass spectrometry following a published method89 (summary in Supplementary Methods 1.1.4).

# Isotopic endmembers of putative subsea methane sources

Three main endmembers were considered for the old $^ { \prime } { > } 4 8$ ky BP) $\mathrm { C H _ { 4 } }$ that was found. These are: subsea permafrost-associated methane (SPAM), fossil primary microbial (FOPRIM) gas, and fossil thermogenic and secondary microbial (FOTSEM) gas (Fig. 1). Full explanations of the endmembers, the isotopic endmember database, and the resulting constraints on the isotopic source endmember values can be found in Supplementary Methods 1.2 and Supplementary Data 1. Isotopic data from 158 articles were included in the isotopic endmember database. In total, 642, 484, and 2394 isotopic samples were incorporated in the database to construct the isotopic endmember values for, respectively, SPAM, FOPRIM gas, and FOTSEM gas.

In short, SPAM covers all forms of microbial $\mathrm { C H } _ { 4 }$ (free gas or hydrate) formed from OM in the upper subsea permafrost region before/during freezing and formed upon subsea permafrost thawing. Importantly, this category thus also encompasses $\mathrm { C H } _ { 4 }$ formed from relatively fresh OM accumulated during the past several million years and trapped by permafrost after formation, i.e., a preformed $\mathrm { C H } _ { 4 }$ pool. As SPAM represents primary microbially formed $\mathrm { C H } _ { 4 } ,$ the constrained dual-stable isotope values of this endmember are low (Supplementary Methods 1.2.4 and Supplementary Data 1). The endmember SPAM is situated in the subsea permafrost layer (Fig. 1).

The natural gases FOTSEM and FOPRIM are fossil gases formed below permafrost by either catagenesis or primary/secondary microbial processes. The endmember FOPRIM encompasses primary microbial gas formed by OM degradation at temperatures up to $6 0 { - } 8 0 ~ ^ { \circ } \mathrm { C } ^ { 9 0 { - } 9 2 }$ , using older OM than SPAM that can be up to several hundred million years old. It is typically formed up to depths of $\sim 1 - 3 \mathrm { k m } ^ { 9 1 - 9 3 }$ . The endmember FOTSEM encompasses $\mathrm { C H } _ { 4 }$ formed by catagenesis in even deeper sedimentary basins at a pressure of 300–1500 bar and a temperature of $5 0 - 2 0 0 ^ { \circ } \mathrm { C } ^ { 9 0 , 9 4 }$ . Furthermore, it encompasses secondary microbial $\mathrm { C H } _ { 4 }$ formed by the biodegradation of thermogenic petroleum, especially oil, in relatively cold $( < 7 0 { - } 9 0 ^ { \circ } \mathrm { C } )$ reservoirs95. The constrained stable carbon isotope value of the endmember FOPRIM gas is much more negative than that of FOTSEM gas due to the primary microbial origin of FOPRIM gas (Supplementary Methods 1.2.1–1.2.3 and Supplementary Data 1). Both FOPRIM and FOTSEM gases can be present at the location of formation, accumulate in another reservoir, or get trapped as $\mathrm { C H } _ { 4 }$ hydrate or free gas in or below subsea permafrost. While isotopic compositions alone do not allow for further distinction between these compartments, the endmembers FOPRIM and FOTSEM effectively represent ancient preformed $\mathrm { C H } _ { 4 }$ pools. The endmembers FOPRIM and FOTSEM gases are indicated with yellow and red, respectively, in Fig. 1.

The constrained isotopic endmember values for $\delta ^ { 1 3 } \mathrm { C } _ { \mathrm { C H 4 } }$ are $- 4 3 \pm 7 \text{‰}$ , $- 6 7 \pm 5 \% 0 ,$ , and $- 7 4 \pm 1 0 \text{‰}$ for, respectively, FOTSEM, FOPRIM, and SPAM. The constrained isotopic endmember values for $\delta ^ { 2 } \mathrm { H } _ { \mathrm { C H } 4 }$ are $- 1 9 6 \pm 3 1 \%$ , $- 2 2 1 \pm 3 8 \%$ , and $- 3 2 2 \pm 4 4 \%$ for, respectively, FOTSEM, FOPRIM, and SPAM (database containing individual isotopic data in Supplementary Data 1).

# Statistical source apportionment of the released methane

The isotopic measurements of dissolved $\mathrm { C H } _ { 4 }$ were extrapolated to the source signatures of the $\mathrm { C H } _ { 4 }$ being released to the water column using Keeling plots. To obtain the Keeling plots, a linear regression model was fitted to the measured isotopic values versus the inverse $\mathrm { C H } _ { 4 }$ concentration using the least squares method. Keeling plots3,96 are applicable for source determination when a distinct single source or well-mixed group of sources mixes to different extents into relatively constant background material. If a mixing scenario is valid, the y-intercept of the Keeling plot gives the isotopic signature of the source(s). A prerequisite for using Keeling plots is that fractionating processes, like $\mathrm { C H } _ { 4 }$ oxidation, do not dominate the observed isotopic changes in the mixing medium, which is seawater in this case. In our study, the Keeling plot-extrapolated values (y-intercepts) were combined with the constrained endmember data in a Bayesian MCMC approach56,57 to derive the probability density functions of the fractions of each source category. A Bayesian MCMC approach was used to account for the isotopic uncertainty of the identified endmembers and to obtain the probability density functions of the source fractions, thereby quantifying the uncertainties associated with these results. A complete description of this procedure can be found in Supplementary Methods 1.3.
