# Isotopic measurements of atmospheric methane in Los Angeles, California, USA: Influence of “fugitive” fossil fuel emissions

Received 12 September 2011;revised 28 February 2012;accepted 4 March 2012; published 14 April 2012.

[1]Recent studies have suggested that $\mathrm { C H } _ { 4 }$ emissions in Los Angeles and other large cities may be underestimated. We utilized stable isotopes ( $^ { 1 3 } \mathrm { C }$ and D) and radiocarbon ${ } ^ { ( ^ { 1 4 } \mathrm { C ) } }$ to investigate sources of $\mathrm { C H } _ { 4 }$ in Los Angeles, California. First, we made measurements of $\delta ^ { 1 3 } \mathrm { C }$ and $\delta \mathbf { D }$ of various $\mathrm { C H } _ { 4 }$ sources in urban areas.Fossil fuel $\mathrm { C H } _ { 4 }$ sources (oil refineries, power plants, traffc,and oil drilling fields) had $\delta ^ { 1 3 } \mathrm { C }$ values between $- 4 5$ and $- 3 0 \text{‰}$ and dD values between $- 2 7 5$ and $- 1 0 0 \text{‰}$ ,whereas biological $\mathrm { C H } _ { 4 }$ (cows, biofuels, landfills, sewage treatment plants, and cattle feedlots) had $\breve { \delta } ^ { 1 3 } \mathrm { C }$ values between $- 6 5$ and $- 4 5 \text{‰}$ and $\delta \mathbf { D }$ values between $- 3 5 0$ and $- 2 7 5 \text{‰}$ . We made high-altitude observations of $\mathrm { C H } _ { 4 }$ concentration using continuous tunable laser spectroscopy measurements combined with isotope analyses ${ \ L } ^ { 1 3 } \mathrm { C } , \ L ^ { 1 4 } \mathrm { C } ,$ and D) of discrete samples to constrain urban $\mathrm { C H } _ { 4 }$ sources. Our data indicate that the dominant source of $\mathrm { C H } _ { 4 }$ in Los Angeles has a $\delta ^ { 1 3 } \dot { \mathrm { C } }$ value of approximately $- 4 1 . 5 \text{‰}$ and a $\delta \mathbf { D }$ value between $- 2 2 9$ and $- 2 0 8 \text{‰}$ $\Delta ^ { 1 4 } \mathrm { C }$ of $\mathrm { C H } _ { 4 }$ in urban air samples ranged from $+ 2 6 2$ to $+ 3 4 4 \text{‰}$ (127.1 to $1 3 4 . 9 \ \mathrm { p M C }$ ), depleted with respect to average global background $\mathrm { C H } _ { 4 }$ We conclude that the major source of $\mathrm { C H } _ { 4 }$ in Los Angeles is leakage of fossil fuels, such as from geologic formations, natural gas pipelines, oil refining, and/or power plants. More research is needed to constrain fluxes of $\mathrm { C H } _ { 4 }$ from natural gas distribution and refining, as this flux may increase with greater reliance on natural gas and biogas for energy needs.

# 1．Introduction

[2] Anthropogenic activities have resulted in increasing levels of greenhouse gases, including methane $\mathrm { ( C H _ { 4 } ) }$ ，with current atmospheric mixing ratios that have approximately doubled over the past 20O years [Sowers et al.,2005; MacFarling Meure et al.,2006; Mitchell et al.,2011]. Methane has a global warming potential of about 25 times that of carbon dioxide $\left( \mathrm { C O } _ { 2 } \right)$ on a 100 year time scale [Forster et al., 20o7]. Major global sources of $\mathrm { C H } _ { 4 }$ include wetlands,cattle and other ruminant animal ranching, fires, and rice paddies, but $\mathrm { C H } _ { 4 }$ is also released from landfills and wastewater treatment plants, and during fossil fuel mining and distribution [Cicerone and Oremland,1988; Reeburgh, 2004].Methane is also an important component in the overall oxidative capacity of the troposphere,as it is con-sumed by reaction with atmospheric radicals [Cicerone and Oremland, 1988].

[3] Stable isotopes and radiocarbon have been previously employed to determine sources of both $\mathrm { C O } _ { 2 }$ [e.g., Pataki et al.,2003a; Fisher et al.,2006; Djuricin et al.,2010] and $\mathrm { C H } _ { 4 }$ [Cicerone and Oremland, 1988; Bergamaschi et al., 1998; Kessler et al.,2008; Lowry et al., 2001,2009; Kai et al., 2011]. For $\mathrm { C H } _ { 4 }$ ， $\delta ^ { 1 3 } \mathrm { C }$ and $\delta \mathbf { D }$ ratios can be used to differentiate microbial from thermogenic sources.Microbial $\mathrm { C H } _ { 4 }$ is characterized by $\delta ^ { 1 3 } \mathrm { C }$ values of between $- 5 0 \text{‰}$ and $- 1 1 0 \text{‰}$ and $\delta \mathbf { D }$ values of $- 1 5 0 \text{‰}$ to $- 4 0 0 \text{‰}$ [Cicerone and Oremland,1988; Quay et al., 1991,1999; Whiticar and Schaefer, 2007]. Thermogenic $\mathrm { C H } _ { 4 }$ (generated at high temperature in the Earth's crust,as in fossil fuels) has $\delta ^ { 1 5 } \mathrm { C }$ values between $- 4 5 \text{‰}$ and $- 2 0 \text{‰}$ ,and $\delta \mathrm { D }$ values between $- 1 0 0 \text{‰}$ and $- 2 7 5 \text{‰}$ [Whiticar and Schaefer, 2007]. Consumption of $\mathrm { C H } _ { 4 }$ by methanogenic bacteria or by oxidation with atmospheric radicals generally causes enrichment in both $\delta ^ { 1 3 } \mathrm { C }$ and $\delta \mathbf { D }$ of remaining $\mathrm { C H } _ { 4 }$ [Tyler,1986; Whiticar, 1999; Saueressig et al., 1996, 2001; Snover and Quay,

In contrast, other sources of methane have $^ { 1 4 } \mathrm { C }$ contents that are approximately modern, including rice paddies [Nakagawa et al.,2002], landfills [Coleman et al., 1995], sewage treatment plants [ $O$ 'Sullivan et al.,2010] and catte [Johnson and Johnson,1995]. It is important to note that nuclear power plants and nuclear waste sites emit $^ { 1 4 } \mathrm { C H } _ { 4 }$ without a significant flux of $\mathrm { C H } _ { 4 }$ overall, leading to global background $\Delta ^ { 1 4 } \mathrm { C }$ of $\mathrm { C H } _ { 4 }$ values that are more enriched than atmospheric $\mathrm { C O } _ { 2 }$ [Lassey et al., 2007a, 2007b], although measurements are sparse due to large sample volume requirements and the high cost of radiocarbon dating.

[4] While the global emissions of $\mathrm { C H } _ { 4 }$ are relatively well constrained,regional emissions and the contribution of individual sources to these emissions is not [Bergamaschi et al.,2010; Dlugokencky et al., 2011]. In particular, relative proportion of urban greenhouse gas sources may differ from the magnitude of global sources,which complicates the use of global models for regional source estimation [Townsend-Small et al.,201la,2011b]. For example, studies of tropospheric air in Los Angeles have found that $\mathrm { C H } _ { 4 }$ concentrations are larger than predicted by statewide models [Wunch et al., 2009; Hsu et al.,2010], indicating that some emissions factors for urban areas are missing or underestimated. Studies of $\mathrm { C H } _ { 4 }$ emissions in urban Indianapolis, USA，also showed evidence for significant urban $\mathrm { C H } _ { 4 }$ sources that are not accounted for in greenhouse gas emissions models [Mays et al.,2009]. Studies of $\mathrm { C H } _ { 4 }$ concentrations in St.Petersburg,Russia showed evidence for significant urban emissions,estimated at about $1 0 0  { ~ \mathrm { k T ~ y r } ^ { - 1 } }$ [Nisbet,2005].

[5] A few prior studies have employed stable isotope analyses to determine sources of urban $\mathrm { C H } _ { 4 }$ and have shown that either landfills or natural gas leaks are significant in urban areas. In Krakow, Poland, analyses of $\delta ^ { 1 3 } \mathrm { \bar { C } }$ and $\Delta ^ { 1 4 } \mathrm { C }$ of $\mathrm { C H } _ { 4 }$ showed that natural gas leaking was the dominant source of anthropogenic $\mathrm { C H } _ { 4 }$ in that city [Kuc et al., 2003; Nisbet, 2005]. In London, UK, $\delta ^ { 1 3 } \mathrm { C }$ analyses showed that the dominant sources of $\mathrm { C H } _ { 4 }$ in the urban area were landfills $( \sim 8 0 \%$ of total source) and natural gas distribution systems $( \sim 2 0 \% )$ [Lowry et al., 2001; Fisher et al., 2006].

[6] The objective of this study was to determine whether isotopes could be useful tracers of urban versus natural or agricultural $\mathrm { C H } _ { 4 }$ sources in southern California. We also hoped to use stable isotopes as well as radiocarbon to make preliminary estimates of the dominant source of $\mathrm { C H } _ { 4 }$ in the metropolitan area of Los Angeles, California.

# 2.Methods

# 2.1. Study Area

[7] Los Angeles is one of world's“megacities”with an estimated population of up to 15 million in the metropolitan area,which includes parts of Los Angeles, Orange,Riverside,and San Bernardino counties.The city is constrained by peninsular and transverse mountain ranges with dominant onshore winds (Figure 1),except during occasional wind reversals: the“Santa Ana”winds. This commonly results in atmospheric temperature inversions in the late afternoon that create notorious smog events.In general,wind trajectories are from the ocean to the land during the day,and in the opposite direction in the afternoon,with stronger sea breezes in summer than in winter [Turpin and Huntzicker,1991]. The climate is semiarid/Mediterranean with most rain events occurring during only a few days during winter.

# 2.2. Sample Collection

[8] There were two components of our field sampling campaign: (1) point source identification and sampling around the basin followed by (2) observation and measurement of $\mathrm { C H } _ { 4 }$ concentrations and isotope ratios in urban air sampled at high altitude. For part 1, we sampled a range of potential $\mathrm { C H } _ { 4 }$ sources including fossl fuel sources (oil wells, power plants, oil refinery, and vehicle emissions) as well as biogenic sources (cow breath,landfills,biofuels (from both manure and landfill sources),and sewage treatment plants).These samples were collected from November 2007 to May 2008.All samples were collected using a battery-powered oil-free GAST diaphragm pump through a magnesium perchlorate water trap in preevacuated stainless steel gas canisters ranging in size from 2 to $6 \mathrm { ~ L ~ }$ . The typical flow rate during sampling was about $1 . 5 \mathrm { L } \mathrm { m i n } ^ { - 1 }$ and canisters were filled to approximately 2 atm.

[9] Sampling locations and dates are shown in Tables 1 and 2.Samples of vehicle emissions were taken in the vicinity of downtown LA traffic (S1 and S2, Table 1). Oil field, oil refinery,and power plant samples (S3-S6, Table 1) were taken as close as possible to the source,using a handheld anemometer to ensure that wind was blowing from the source to the sample collection device. Biofuel samples (S8- S12, Table 1) were collected from or near collection systems at biofuel generation plants. Sewage treatment plant air was sampled from just above the surface of the treatment tanks, within the freeboard space to avoid sampling large amounts of background air (Si3 and S14, Table 1). # 2.3.Sample Analysis

[11] Methane concentration was measured on a Shimadzu Scientific Instruments GC-14A gas chromatograph with flame ionization detector (GC-FID). Sample concentrations were referenced to a gas standard $\left( 1 . 9 0 3 ~ \mathrm { p p m } \mathrm { C H } _ { 4 } \right)$ that has been intercompared to NOAA Global Monitoring Division reference standards (CMDL83 scale [Lang et al., 1990]). The precision of this measurement is $\pm 5$ to $1 0 \ \mathrm { p p b }$ ,or about 0.25 to $0 . 5 0 \%$ uncertainty.

[12] Stable isotope ratios were analyzed at the University of California, Irvine using continuous flow isotope ratio mass spectrometry according to the method of Rice et al. [2001],with combustion to $\mathrm { C O } _ { 2 }$ for $\delta ^ { 1 3 } \mathrm { C }$ and pyrolysis to $\mathrm { H } _ { 2 }$ for $\delta \mathbf { D }$ Carbon and hydrogen stable isotope ratios are expressed in delta $( \delta )$ notation, where the ratio of the rare to abundant isotope is expressed relative to an internationally recognized standard (PeeDee Belemnite (PDB) and Vienna Standard Mean Ocean Water (VSMOW), respectively). The uncertainties of $\delta ^ { 1 3 } \mathrm { C }$ and $\delta \mathbf { D }$ measurements have been estimated at $0 . 0 5 \text{‰}$ and $1 . 1 \text{‰}$ ，respectively.Extended details about calibration standards for $\delta ^ { 1 3 } \mathrm { C }$ and $\delta \mathbf { D }$ are included in the work by Tyler et al. [2007]. # 3.Results

# 3.1. Stable Isotope Composition of $\mathbf { C H _ { 4 } }$ From Urban Sources

[15] Results for point source measurements of $\mathrm { C H } _ { 4 }$ concentration, $\delta ^ { 1 3 } \mathrm { C }$ ,and $\delta \mathbf { D }$ are shown in Table 1 and Figure 2. Figure 2 shows the background-corrected source signature values of $\delta ^ { 1 3 } \mathrm { C }$ and $\delta \mathbf { D }$ for $\mathrm { C H } _ { 4 }$ sampled in the Los Angeles basin. Fossil fuel $\mathrm { C H } _ { 4 }$ (solid symbols in Figure 2) was enriched in $^ { 1 3 } \mathrm { C }$ and $\mathrm { D }$ ，whereas biological sources were more depleted in both isotopes (open symbols in Figure 2). Fossil fuel derived samples had $\delta ^ { 1 3 } \mathrm { C }$ values above $- 4 5 \text{‰}$ and $\delta \mathbf { D }$ values above about $- 2 7 5 \text{‰}$ (Figure 2). Biological samples had $\delta ^ { 1 3 } \mathrm { C }$ values below about $- 5 0 \text{‰}$ and $\delta \mathbf { D }$ below $- 2 7 5 \text{‰}$ .In general, separation between fossil and biological $\mathrm { C H } _ { 4 }$ was better for $\delta ^ { 1 3 } \mathrm { { C } }$ than for $\delta \mathbf { D }$ (Figure 2). Samples taken in enclosed parking garages and traffic tunnels had very enriched $\delta ^ { 1 3 } \mathrm { C }$ and $\delta \mathbf { D }$ values,at the high end of our measurement range, similar to previous studies [Nakagawa et al., 20o5]. Some point source isotope values were derived from relatively small enrichments in $\mathrm { C H } _ { 4 }$ concentrations,which may increase uncertainty (see Table 1).

# 4．Discussion

# 4.1.Isotopic Composition of Point Source $\mathbf { C H _ { 4 } }$

[19] Measurements of fossil fuel and biological $\mathrm { C H } _ { 4 }$ sources in the Los Angeles generally agree with previous work showing that fossil sources are more enriched in both $^ { 1 3 } \mathrm { C }$ andDthan biologicalsources[Cicerone andOremland 1988;Whiticar, 1999]. We also provide some new information on emerging urban $\mathrm { C H } _ { 4 }$ sources,including the stable isotope composition of $\mathrm { C H } _ { 4 }$ of biofuels (from both landfills and manure) and sewage treatment plants.

[20] Biofuels are likely to encompass a larger portion of southern California's energy portfolio as fossil fuel prices rise and as the state enforces greenhouse gas emissions limits. Interestingly,we found large differences in $\delta ^ { 1 3 } \mathrm { C }$ in twotypesof biofuels (landfill $( - 6 1 \text{‰}$ and manure $( - 5 1 \text{‰}$ ，but similar $\delta \mathbf { D }$ values( $- 2 8 0$ to $- 3 3 0 \text{‰}$ (Figure 2). At the (closed) landfills we sampled, $\mathrm { C H } _ { 4 }$ is extracted by pumping through a network of pipelines. In general in California,closed landfills are managed in this way to provide fuel for trash collection vehicles.We sampled landfill biofuel (about $3 0 \% \mathrm { C H } _ { 4 } )$ ）directly from this system. The vacuum system likely prevents consumption of $\mathrm { C H } _ { 4 }$ by soil microbes in upper layers of the landfill. Previous analyses of $\delta ^ { 1 3 } \mathrm { C }$ of $\mathrm { C H } _ { 4 }$ from diffuse landfill emissions are more enriched than our landfill biofuel measurements, likely due to $\mathrm { C H } _ { 4 }$ oxidation in cover soils [Chanton et al., 1999, 2008]. Biofuels derived from cow manure, however, are more enriched in $^ { 1 3 } \mathrm { C }$ and, to a lesser degree D, than $\mathrm { C H } _ { 4 }$ measured on cattle feedlots (Figure 2 and Table 1). The manure biofuel test facility we visited was an anaerobic digester supplied with manure from off-site facilities,and relies on increased microbial activity in the digester to create greater $\mathrm { C H } _ { 4 }$ production than at feedlots,with increased enrichment in stable isotope composition.

[21] Our data show that sewage treatment plants in the Los Angeles area emit $\mathrm { C H } _ { 4 }$ (Table 1),and we have previously shown that these systems are a large source of $\mathrm { N } _ { 2 } \mathrm { O }$ in the region [Townsend-Small et al., 20i1b]. In water recycling systems where denitrification is enhanced, $\mathrm { C H } _ { 4 }$ may be emitted as a by-product of low oxygen conditions. Only a handful of previous studies have analyzed the isotopic composition of $\mathrm { C H } _ { 4 }$ derived from sewage treatment. In a nitrification-denitrification plant in Japan, Toyoda et al. [2011] found $\mathrm { C H } _ { 4 }$ emissions of $1 4 . 1 \ \mathrm { \ m g } \ \mathrm { C H } _ { 4 } \ \mathrm { \dot { m } } ^ { - 3 }$ ，with a $\bar { \delta } ^ { 1 3 } \mathrm { C }$ signature of $- 5 0 . 7 \text{‰}$ ,depleted with respect to background air. Methane emissions from sludge digester-type treatment plants may be even higher, but we do not know the isotopic composition of such $\mathrm { C H } _ { 4 }$ .No previous study has measured the $\delta \mathbf { D }$ of $\mathrm { C H } _ { 4 }$ from sewage treatment plants, but this is deserving of future research,as our preliminary data show that this source may be isotopically distinct from biological and fossil fuel sources.A better understanding of the $\mathrm { C H } _ { 4 }$ flux from sewage treatment in this region is also needed, as wastewater recycling is an important component of the water management portfolio in arid southern California.

[22] There is a small but increasing amount of evidence that C in wastewater treatment plants is not entirely modern, either because of fossil C in detergents and pharmaceuticals [Griffith et al.,20o9],or due to methanol added to support denitrification [Townsend-Small et al.,2011b]. One study in Japan found dissolved organic C in sewage treatment plants with $^ { 1 4 } \mathrm { C }$ ages up to 5000 years old [Nara et al.,2010], and rivers in northern California have dissolved organic C with low radiocarbon content, perhaps due to the presence of wastewater in urban rivers [Sickman et al.,2010]. We did not make direct measurements of $\Delta ^ { 1 4 } \mathrm { C }$ of $\mathrm { C H } _ { 4 }$ from wastewater treatment plants in the area, but we have found that $\mathrm { C O } _ { 2 }$ sampled from wastewater treatment tanks contains up to $1 0 \%$ fossil carbon (X. # 4.2. Isotopic Constraints on Sources of $\mathbf { C H _ { 4 } }$ in Los Angeles

# 4.2.1． Stable Isotopes

[23] Our lowest observations of $\mathrm { C H } _ { 4 }$ in air at Mount Wilson $( \sim 1 . 7 6 \ \mathrm { p p m } )$ were depleted in $\mathrm { C H } _ { 4 }$ with respect to the nearest background air monitoring site (Figure 3a). This concentration likely represents the annual minimum in $\mathrm { C H } _ { 4 }$ concentration at our site,as,in general, $\mathrm { C H } _ { 4 }$ is lower in summer than winter in other Northern Hemisphere sites [Lowry et al., 2009; Dlugokencky et al., 2010]. The NOAA flask sampling network reports an average $\mathrm { C H } _ { 4 }$ concentration in August 2009 of $1 . 8 2 \ \mathrm { p p m }$ at Trinidad Head, California[Dlugokenckyetal.， 2010]. Thisindicates consumption of $\mathrm { C H } _ { 4 }$ by interaction with OH or other radicals in the urban atmosphere at our study site,which is high in concentration in the summer months [Seinfeld,1989; Griffin et al., 2004; Langford et al., 2010]. Previous studies have also documented that $\mathrm { C H } _ { 4 }$ concentrations drop in the summer months in response to high oxidation rates in the atmosphere [Tyler et al., 2007]. Our measurements of urban air at high altitude indicate that excess $\mathrm { C H } _ { 4 }$ in Los Angeles has a $\delta ^ { \Gamma 3 } \mathrm { C }$ of approximately $- 4 1 . 5 \text{‰}$ and a $\delta \mathbf { D }$ between $- 2 0 3 \text{‰}$ and $- 2 2 8 \text{‰}$ (Figure 4). Assuming depletion of $\mathrm { C H } _ { 4 }$ by $0 . 1 \ \mathrm { p p m }$ that is uniform across the concentration gradient measured, we can assume that our estimates of the $\mathrm { C H } _ { 4 }$ end-members are depleted by up to $4 \text{‰}$ for $\delta ^ { 1 3 } \mathrm { C }$ and $20 \text{‰}$ for $\delta \mathrm { D }$ [Saueressig et al., 2001]. This places our endmember close to our measurements from oil fields and power plants (Figure 2). Our estimates would be improved by incorporating tracers to track air masses moving through the urban core and up to our sampling site, such as $^ { 2 2 2 } \mathrm { R n }$ or by incorporating measurements of other fossil fuel tracers, such as ${ } ^ { \mathrm { i } 4 } \mathrm { C O } _ { 2 }$ or CO.Measurements of conservative tracers as well as trajectory analysis would enable us to translate our measurements into emission rates.

[24] Our data indicate that $\mathrm { C H } _ { 4 }$ loss from geologic formations, natural gas pipelines and/or fossil fuel refining was the major source of $\mathrm { C H } _ { 4 }$ in the Los Angeles Basin during our brief sampling period. Longer-term studies are needed to confirm that this is the major source of $\mathrm { C H } _ { 4 }$ throughout the year. This finding is in keeping with an earlier study[Wunch et al.，20o9],which estimated that gas leaks and other industrial sources could account for about 0.1 to $0 . 3 \mathrm { T g } \mathrm { C H } _ { 4 }$ emitted in Los Angeles annually. A recent study by the California Air Resources Board also indicated that leakage from natural gas infrastructure and distribution systems ("fugitive" $\mathrm { C H } _ { 4 }$ )may be underestimated in statewide models [Hsu et al.,2010]. Estimates of fugitive $\mathrm { C H } _ { 4 }$ emission rates vary widely, ranging from $0 . 0 0 5 \%$ to $4 \%$ ，[Shorter et al., 1996; Kirchgessner et al., 1997; Lelieveld et al., 2005], with estimates for the entire natural gas industry of up to $1 0 \%$ ，including emissionsfrom ventingand flaring [Cicerone and Oremland,1988; Kirchgessner et al., 1997]. However, there are very few published studies of fugitive $\mathrm { C H } _ { 4 }$ emission rates in urban areas,despite very extensive natural gas pipelines present in most cities.Studies of $\delta ^ { 1 3 } \mathrm { C } .$ $\mathrm { C H } _ { 4 }$ in Krakow,Poland, found excess $\mathrm { C H } _ { 4 }$ concentrations attributed to leakage from natural gas pipelines [Kuc et al., 2003],and fossil fuel leakage is a significant source of $\mathrm { C H } _ { 4 }$ in London, UK ( $\sim 2 0 \%$ of total urban $\mathrm { C H } _ { 4 }$ emissions) [Lowry et al., 2001; Fisher et al., 2006]. In addition to natural gas pipelines,Los Angeles also has several large oil refineries, which process most of the crude oil from the Alaskan North Slope. These facilities are known sources of $\mathrm { C H } _ { 4 }$ ,as are electric utilities [Piccot et al.,1996]. Because of the higher global warming potential of $\mathrm { C H } _ { 4 }$ with respect to $\mathrm { C O } _ { 2 }$ , fugitive $\mathrm { C H } _ { 4 }$ emissions of even $1 \%$ of natural gas in a distribution system will increase the overall global warming potential of natural gas consumption by $2 5 \%$ [Howarth et al.,2011]. This is a growing concern as biogas production and domestic natural gas exploration, including from shale deposits ("hydrofracking"), increases.

[25] Our measurements of $\mathbf { \check { \delta } } ^ { 1 3 } \mathbf { \check { C } }$ of $\mathrm { C H } _ { 4 }$ on freeways during rush hour (Table 2) do not indicate a large source of highly enriched $\mathrm { C H } _ { 4 }$ from vehicle emissions (Figure 2). This is not surprising,as other studies have also shown that vehicle exhaust is a minor source of atmospheric $\mathrm { C H } _ { 4 }$ [Tyler, 1991; Chanton et al., 2000; Mays et al., 2009].

[26] Direct emissions of $\mathrm { C H } _ { 4 }$ from vehicles are not considered a significant portion of the global $\mathrm { C H } _ { 4 }$ budget [Forster et al.,2007]: one group estimated that direct emissions from vehicles accounted for about $0 . 5 \ \mathrm { T g } \ \mathrm { C H } _ { 4 }$ $\mathrm { y r } ^ { - 1 }$ globally,or about $0 . 2 \%$ of annual anthropogenic $\mathrm { C H } _ { 4 }$ emissions [Nam et al., 2004]. Amendments to the Clean Air Act in 1990 restricted total hydrocarbon emissions from passenger cars to $0 . 1 6 \ \mathrm { g } \ \mathrm { k m } ^ { - 1 }$ , and up to $0 . 2 4 ~ \mathrm { g ~ k m } ^ { - 1 }$ for trucks [U.S. Environmental Protection Agency (USEPA), 2004]. Actual $\mathrm { C H } _ { 4 }$ emissions from gasoline-powered cars in this category (built since 1990) range from 0.007 to $0 . 0 1 2 \ \mathrm { g } \ \mathrm { k m } ^ { - 1 }$ ，with an additional $0 . 0 5 5 \ \mathrm { g } \ \mathrm { C H } _ { 4 }$ emitted per cold start [USEPA, 2004]. Interstate 405, the most crowded freeway in Los Angeles, has an average of 374,0oo cars per day at the busiest interchanges (California Department of Transportation, Annual average daily trafic statistics, 2009, http://traffic-counts.dot.ca.gov). The average commuting distance in California is $4 0  { \mathrm { k m } }  { \mathrm { d } } ^ { - 1 }$ ,or about $2 6 . 7 \ \mathrm { m i n \ d ^ { - 1 } }$ [U.S. Department of Transportation, 2001]. At $0 . 0 0 7 \mathrm { g } \mathrm { C H } _ { 4 }$ $\mathrm { \bar { k } m } ^ { - 1 }$ plus an additional $0 . 0 5 5 \ : \mathrm { g } \ : \mathrm { C H } _ { 4 }$ per start (and assuming all of the cars have been built since 199O and are started 2 times per day),vehicles contribute $2 2 7 \ \mathrm { k g } \ \mathrm { C H } _ { 4 } \ \mathrm { d } ^ { - 1 }$ in Los Angeles, or about $8 3 , 0 0 0 \mathrm { \ k g \ C H _ { 4 } \ y r } ^ { - 1 }$ . This is only a small fraction of estimated annual $\mathrm { C H } _ { 4 }$ emissions in Los Angeles of between 0.2 to $0 . 6 \mathrm { \ T g \ C H _ { 4 } \ y r ^ { - 1 } }$ (2 to $6 \times 1 0 ^ { 8 } \mathrm { k g \ y r ^ { - 1 } } ,$ [Wunch et al.,2009; Hsu et al.,2010].

[27] More surprisingly, our measurements do not indicate a large source of $\mathrm { C H } _ { 4 }$ from landfills or wastewater treatment in Los Angeles.However, in London,UK,a comparable sized city (population ${ \sim } 1 3$ million), landfills are the dominant source of urban $\mathrm { C H } _ { 4 }$ [Lowry et al., 2001; Fisher et al., 2006]. Globally, landfills and wastewater are a large source of $\mathrm { C H } _ { 4 }$ ,with estimates ranging from 6 to $12 \%$ of total global $\mathrm { C H } _ { 4 }$ emissions [Denman et al., 2007]. This contribution is expected to be much larger in urban areas,especially in generally dry regions,such as southern California,without significant wetland area. However, California regulates $\mathrm { C H } _ { 4 }$ emissions from landfills,and the state is at the forefront of natural gas reclamation from landfills to provide fuel for trash collection vehicles.The contribution of wastewater treatment to $\mathrm { C H } _ { 4 }$ emissions in Los Angeles is not well understood,and more studies are needed on the flux and stable isotopic composition of $\mathrm { C H } _ { 4 }$ from wastewater treatment plants, especially as the region incorporates more biological wastewater recycling techniques to conserve freshwater resources [Townsend-Small et al.,2011b]. However, our isotopic measurements do not indicate that this is a major source of $\mathrm { C H } _ { 4 }$ in the Los Angeles area.

# 4.2.2．Radiocarbon

[28] The radiocarbon content of atmospheric $\mathrm { C H } _ { 4 }$ is globally higher than that of $\mathrm { C O } _ { 2 }$ ,due largely to the release of radiocarbon-labeled $\mathrm { C H } _ { 4 }$ from nuclear power facilities and atmospheric nuclear weapons testing [Lassey et al., 2007b]. Most recent evidence shows that $\mathrm { \Delta \bar { \Delta } ^ { 1 4 } C }$ of $\mathrm { C H } _ { 4 }$ of background air has increased linearly since at least the mid-1980s, to a present-day value of about $1 3 8 . 9 \ \mathrm { p M C }$ (extrapolated from Figure 1 [Lassey et al.,2007b]). The flux of $^ { 1 4 } \mathrm { C H } _ { 4 }$ from nuclear reactors is mostly from pressurized water reactors and results from deprotonation of $\mathrm { ^ { 1 4 } N }$ and reaction with $\mathrm { H } _ { 2 }$ ，resulting in venting of radio-labeled $\mathrm { C H } _ { 4 }$ and other reduced C species [Lassey et al., 2007b]. However,this flux is poorly quantified,and $\mathrm { C H } _ { 4 }$ from these sources is approximately $70 \%$ $^ { 1 4 } \mathrm { C }$ [Lassey et al., 2007a, 2007b]. At least one other study in southern California has also shown that $\mathrm { C H } _ { 4 }$ dissolved in surface ocean water is enriched in $^ { 1 4 } \mathrm { C }$ as compared to modern C [Kesser et al., 2008]. There are no nuclear power plants located directly in the Los Angeles air basin, but there is one pressurized water reactor just south of the Los Angeles basin (San Onofre Nuclear Generating Station, San Clemente; Figure 1) and one further north (Diablo Canyon Power Plant; San Luis Obispo county).

[29] Despite the radiomethane contribution from nuclear power plants, high $\Delta ^ { 1 4 } \mathrm { C }$ levels in atmospheric $\mathrm { C H } _ { 4 }$ are tempered by the release of $^ { 1 4 } \mathrm { C }$ -free $\mathrm { C H } _ { 4 }$ from fossil fuel sources [Wahlen et al.,1989; Lassey et al.,2007b]. Previous analyses of $\Delta ^ { 1 4 } \mathrm { C }$ of $\mathrm { C H } _ { 4 }$ have found that about $20 \%$ to $30 \%$ of $\mathrm { C H } _ { 4 }$ globally is $^ { 1 4 } \mathrm { C }$ -free, or of fossil origin [Wahlen et al., 1989; Quay et al.,1999; Lassey et al.,2007bj. It is difficult to use our measurements of $\Delta { } ^ { 1 4 } \mathrm { C - C H _ { 4 } }$ to calculate the fossil fuel fraction of $\mathrm { C H } _ { 4 }$ emissions in Los Angeles, due to high variability in our radiocarbon dates and due to the lack of relationship to $\mathrm { C H } _ { 4 }$ concentration. For example,our mea-surements of $\Delta ^ { 1 4 } \mathrm { C }$ in background air $( 1 . 7 6 \mathrm { p p m } )$ range from $+ 2 6 1 . 9 \text{‰}$ to $+ 3 3 9 . 8 \text{‰}$ ,0r 127.1 to $1 3 4 . 9 \mathrm { p M C }$ ,which more or less represents the range of $\Delta ^ { 1 4 } \mathrm { C }$ of $\mathrm { C H } _ { 4 }$ measurements along the entire concentration gradient in thisstudy (Figure 3d and Table 3). However,our data do generally indicate the presence of fossil fuel-derived $\mathrm { C H } _ { 4 }$ in air in the Los Angeles basin: the current global background $\Delta ^ { 1 4 } \mathrm { C }$ of $\mathrm { C H } _ { 4 }$ of $\mathsf { \bar { 1 } 3 8 . 9 \ p M C }$ [Lassey et al., 2007b] is greater than all of the air samples analyzed in this study. Certainly more research is needed to constrain the background value of $\Delta ^ { 1 4 } \mathrm { C }$ of $\mathrm { C H } _ { 4 }$ in air in southern California as well as other urban areas,which can aid in constraining contributions of fossil fuels to total $\mathrm { C H } _ { 4 }$ emissions.

# 4.3.Potential for Optical, in Situ Measurements to Determine Sources of $\mathbf { C H _ { 4 } }$ Emissions

[30] Continuous measurements of greenhouse gas concentrations,such as those presented here,will likely be essential to any attempt to monitor emissions reductions targets,and stable isotopes and radiocarbon will be extremely useful in source apportionment [Levin et al., 2011]. Recent technological advances have shown that the stable isotopic composition of $\mathrm { C H } _ { 4 }$ can also be measured using optical techniques,with a strong interest in constraining $\mathrm { C H } _ { 4 }$ sources [Quay et al.,1999; Webster and Mahaffy, 201i]. However, currently these instruments generally have decreased accuracy as compared to IRMS systems [Zare et al.,2009; Webster,2005],and work best with $\mathrm { C H } _ { 4 }$ that is much higher than atmospheric concentrations and/or pressures [Bergamaschi et al., 20oo; Keppler et al., 2010]. Because of the high background concentration of $\mathrm { C H } _ { 4 }$ in Earth's atmosphere and relatively small contribution of source $\mathrm { C H } _ { 4 }$ ,measurements of the isotopic composition of $\mathrm { C H } _ { 4 }$ in air with excess $\mathrm { C H } _ { 4 }$ are similar to those in back-ground air. For example, in this study, $\delta ^ { 1 3 } \mathrm { C }$ of $\mathrm { C H } _ { 4 }$ in Los Angeles air varied less than $1 . 5 \text{‰}$ along a concentration gradient from 1.7 to $2 . 2 \mathrm { \ p p m }$ (Figure 3b). Until TLS instruments are able to accurately measure small (i.e., $\text{‰}$ for $\delta ^ { 1 3 } \mathrm { C } )$ differencesin $\delta ^ { 1 3 } \mathrm { C }$ of $\delta \mathbf { D }$ of $\mathrm { C H } _ { 4 }$ at normal atmospheric concentrations and pressures, mass spectrometry remains the more practical tool for source determination. However,we have shown that the combination of TLS concentration measurements and IRMS isotope measurements of these parameters is a very promising tool for monitoring $\mathrm { C H } _ { 4 }$ emissions and source identification in urban areas or along urban-to-rural gradients.In our study, we used concentration data from the TLS instrument to time our flask sampling for later isotope analysis,so that our isotope measurements would represent the maximum possible concentration gradient.

# 5. Conclusions and Implications

[31] We have shown that $\delta ^ { 1 3 } \mathrm { C }$ and $\delta \mathbf { D }$ of atmospheric methane can be very useful for elucidating urban sources of $\mathrm { C H } _ { 4 }$ . We also present data on new sources of $\mathrm { C H } _ { 4 }$ fuel in our measurements of isotope ratios of landfill and manure biofuels. Radiocarbon measurements of $\mathrm { C H } _ { 4 }$ in_our study region show that high background values of $\Delta ^ { 1 4 } \mathrm { C }$ of $\mathrm { C H } _ { 4 }$ may be diluted by inputs of fossil fuel $\mathrm { C H } _ { 4 }$ ，but long-term monitoring is necessary to better understand the patterns of radiomethane in Los Angeles.However, stable isotope measurements of $\mathrm { C H } _ { 4 }$ in Los Angeles indicate that fossil fuels, not agriculture, are the dominant source of $\mathrm { C H } _ { 4 }$ in this region,with evidence pointing toward losses from natural gas pipelines or hydrocarbon refining as the dominant source in the region. Further work on $\delta ^ { 1 3 } \bar { \mathrm { C } }$ and $\delta \mathbf { D }$ of $\mathrm { C H } _ { 4 }$ in Los Angeles will improve our ability to quantify the strength of these $\mathrm { C H } _ { 4 }$ sources. This type of observation will be improved by continuous measurements of $\mathrm { C H } _ { 4 }$ concentration using TLS.In general, continuous measurements of greenhouse gas concentrations supplemented with isotope ratio measurements are extremely useful tools for verifying emissions reductions and for constraining regional-scale inversion modeling of emissions.
