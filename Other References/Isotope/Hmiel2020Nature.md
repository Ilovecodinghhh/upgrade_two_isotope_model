Atmospheric methane $\mathrm { ( C H _ { 4 } ) }$ is a potent greenhouse gas,and its mole fraction has more than doubled since the preindustrial eral.Fossil fuel extraction and use are among the largest anthropogenic sources of $\mathrm { C H } _ { 4 }$ emissions,but the precise magnitude ofthese contributions is a subject of debate²3.Carbon-14 in $\mathrm { C H } _ { 4 } ( ^ { 1 4 } \mathrm { C H } _ { 4 } )$ can be used to distinguish between fossil( $^ { \circ 1 4 } { \mathrm { C } }$ -free) $\mathrm { C H } _ { 4 }$ emissions and contemporaneous biogenic sources;however,poorly constrained direct $^ { 1 4 } { \mathrm { C H } } _ { 4 }$ emissions from nuclear reactors have complicated this approach since the middle of the 20th century4,5. Moreover,the partitioning oftotal fossil $\mathrm { C H } _ { 4 }$ emissions (presently 172 to 195 teragrams $\mathrm { C H } _ { 4 }$ per year)2³ between anthropogenic and natural geological sources (such as seeps and mud volcanoes) is under debate; emission inventories suggest that the latter account for about 4O to 6O teragrams $\mathrm { C H } _ { 4 }$ per year6.7. Geological emissions were less than 15.4 teragrams $\mathrm { C H } _ { 4 }$ per year at the end of the Pleistocene,about 1l,6oo years ago&,but that period is an imperfect analogue for present-day emissions owing to the large terrestrialice sheet cover,lower sea level and extensive permafrost. Here we use preindustrial-era ice core $^ { 1 4 } { \mathrm { C H } } _ { 4 }$ measurements to show that natural geological $\mathrm { C H } _ { 4 }$ emissions to the atmosphere were about 1.6 teragrams $\mathrm { C H } _ { 4 }$ per year,with a maximum of 5.4 teragrams $\mathrm { C H } _ { 4 }$ per year(95 per cent confidence limit)-an order of magnitude lower than the currently used estimates. This result indicates that anthropogenic fossi $\mathrm { C H } _ { 4 }$ emissions are underestimated by about 38 to 58 teragrams $\mathrm { C H } _ { 4 }$ per year,or about 25 to 40 per cent of recent estimates. Our record highlights the human impact on the atmosphere and climate,provides a firm target for inventories ofthe global $\mathrm { C H } _ { 4 }$ budget,and willhelp to inform strategies for targeted emission reductions9,10.

Atmospheric measurements of carbon-13 in methane $( \delta ^ { 1 3 } \mathrm { C H } _ { 4 } )$ have been used to estimate the fossil fraction ofthe contemporaneous $\mathrm { C H } _ { 4 }$ budget.This approach relies on having accurate estimates of the $\delta ^ { 1 3 } \mathsf C$ signatures of the major $\mathrm { C H } _ { 4 }$ source categories (fossil, microbial and biomass burning) and the strength of the biomass burning source. Large uncertainties in these parameters in the past preclude accurate $\ S ^ { 1 3 } { \mathrm { C H } } _ { 4 }$ based estimates of preindustrial-era fossil $\mathrm { C H } _ { 4 }$ emissions&,11,12. Radiocarbon ${ } ^ { ( 1 4 } \mathrm { C ) }$ is an idealtracer for quantifying the fossilcomponent ofthe atmospheric $\mathrm { C H } _ { 4 }$ budgetbecause all $^ { 1 4 } \mathrm { C }$ in fossil $\mathrm { C H } _ { 4 }$ has decayed. By contrast,biogenic $\mathrm { C H } _ { 4 }$ sources (wetlands,biomass burning) have a $^ { 1 4 } \mathrm { C }$ activity similar to that of contemporaneous atmospheric $\mathbf { C O } _ { 2 }$ (ref. $^ { 4 , 8 }$ ).Interpretationofatmospheric $^ { 1 4 } { \mathrm { C H } } _ { 4 }$ measurements from1987-2000 suggests that the fossil fraction of the contemporary $\mathrm { C H } _ { 4 }$ budget is

$3 0 \pm 2 . 3 \%$ (ref.13; $1 \sigma )$ .However,the interpretation of atmospheric $^ { 1 4 } { \mathrm { C H } } _ { 4 }$ in recent decades has been complicated by(1) rapidly changing atmospheric ${ } ^ { 1 4 } \mathrm { C O } _ { 2 }$ (from above-ground nuclear testing and fossil fuel emissions) that propagates into biospheric $\mathrm { C H } _ { 4 }$ emissions13,and (2) direct $^ { 1 4 } { \mathrm { C H } } _ { 4 }$ emissions from nuclear power plants45.
