Keywords: Methane trends Methane isotopes Isotopic signatures Chemistry-climate model

The atmospheric methane growth rate has fluctuated over the past three decades,signifying variations in methane sources and sinks.Methane isotopic ratios $( \delta ^ { 1 3 } \mathrm { C H } _ { 4 } )$ differ between emission categories,and can therefore be used to distinguish which methane sources have changed. However,isotopic modeling studies have mainly focused on uncertainties in methane emissions rather than uncertainties in isotopic source signatures.We simulated atmospheric $\delta ^ { 1 3 } \mathrm { C H } _ { 4 }$ for the period 1990-2010 using the global chemistry-climate model SOCOL. Empirically-derived regional variability in the isotopic signatures was introduced in a suite of sensitivity simulations.These simulations were compared to a baseline simulation with commonly used global mean isotopic signatures.We investigatedcoal,natural gas/oil,wetland,livestock,and biomass burning source signatures to determine whether regional variations impact the observed isotopic trend and spatial distribution.Based on recently published source signature datasets,our calculated global mean isotopic signatures are in general lighter than the commonly used values.Trends in several isotopic signatures were also apparent during the period 1990-201o.Tropical livestock emissions grew during the 20o0s,introducing isotopically heavier livestock emissions since tropical livestock consume more $\mathrm { C } _ { 4 }$ vegetation than midlatitude livestock. Chinese coal emissions,which are isotopically heavy compared to other coals,increase during the 2Ooos leading to higher global values of $\delta ^ { 1 3 } \mathrm { C H } _ { 4 }$ for coal emissions.EDGAR $\mathtt { v 4 . 2 }$ emissions disagree with the observed atmospheric isotopic trend for almost all simulations,confirming past doubts about this emissons inventory.The agreement between the modelled and observed $\delta ^ { 1 3 } \mathrm { C H } _ { 4 }$ interhemispheric differences improves when regional source signatures are used.Even though the simulated results are highly dependent on the choice of methane emission inventories,they emphasize that the commonly used global mean signatures are inadequate.Regional isotopic signatures should be employed in modelling studies that try to constrain methane emisson inventories.

# 1. Introduction

Due to its significance in climate studies and atmospheric chemistry, methane $\mathrm { ( C H _ { 4 } ) }$ warrants extensive scientific attention. $\mathrm { C H } _ { 4 }$ is the second most important anthropogenic greenhouse gas after carbon dioxide $\left( \mathrm { C O } _ { 2 } \right)$ ,with a Global Warming Potential (GWP) of 32 over a 100 year period (Etminan et al., 2016). $\mathrm { C H } _ { 4 }$ also alters the oxidative capacity of the atmosphere by reacting with hydroxyl (OH) radicals,impacting the lifetime of other airborne compounds (Hartmann et al., 2013). $\mathrm { C H } _ { 4 }$ emission reductions could help mitigate climate change in the near-term,as the relatively short lifetime of $\mathrm { C H } _ { 4 }$ will lead to more immediate decreases in radiative forcing compared to $\mathrm { C O } _ { 2 }$ (Kirschke et al.,2Ol3).For reliable future predictions of climate,the past behavior of atmospheric $\mathrm { C H } _ { 4 }$ must be better understood.

The growth rate of $\mathrm { C H } _ { 4 }$ was highly variable in the recent past: decelerating during the 1980s and 1990s,stabilizing at zero growth between 1999 and 2006,and increasing again after 2007 (Kirschke et al., 2013; Nisbet et al., 2016; Saunois et al., 2016). Much of the recent $\mathrm { C H } _ { 4 }$ research has focused on the changes in $\mathrm { C H } _ { 4 }$ sources and sinks that led to this growth rate pattern (e.g. Rigby et al., 2O17; Turner et al., 2017).

Multiple studies have used stable isotopes to decipher the mechanisms behind the inter-annual variability of $\mathrm { C H } _ { 4 }$ emissions and sinks (Monteil et al., 2011; Kai et al., 2011; Levin et al., 2012; Nisbet et al., 2014; Ghosh et al., 2015; Schaefer et al., 2016; Schwietzke et al., 2016; Nisbet et al., 2016). The isotopic ratio ${ \binom { 1 3 } { \phantom { 1 3 } } } \mathrm { C } / { } ^ { 1 2 } \mathrm { C } )$ of $\mathrm { C H } _ { 4 }$ emitted to the atmosphere varies for different sources.The variation in the emitted $\mathrm { C H } _ { 4 }$ isotopic ratio depends on three factors:the isotopic ratio of the initial source material (e.g. dissolved $\mathrm { C O } _ { 2 }$ in a wetland), fractionation during the production process (e.g.methanogenesis by bacteria in the wetland),and whether/how much oxidation occurs before the $\mathrm { C H } _ { 4 }$ is emitted to the atmosphere (e.g. $\mathrm { C H } _ { 4 }$ is partly oxidized in the topsoil of the wetland before emission) (Gros et al., 2004; Fisher et al., 2017).The $\mathrm { C H } _ { 4 }$ source categories have different (yet overlapping) ranges of isotope ratios,with pyrogenic $\mathrm { C H } _ { 4 }$ (e.g.biomass burning) being the heaviest source for carbon isotopes, then thermogenic sources (e.g.extraction of certain fossil fuels),and lastly biogenic $\mathrm { C H } _ { 4 }$ (e.g.microbes in wetlands, livestock,etc.) (Kirschke et al.,20l3). The chemical sinks of $\mathrm { C H } _ { 4 }$ also alter the atmospheric $\mathrm { C H } _ { 4 }$ isotope ratio due to distinct isotopologue reactivities.Heavier isotopologues react slower than their lighter counterparts; sinks thus lead to an enrichment of the heavier isotopologues in the atmosphere.Measurements of the $\mathrm { C H } _ { 4 }$ isotopic ratios can provide insight into changes in the $\mathrm { C H } _ { 4 }$ sources and sinks.

The intensified $\mathrm { C H } _ { 4 }$ growth after 2oo7 coincided with a global decrease in $\delta ^ { 1 3 } \mathrm { C H } _ { 4 }$ (White et al., 2Ol7). Several studies therefore attribute the $\mathrm { C H } _ { 4 }$ increase to biogenic sources:augmented wetlands emissions (Dlugokencky et al., 2009, 2011; Bousquet et al., 2011; Bloom et al., 2010; Kirschke et al., 2013; Nisbet et al., 2014, 2016) or agricultural emissions in the tropics (Patra et al., 2016; Schaefer etal., 2016; Nisbet et al.,2Ol6).Nevertheless,others suggest that fossil fuels contributed to the post-2007 $\mathrm { C H } _ { 4 }$ growth,through increased Asian coal mining emissions or expanded shale gas exploitation by the United States (Kirschke et al., 2013; Bergamaschi et al., 2013; Hausmann et al., 2016; Rice et al.,20l6). The interpretation of the $\mathrm { C H } _ { 4 }$ isotopic record is central in the attempts to explain the recent $\mathrm { C H } _ { 4 }$ increase.

Past modelling studies have mostly used global mean isotopic signatures,with litle consideration of regional variability in the signatures.As well,the published global mean isotopic signatures are based on limited data and may not be accurate (Zazzeri et al., 2016; Schwietzke et al., 2O16). Empirical data has underlined the variability of isotopic signatures.For example,the commonly used coal $\mathrm { C H } _ { 4 }$ signature of- $3 5 \text{‰}$ is valid only for anthracite coal; lower rank coal can be lighter by up to $30 \text{‰}$ .Additionally,coal mined at the surface emits lighter $\mathrm { C H } _ { 4 }$ than deeper coal, due to biogenic $\mathrm { C H } _ { 4 }$ that is produced after water incursions (Zazzeri et al.,2015,2Ol6). Natural gas/oil $\mathrm { C H } _ { 4 }$ emissions can also vary in their isotopic signatures (Sherwood et al., 2016).Biomass burning and livestock $\mathrm { C H } _ { 4 }$ isotopic ratios depend on whether ${ \mathrm { C } } _ { 3 }$ or ${ \mathrm { C } } _ { 4 }$ vegetation is being burned or consumed (Rust, 1981; Lassey et al.,2007). The ${ \mathrm { C } } _ { 3 }$ and $\mathrm { C } _ { 4 }$ photosynthetic pathways discriminate against $^ { 1 3 } \mathrm { C }$ differently,leading to distinct carbon isotopic compositions in ${ \mathrm { C } } _ { 3 }$ and $\mathrm { C } _ { 4 }$ vegetation (Still et al.,2003).Wetlandemitted $\mathrm { C H } _ { 4 }$ becomes lighter at high latitudes (Gros et al., 2OO4; Tyler et al.,2007). This could be due to less $\mathrm { C H } _ { 4 }$ oxidation in high latitude wetlands,distinct methanogenic communities,changes in temperature, and the parent plant material in boreal wetlands being isotopically lighter $\left( \mathbf { C } _ { 3 } \right)$ than in tropical wetlands,where $\mathrm { C } _ { 4 }$ vegetation is also present (Brownlow et al.,2Ol7). Regional changes in emissions could be responsible for the post-2007 $\mathrm { C H } _ { 4 }$ increase,such as Asian coal mining or tropical wetlands (Nisbet et al., 2014, 2016). Therefore,an effort should be made to accurately represent the source signatures in these regions.

# 2.Data and methods

# 2.1.Model description

SOCOLv3 (Stenke et al.,2Ol3) is a global CCM based on the middle atmosphere version of ECHAM5 (Roeckner et al., 20o3), the fifth generation of the European Centre/HAMburg general circulation model (GCM),and the chemical transport model (CTM) MEZON (Egorova et al.,2003).ECHAM5 is coupled to MEZON through the distribution of temperature and radiation-active chemical species.The model is run in T42 horizontal resolution $( 2 . 8 ^ { \circ } ~ \times ~ 2 . 8 ^ { \circ } { \sim } )$ and 39 vertical levels up to around $8 0 ~ \mathrm { k m }$ ，Tracer advection is based on a flux-form semi-Lagrangian scheme (Lin and Rood,1996). The model time-step is $1 5 \mathrm { { m i n } }$ for dynamics and $^ \mathrm { ~ 2 ~ h ~ }$ for chemistry and radiation. For the years 1990-2o1O the model was run with specified dynamics ("nudging"),a relaxation technique that forces the model dynamics towards ERA-Interim reanalysis data (Dee et al.,2Ol1).This reduces the influence of model dynamics on the comparison between observed and simulated isotope ratios.SOcOL includes detailed stratospheric and tropospheric background chemistry, including the oxidation of $\mathrm { C H } _ { 4 }$ by OH, ${ \mathrm { O } } ( { } ^ { 1 } { \mathrm { D } } )$ ， and Cl.The chemistry scheme also contains the Mainz isoprene mechanism (MIM-1) (Poschl et al.,20oO).More information about the SOCOL version used in this study can be found in Revell et al. (2015).

# 2.2. $C H _ { 4 }$ emission fluxes

The model simulations presented here use a flux boundary condition for $\mathrm { C H } _ { 4 }$ (i.e.emission fluxes).Estimates of $\mathrm { C H } _ { 4 }$ emissions from different source categories were employed (Table 1).As well, the $\mathrm { C H } _ { 4 }$ soil sink was calculated online using uptake maps from Spahni et al. (2011), scaled by simulated atmospheric $\mathrm { C H } _ { 4 }$ concentrations.

The tropospheric OH concentrations in SOCOL are likely too high (Revell et al.,2015; Coulon,2016),leading to a shorter atmospheric $\mathrm { C H } _ { 4 }$ lifetime than in reality. Coulon (2Ol6) evaluated the simulated methyl chloroform (MCF) trend against observations,as MCF can be used as a tracer of OH variability (Montzka et al., 2Ol1). The evaluation demonstrated that simulated tropospheric OHis high biased by $2 7 \%$ for 1997-2oo8;however the offset from observations is constant.Therefore,in our simulations OH should not distort the $\mathrm { C H } _ { 4 }$ and $\delta ^ { 1 3 } \mathrm { C H } 4$ trends.However,since the OH sink varies spatially,the spatial distribution of the isotopic ratio may be impacted by this error.As well, SOCOL simulates $4 0 \%$ higher OH in the NH troposphere than the SH. Estimates constrained by MCF measurements suggest that the ratio is closer to unity (Patra et al., 2Ol4). Since the OH interhemispheric ratio is similar in all simulations,this bias would be consistent throughout the study.

In order to compensate for the high OH bias, $\mathrm { C H } _ { 4 }$ emissions in Table 1 were scaled by 1.23 to yield the observed global mean $\mathrm { C H } _ { 4 }$ concentration in 198o.The combination of bottom-up estimates of different source categories may lead to an unrealistic value for total $\mathrm { C H } _ { 4 }$ emissions,so applying scaling factors to emissions is common in other modelling studies (Monteil et al., 2011; Patra et al., 2011; Ghosh et al., 2015). The total scaled $\mathrm { C H } _ { 4 }$ emissions from 2000 to 2009 in the simulation (671 Tg $\mathrm { C H } _ { 4 } \mathrm { y r } ^ { - 1 } \mathrm { \frac { \Omega } { \Omega } }$ ）agree with the Kirschke et al. (2013) estimate for total bottom-up emissions (678 Tg $\mathrm { C H _ { 4 } y r } ^ { - 1 }$ ). Theemission weighted average isotopic signature of $\mathrm { C H } _ { 4 }$ for each simulation is not affected by scaling the emissions.

# 2.3. Isotopic implementation

Since deviations of isotopic ratios from the standard ratio are usually small, they are often reported in $\delta ^ { 1 3 } \mathrm { C H } 4$ notation:

$$
\delta ^ { 1 3 } \mathrm { C H } _ { 4 } = \left( \frac { [ ^ { 1 3 } \mathrm { C H } _ { 4 } ] [ [ ^ { 1 2 } \mathrm { C H } _ { 4 } ] ] } { ^ { 1 3 } R _ { \mathrm { V P D B } } } - 1 \right) \times 1 0 0 0 \%
$$

where $R _ { \mathrm { V P D B } }$ is the isotope ratio of the Vienna Pee Dee Belemnite (VPDB) standard $( ^ { 1 3 } { \bf C } / ^ { 1 2 } { \bf C } = 0 . 0 1 1 2 3 7 2 )$ . For chemical reactions, differences in the rate constants $( k )$ between $^ { 1 2 } \mathrm { C H } _ { 4 }$ and $^ { 1 3 } \mathrm { C H } _ { 4 }$ can be described by the fractionation factor, $\alpha _ { \mathrm { 1 3 C } }$ (Allegre and Sutcliffe, 2008):

$$
\alpha _ { \mathrm { 1 3 C } } = \frac { ^ { 1 3 } k } { ^ { 1 2 } k }
$$

Isotopic fractionation is sometimes represented by $\varepsilon _ { \mathrm { 1 3 C } }$ notation,also called the kinetic isotope effect:

$$
\varepsilon _ { \mathrm { 1 3 C } } = ( \alpha _ { \mathrm { 1 3 C } } - 1 ) \times 1 0 0 0
$$

For a baseline simulation (BASE),we selected the global mean source signatures in Table 2,which are commonly used in modeling studies (e.g. Monteil et al., 201l; Ghosh et al., 2015; Coulon,2016). Global mean $\mathrm { C H } _ { 4 }$ emissions have an isotopic signature of around $- 5 3 \text{‰}$ .The chemical sinks of $\mathrm { C H } _ { 4 }$ ，bypreferentially removing the lighter isotope of $\mathrm { C H } _ { 4 }$ ,shift the isotopic ratio by $+ \text{‰}$ to yield the observed atmospheric $\delta ^ { 1 3 } \mathrm { C H } _ { 4 }$ $( \sim - 4 7 \text{‰}$ .It is important to note, however, that the equilibration timescale of atmospheric $\delta ^ { 1 3 } \mathrm { C H } _ { 4 }$ is long and the observed atmospheric $\delta ^ { 1 3 } \mathrm { C H } _ { 4 }$ may lag changes in $\mathrm { C H } _ { 4 }$ emissions and sinks (Tans, 1997).

The fractionation factors for the OH, ${ \mathrm { O } } ( { } ^ { 1 } { \mathrm { D } } )$ ,and Cl reactions were compiled from the literature (Table 2).In addition to acting as a stratospheric oxidant of $\mathrm { C H } _ { 4 }$ ,atomic Cl has been suggested to act as a sink for $\mathrm { C H } _ { 4 }$ in the marine boundary layer (Allan et al., 2Oo7). This could influence the variability of $\delta ^ { 1 3 } \mathrm { C H } _ { 4 }$ due to the strong isotopic fractionation effect of Cl.However, the SOCOL model does not include a parametrization for atomic Cl production in marine environments.We decided that inclusion of this sink is out of the scope of this study since the spatial distribution and inter-annual variability of marine Cl are highly uncertain. The soil sink was implemented as a negative source that removes $\mathrm { C H } _ { 4 }$ at the surface.The isotopic fractionation from soil is expressed in $\delta ^ { 1 3 } \mathrm { C H } _ { 4 }$ notation, similar to sources (Allan et al., 20o1). The $\varepsilon _ { \mathrm { 1 3 C } }$ due to soil fractionation was measured to be $- 2 2 \text{‰}$ (Snover and Quay, 200O). The effective soil $\delta ^ { 1 3 } \mathrm { C H } _ { 4 }$ was assigned by depleting the atmospheric $\delta ^ { 1 3 } \mathrm { C H } _ { 4 }$ $( \sim - 4 7 \mathrm { ‰ } )$ by the soil $\varepsilon _ { 1 3 \mathrm { C } }$ $( - 4 7 - 2 2 = - 6 9 \% o )$

# 2.4. Simulations setup

Initial conditions were produced by spinning up the model for 15 years under 1990 conditions.As shown by Tans (1997), $\mathrm { C H } _ { 4 }$ isotopic ratios take longer to equilibrate after perturbations than total $\mathrm { C H } _ { 4 }$ . The 15 year spin-up time was sufficient for the isotopic ratio to be equilibrated in the troposphere.A spin-up was performed for each simulation,to ensure that the isotopes were equilibrated with the isotopic source signatures of that particular simulation.

Variability in five source signatures was investigated: coal,natural gas/oil,wetlands, livestock,and biomass burning (Table 3). The implemented spatial distribution of these source signatures will be described below.The use of regional source signatures leads to a more flexible global average source signature that changes over the course of the simulation,as the emissions from different regions change (Fig.4). Assuming that the source signature distributions that we applied are correct,this should lead to a more accurate trend in atmospheric $\delta ^ { 1 3 } \mathrm { C H } _ { 4 }$

# 2.4.2. Wetlands $\delta ^ { 1 3 } C H _ { 4 }$

We analyzed the available wetland isotopic measurements,including those compiled by Sherwood et al. # 2.5.Observations

$\mathrm { C H } _ { 4 }$ observations were provided by NOAA-ESRL (Dlugokencky et al., 2015). $\delta ^ { 1 3 } \mathrm { C H } _ { 4 }$ observations were measured by INSTAAR at the University of Colorado for 19 of the NOAA-ESRL stations (shown in Fig.lc),the earliest of which began measuring in 1998 (White et al., 20l7). The isotopic measurements will be referred to as NOAA-INSTAAR in this publication.The observations at surface sites were compared with the model grid boxes in which the sites were located.While model tracers are outputted continuously,observations of $\mathrm { C H } _ { 4 }$ and its isotopologues suffer from irregular sampling periods and prolonged data gaps.We employed a harmonic regression approach on the observations to reduce the influence of these irregularities on the model evaluation (see Section S1).Harmonic regression has often been applied to measurements of atmospheric trace gases (Nakazawa et al., 1997; Levin et al., 2012). Smoothing of simulated quantities was performed using a 12 month running average.

# 3.Results and discussion

# 3.1. Transient source signatures

When regional isotopic variations are considered for the $\mathrm { C H } _ { 4 }$ sources,the global mean source signatures differ from the commonly cited global means (Fig.4).For all of the sources except biomass burning,the isotopic signatures are globally lighter than the BASE isotopic signature. This confirms the analysis in Schwietzke et al. (2016),who also found that modelling studies use too heavy global isotopic signatures for $\mathrm { C H } _ { 4 }$ emissions.The previously used isotopic signatures were based on less empirical data than this study and Schwietzke et al. (2016). The lighter $\delta ^ { 1 3 } \mathrm { C H } _ { 4 }$ values calculated by this paper are likely more representative of the actual global mean signatures.

In our simulations the global mean isotopic signatures of source categories vary over time.The contributions of different regions to emissions have changed in previous decades,which is evidenced by several of the source signatures in Fig.4.The $\delta ^ { 1 3 } \mathrm { C H } _ { 4 }$ of global livestock emissions increases from 1990 to 2010. This is due to the expanding influence of agriculture from tropical regions (India, South America, and Tropical Asia),where heavier $\mathrm { C } _ { 4 }$ vegetation is more prevalent. The global mean coal source signature becomes heavier over time using both of the coal maps,M-COAL and $\mathbf { M } { \mathrm { - C O A L } } S$ $\delta ^ { 1 3 } \mathrm { C H } _ { 4 }$ of coal emissions increases due to growing Chinese coal emissions,which are relatively heavy $( - \ : 3 6 \ : \text{‰}$ in $\operatorname { M - C O A L } _ { - } S$ ） compared to the global average $( - 4 2 . 5 \mathrm { ~ ‰ ~ }$ in 199O).The coal signature trend in M-COAL_S is smaller than in M-COAL,because Chinese coal is $5 \text{‰}$ lighter in M-COAL_S.The global mean of biomass burning $\delta ^ { 1 3 } \mathrm { C H } _ { 4 }$ shows a strong decrease during the 1997-1998 El Nino,due to extremely high ${ \mathrm { C } } _ { 3 }$ burning (Randerson et al.,2Oo5).After 20o2 the biomass burning signature is fairly stable (Fig.4).The global mean source signatures of natural gas/oil and wetland emissions are relatively constant throughout the simulation (Fig.4).The variation of $\mathrm { C H } _ { 4 }$ source signatures over time due to changing regional emissions has not been considered in previous modelling studies.

# 3.2. Simulation of $C H _ { 4 }$

We will briefly discuss how simulated $\mathrm { C H } _ { 4 }$ compares with NOAA-ESRL observations (Dlugokencky et al., 2015). The $\mathrm { C H } _ { 4 }$ spatial distribution of our simulations agrees quite well with NOAA-ESRL observation stations (Fig.5).The interhemispheric difference (IHD) will be defined here as the 2001-2010 mean $\mathrm { C H } _ { 4 }$ concentration at South Pole Observatory (SPO) minus that of Alert,Canada (ALT, $8 2 ^ { \circ }$ N, $6 2 ^ { \circ }$ W). The $\mathrm { C H } _ { 4 }$ IHD of observations is -130 ppb,whereas in the simulations it is -1O7 ppb.Errors in simulated interhemispheric transport are minimized by nudging the model dynamics to ERA-Interim meteorology.Thus the small difference in IHD between simulations and observations is due to incorrect distributions of $\mathrm { C H } _ { 4 }$ emissions and/or sinks.

Fractionation factors for $\mathrm { C H } _ { 4 }$ sinks have been measured by several groups with relatively good agreement (Feilberg et al., 2Oo5; Saueressig et al., 2001; Tyler et al., 2000; Crowley et al.,1999; Roberto-Neto et al., 1998； Saueressig et al.，1995;Cantrell et al.，1990).However，the spatial distribution and temporal trend of the OH sink remain a source of uncertainty. # 4. Conclusions

Whereas other studies have focused on the impacts of emissions on $\mathrm { C H } _ { 4 }$ isotopic trends and spatial distribution,we have investigated the influences of source signature representation on $\mathrm { C H } _ { 4 }$ isotopes. Regional source signatures for coal,natural gas/oil,wetlands,livestock,and biomass burning were developed and implemented based on the available literature.The newly calculated global mean isotopic signatures are in general lighter than previous estimations.Two methods forrepresenting the regional coal signatures lead to different isotopic trends,revealing that more measurements of coal isotopic signatures are necessary. Introducing regionally distinct signatures for ${ \mathrm { C } } _ { 3 }$ and ${ \mathrm { C } } _ { 4 }$ fed-livestock leads to an $1 4 \%$ higher $\delta ^ { 1 3 } \mathrm { C H } _ { 4 }$ trend during 2003-2010 compared to using a global average livestock signature.This means that larger increases in tropical livestock emissions would be needed to explain the $\delta ^ { 1 3 } \mathrm { C H } _ { 4 }$ decrease after 20o8,compared to what would be expected from a global average livestock source signature.The combination of all of the regional source signatures leads to a stronger increasing $\delta ^ { 1 3 } \mathrm { C H } _ { 4 }$ trend as with the commonly used isotopic signatures. We show that the Chinese coal emission increase in EDGAR $\mathtt { v 4 . 2 }$ is difficult to reconcile with observed NOAA-INSTAAR $\delta ^ { 1 3 } \mathrm { C H } _ { 4 }$ trends, unless China has increased production of lower grade coal with a lighter source signature. Including regional source signatures also has a large impact on the $\delta ^ { 1 3 } \mathrm { C H } _ { 4 }$ spatial distribution,accounting for $4 5 \%$ of the $\delta ^ { 1 3 } \mathrm { C H } _ { 4 }$ IHD gap between simulations and observations.As $\mathrm { C H } _ { 4 }$ emissions have changed distinctly in different regions,we think that it is important to capture the regional character of source signatures in future modelling studies.Further field and laboratory measurements of the $\delta ^ { 1 3 } \mathrm { C H } _ { 4 }$ of emissions are essential to refine our estimates of regional source signatures.
