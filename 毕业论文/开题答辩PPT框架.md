### P3 · 背景：甲烷增长之谜
- CH₄ 是第二大人为温室气体；2007 年后重新快速增长、2020 年前后创历史高增速
- 增长主因未定：微生物源增强？化石源增加？OH 氧化能力下降？
- δ¹³C / δD 可区分源汇，但解读依赖源信号、**汇分馏因子**、传输假设
- 🖼 NOAA 全球 CH₄ 与 δ¹³C 长期序列（或 KIE/`fig1_timeseries_grid.png`）
- 💬 引出"汇分馏因子"是最薄弱一环

### P4 · 科学问题：OH ¹³C-KIE 的 25 年争议
- OH 占甲烷总汇约 84%，其 KIE 直接影响全球同位素收支
- 两实验室值不收敛：**Cantrell 1990 = 1.0054** vs **Saueressig 2001 = 1.0039**
- 后果：全球反演中重新分配约 **13–20 Tg yr⁻¹** 的化石源/微生物源，具政策含义
- **→ 需要一个独立于实验室条件的大气观测约束**
- 🖼 数轴对比图：1.0039 ↔ 1.0054，标注"±(13–20) Tg/yr"（自制简图）
- 💬 强调这不是学术细节，而是"堵化石泄漏 vs 管农业排放"的抉择

### P5 · 核心思想（关键点）
- 夏季 OH↑ → 优先消耗轻同位素 → 残余 CH₄ 在 ¹³C 与 D 上**同时富集**
- 若 OH 主导季节循环：**A(δ¹³C)/A(δD) ≈ (α¹³C−1)/(α_D−1)**
- **α_D_OH ≈ 1.294** 较确定 → 以"氢参考"反演有争议的 α¹³C_OH
- 纯 OH 预期振幅比 R ≈ **0.013–0.017**（Saueressig–Cantrell）
- 🖼 自制示意（夏季 OH↑→δ 抬升；两同位素正弦叠加）
- 💬 全篇"点子"，讲透这页答辩成功一半

### P6 · 关键难点：源季节性污染 → 为何用矢量
- 湿地源峰值与 OH 同处夏季，却把同位素推向**相反**方向
- 污染对 ¹³C 远重于 δD → 观测 R 被抬高（是"汇富集 − 源亏损"的净值，≠ KIE 比）
- OH（~7 月）与湿地（~7–8 月）存在**相位差** → 标量相减会出错，必须**矢量（相量）**处理
- 🖼 KIE/`fig2_harmonic_summary.png`（R vs 纬度，NH 远超纯 OH 带 + 相位差）
- 💬 用真实图证明"污染确实存在"，自然引出方法创新

### P7 · 研究目标、内容与关键科学问题（合并页）
- **总目标：** 建立从共址碳氢同位素季节循环反演 α¹³C_OH 的相量方法
- **四内容：** ①δ¹³C SCA 趋势（支撑）→ ②双同位素复相量表征 → ③湿地源矢量校正（核心）→ ④KIE 反演 + 非 OH 修正
- **三关键问题：** ①振幅比↔KIE 比关系与"OH 主导"边界；②如何矢量扣除同相位反方向的湿地源；③短重叠 / 低信噪下稳健区分两实验室值
- 🖼 四内容递进箭头（自制流程条）
- 💬 内容与问题一一对应："能不能做 / 怎么做对 / 做得准不准"

### P8 · 数据基础
- **δ¹³C：** NOAA/INSTAAR 通量瓶（Michel 2023）——24 站，约 4600 月记录，1998–2022
- **δD：** Riddell-Young 2025 多实验室协调记录；**CH₄：** NOAA GML（Lan 2025）
- **湿地 / 源信号：** Li 2026 网格 + Douglas 2021 / Ganesan 2018 / OIPC
- **最优子集：** 12 个共址站点，INSTAAR **2005–2010 同瓶配对**（无跨标尺问题）
- 🖼 KIE/`fig1_data_coverage.png`（配对覆盖热图，按纬度排序）
- 💬 同瓶配对是数据质量的护城河

### P9 · 方法一：季节谐波拟合与 SCA
- 拟合年谐波 y = c₀ + B·sin + C·cos；**振幅 A = 2√(B²+C²)**、相位 φ
- 三种 SCA 定义（原始 / 去趋势极差 / 谐波）；覆盖度筛选（每年 ≥8 月且 ≥3 季度、站点合格年 ≥70%）
- 不确定性：**Bootstrap（N≈2000）**
- 🖼 SCA/`phase6_period_coverage_heatmap.png` 或 KIE/`fig2_seasonal_cycles.png`（折叠季节循环 + 拟合曲线）
- 💬 两层分析共用的"引擎"

### P10 · 方法二 + 技术路线：复相量与矢量源校正（核心方法，合并页）
- 年谐波 → 复相量 **Z = B + iC**（模 = 振幅，辐角 = 相位）
- 湿地源相量 Z_src =(δ_src − δ_atm)·Z_frac；**矢量相减 Z_sink = Z_obs − Z_src** → R_corr
- 反演 α¹³C_OH → 用汇分数（OH 0.84 / Cl 0.035 / 土壤 0.06 / 平流层 0.065）修正非 OH → **Monte Carlo（N≈5×10⁴）**
- 诊断：校正后碳、氢**汇相位应同月**
- **技术路线条（页底横向小流程）：** 配对 → 谐波 → 跨站综合 → 矢量校正 → 反演 + 修正 → α 区间
- 🖼 KIE/`fig8_phasor_decomposition.png`（相量钟表分解图）
- 💬 最硬核一页，配矢量图讲

### P11 · 工作基础①：δ¹³C-CH₄ 季节振幅趋势（SCA）
- 24 站可稳定提取季节振幅（381/423 站点-年合格）
- 长期 2002–2022：弱正趋势，中位 **+0.034‰/decade**，12 站中 11 站为正
- 近期 2016–2022：更强且符号一致，中位 **+0.13‰/decade**，20 站全部为正
- 对三种 SCA 定义、OLS 与 Theil–Sen 两种估计量均稳健
- 🖼 SCA/`phase6_sca_harmonic_trends_by_latitude.png` + `phase6_sca_harmonic_period_comparison.png`
- 💬 证明"季节信号可稳健提取"，为双同位素分析铺路

### P12 · 工作基础②：相量校正与 KIE 约束（重点结果）
- NH 原始振幅比 = 纯 OH 预期的 **3–10 倍** → 证实强源污染
- 矢量校正后大幅下降（**BRW 0.139 → 0.056**）；校正后碳、氢汇相位一致到 **<1 个月**
- SH 洁净约束：**α¹³C_OH ≈ 1.0044（95% ≈ [0.997, 1.015]）**，与 **Saueressig（1.0039）一致**、与 Cantrell（1.0054）在不确定度内一致
- 🖼 KIE/`fig9_corrected_ratio.png` + `fig10_alpha_constraint.png`（校正后 R + α 约束对比）
- 💬 "方法真能给出可比实验室的独立约束"的证据

### P13 · 初步结论
1. **季节循环可作为 OH 碳 KIE 的大气观测约束** —— SH 洁净站给出 α¹³C_OH ≈ 1.0044，与 Saueressig 一致
2. **源季节性污染真实存在、可诊断、可矢量校正** —— NH 校正后振幅比大幅下降、汇相位趋于一致
3. **δ¹³C-CH₄ 季节振幅可稳健提取并呈弱正趋势** —— 长期弱正、近期更强，稳健于定义与估计量
- ⚠ 局限：NH 残余偏差（非湿地源、Cl 季节性）待处理；SH 仅 2 站，需保守对待
- 💬 明确"初步结论，正式结论待论文完成"
