# Implementation Plan — 2026-05-20

## Goal

Extract a cleaner observational constraint on the OH ¹³C KIE by removing wetland source contamination from the seasonal amplitude ratio R = A(δ¹³C)/A(δD) via phasor (vector) decomposition.

**Current state**: Phase 5 gives α¹³C_OH = 1.0034 (SH direct, 2 sites only) and 1.0162 (all clean sites, biased high). The source-corrected approach is biased because it uses scalar subtraction with a global δD source and no independent wetland seasonality constraint.

**Target**: A multi-site corrected ratio R_corr that converges across latitude, providing an observational KIE constraint with tighter uncertainty.

---

## Step 1: `extract_wetland_seasonality.py` ← NEXT

**Create** `experiments/KIE_sites/analysis/extract_wetland_seasonality.py`

### What it does
1. Open `ImportantReferences/Li2026ESSD_DS.nc` (monthly 1°×1° wetland CH₄ emissions, 2000–2025)
2. For each latitude band (NH high 60–90°N, NH mid 30–60°N, Tropics 30°S–30°N, SH extra 90–30°S, Global), sum over longitude
3. Compute 2005–2010 monthly climatology (6 years matching INSTAAR δD period)
4. Fit annual harmonic: `Q(t) = Q_mean + B_Q·sin(2πt/12) + C_Q·cos(2πt/12)`
5. For CGO/SPO: compute flux-weighted global mean seasonality

### Outputs
- `data/wetland_seasonality.json` — per-band: Q_mean (Tg/month), B_Q, C_Q, amplitude, phase, fractional amplitude; plus per-site assignment
- `figures/fig7_wetland_seasonality.png` — monthly climatology + harmonic fit (4 panels)

### Source region assignment
| Site | Source Region |
|------|-------------|
| ALT, ZEP, BRW | NH high-lat (60–90°N) |
| CBA, MHD, AZR | NH mid-lat (30–60°N) |
| MLO, KUM, ASC, SMO | Tropics (30°S–30°N) |
| CGO, SPO | Global flux-weighted |

### Verification
- Annual totals match Li2026: ~11 Tg NH high, ~30 Tg NH mid, ~114 Tg tropics, ~158 Tg global
- NH peaks July, SH peaks January
- Harmonic fits capture >80% of variance for strongly seasonal bands

## Step 2: `phase6_phasor.py`

**Create** `experiments/KIE_sites/analysis/phase6_phasor.py`

### Core algorithm
```
For each clean site, for each isotope (δ¹³C, δD):

  Z_obs    = B_obs + i·C_obs                              ← Phase 2 harmonic fits
  Z_frac   = (B_Q + i·C_Q) / Q_total                      ← wetland fractional seasonality
  Z_src    = (δ_source − δ_atm) × Z_frac                  ← source phasor (‰)
  Z_sink   = Z_obs − Z_src                                 ← vector subtraction

R_corrected = |Z_sink(δ¹³C)| / |Z_sink(δD)|
```

### Key parameters
| Parameter | Value | Source |
|-----------|-------|--------|
| δ¹³C_wetland | −62 ± 5 ‰ | Global (C₃-dominated at our sites) |
| δ¹³C_atm | −47.3 ‰ | NOAA |
| δD_wetland | Site-specific | `dD_source_database.json` |
| δD_atm | −86 ‰ | NOAA |
| Q_total | 580 ± 50 Tg/yr | Saunois (2025) |
| B_Q, C_Q | From Step 1 | Li2026 per source region |

### Monte Carlo uncertainty (N = 50,000)
Draw from:
- B, C ± bootstrap SE (Phase 2)
- δD_wetland ± site σ (from database)
- δ¹³C_wetland ~ N(−62, 5)
- Q_total ~ N(580, 50)
- B_Q, C_Q ± 20% (Li2026 model spread)
- Non-OH KIE parameters (same as Phase 5)

Invert R_corrected → α¹³C_OH using `ratio_to_alpha_13c()` from `phase5_kie.py`.

### Built-in consistency checks
1. **Sink phase agreement**: arg(Z_sink_δ¹³C) ≈ arg(Z_sink_δD) ≈ July for all sites
2. **R convergence**: R_corrected should be similar across sites (unlike R_uncorrected)
3. **Magnitude**: source phasor |Z_src| < |Z_obs| (correction should not exceed signal)

### Outputs
- `results/phase6_phasor/phasor_results.json` — per-site corrected R, sink phases, α¹³C_OH
- `figures/fig8_phasor_decomposition.png` — vector diagrams for select sites (ALT, BRW, CGO, SPO)
- `figures/fig9_corrected_ratio.png` — R_corrected vs latitude (with uncorrected overlay)
- `figures/fig10_alpha_constraint.png` — final α¹³C_OH constraint vs Saueressig/Cantrell
